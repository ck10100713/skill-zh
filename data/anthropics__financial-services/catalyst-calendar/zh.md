# 催化劑行事曆

## 工作流程

### 步驟 1：定義涵蓋範圍

- 要追蹤的公司清單（股票代號或名稱）
- 產業 / 行業聚焦
- 要不要納入總經事件？（Fed 會議、經濟數據、監管截止日）
- 時間範圍（未來 2 週、1 個月、1 季）

### 步驟 2：蒐集催化劑

針對每家公司，找出即將發生的事件：

**財報與財務事件**
- 季度財報的日期和時間（盤前/盤後）
- 年度股東會
- 投資人日 / 分析師日
- 資本市場日
- 債務到期 / 再融資日期

**公司事件**
- 產品發表或公告
- FDA 核准 / 監管決定
- 合約續約或到期
- 併購里程碑（交割日、監管核准）
- 管理層異動
- 內部人交易窗口（禁售期到期）

**產業事件**
- 重大研討會（日期、哪些公司會報告）
- 貿易展與展覽
- 監管意見徵詢期或裁決
- 產業數據發布（月銷售、流量等）

**總經事件**
- Fed 會議（FOMC 日期）
- 就業報告、CPI、GDP 發布
- 央行決議（ECB、BOJ 等）
- 對市場有影響的地緣政治事件

### 步驟 3：行事曆檢視

| 日期 | 事件 | 公司/產業 | 類型 | 影響（H/M/L） | 我們的部位 | 備註 |
|------|-------|---------------|------|-----------------|----------------|-------|
| | | | Earnings/Corp/Industry/Macro | | Long/Short/Neutral | |

### 步驟 4：每週預覽

每週產出一份前瞻性的摘要：

**本週重點事件：**
1. [星期幾]：[公司] Q[X] 財報：市場共識 [$X EPS]，我們的預估 [$X]，關注重點：[指標]
2. [星期幾]：[事件]：為什麼對 [股票] 重要
3. [星期幾]：[總經數據發布]：預期與部位

**下週預覽：**
- 提早預告即將到來的重要事件

**對部位的影響：**
- 可能讓特定部位波動的事件
- 建議的事前布局
- 二元事件之前的風險管理

### 步驟 5：輸出

- Excel 活頁簿，附行事曆檢視和可排序的欄位
- 每週預覽的 email/筆記（markdown）
- 選用：整合 Google Calendar

## 重要注意事項

- 財報日期會變動：接近日期時，要對照公司的 IR 頁面和 Bloomberg/FactSet 再確認
- 預先公告風險：追蹤有預先公告（pre-announce）歷史的公司（不論好消息或壞消息）
- 研討會的出席名單很有價值：哪些公司會報告？哪些公司明顯缺席？
- 有些催化劑是週期性的（每月的產業數據），建一個範本並自動填入
- 依影響程度用顏色標示：紅色 = 高影響、黃色 = 中等、綠色 = 例行
- 把過去的催化劑連同實際結果一起封存，隨著時間累積，能建立模式辨識能力
