# 論點追蹤器

## 工作流程

### 步驟 1：定義或載入論點

如果是建立新的論點：
- **公司**：名稱和股票代號
- **部位**：做多或做空
- **論點陳述**：1-2 句的核心論點（例如 "Long ACME — margin expansion from pricing power + operating leverage as mix shifts to software"）
- **關鍵支柱**：3-5 個支持論點
- **關鍵風險**：3-5 個會推翻論點的風險
- **催化劑**：可能證實／證偽論點的即將發生事件（財報、產品發表、法規決定）
- **目標價／估值**：如果論點成真，值多少
- **停損觸發條件**：什麼情況會讓你出場

如果是更新現有論點，請向使用者詢問新的資料點或進展。

### 步驟 2：更新紀錄

每個新的資料點或進展都記錄：

- **日期**：發生的時間
- **資料點**：變了什麼（財報超預期、管理層離職、競爭對手動作等）
- **對論點的影響**：它強化、削弱，還是抵銷了某個特定支柱？
- **動作**：不變／加碼／減碼／出場
- **更新後的信心**：高／中／低

### 步驟 3：論點計分卡

維護一份持續更新的計分卡：

| 支柱 | 原本預期 | 目前狀態 | 趨勢 |
|--------|---------------------|----------------|-------|
| 營收成長 >20% | 符合進度 | Q3 為 22% | 穩定 |
| 利潤率擴張 | 落後 | 利潤率年增持平 | 令人擔憂 |
| 新產品上市 | 待定 | 延到 Q2 | 觀察 |

### 步驟 4：催化劑日曆

追蹤即將到來的催化劑：

| 日期 | 事件 | 預期影響 | 備註 |
|------|-------|-----------------|-------|
| | | | |

### 步驟 5：輸出

適合以下用途的論點摘要：
- 晨會討論
- 投資組合檢視
- 風險委員會簡報

格式：簡潔的 markdown 或 Word 文件，附計分卡、近期更新和目前的信心水準。

## 重要注意事項

- 論點應該是可證偽的，如果沒有任何東西能推翻它，那它就不是論點
- 追蹤反面證據要跟追蹤正面證據一樣嚴謹
- 論點至少每季檢視一次，即使沒發生什麼大事
- 如果使用者管理多個部位，主動提議做一次完整的投資組合論點檢視
- 論點資料要用結構化格式儲存，才能跨 session 參照
