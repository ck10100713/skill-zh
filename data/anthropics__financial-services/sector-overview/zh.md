# 板塊總覽

## 工作流程

### 步驟 1：界定範圍

- **板塊／子板塊**：哪個產業、界定得多窄？
- **目的**：客戶報告、內部研究、pitch 素材、發想點子
- **深度**：高階概覽（5-10 頁）或深入研究（20-30 頁）
- **切入角度**：中立的全景 vs. 主題論述（例如 "AI infrastructure buildout"）
- **範圍**：只看上市公司，還是包含未上市公司？

### 步驟 2：市場概覽

**市場規模與成長**
- 總體可服務市場（TAM），並附來源
- 歷史成長率（5 年 CAGR）
- 預測成長率與關鍵假設
- 市場區隔（依產品、地區、終端市場、客戶類型）

**產業結構**
- 分散 vs. 集中，前 5 名的市占率
- 價值鏈圖：價值累積在哪一段？
- 商業模式類型（訂閱、交易、授權、服務）
- 進入障礙（資本、法規、技術、網路效應）

**關鍵趨勢與驅動因素**
- 長期順風（3-5 個主要趨勢）
- 逆風與風險
- 技術顛覆的切入點
- 法規動態
- 併購活動與整併趨勢

### 步驟 3：競爭格局

**公司簡介**（前 5-10 名業者）：

| 公司 | 營收 | 成長 | EBITDA 利潤率 | 市占率 | 關鍵差異化 |
|---------|---------|--------|--------------|-------------|-------------------|
| | | | | | |

每家公司寫簡短簡介：
- 業務描述（2-3 句）
- 策略定位與護城河
- 近期動態（財報、併購、產品發表）
- 估值快照（P/E、EV/EBITDA、EV/Revenue）

**競爭動態**
- 公司之間怎麼競爭？（價格、產品、服務、通路）
- 誰在搶市占、誰在丟市占，為什麼？
- 新進者或相鄰業者帶來的顛覆風險

### 步驟 4：估值背景

- 板塊交易倍數（目前和歷史區間）
- 溢價／折價的驅動因素（成長、利潤率、市場地位）
- 近期併購交易倍數
- 這個板塊跟大盤比起來如何？

### 步驟 5：投資意涵

- 風險報酬比最好的機會在哪裡？
- 可以透過這個板塊表達哪些主題性押注？
- 板塊內的主要爭論（多方 vs. 空方論點）
- 可能改變板塊敘事的催化劑

### 步驟 6：輸出

- Word 文件或 PowerPoint，包含：
  - 市場概覽與規模估算
  - 競爭格局地圖
  - 公司比較表
  - 估值摘要
  - 關鍵圖表：市場成長、市占趨勢、估值歷史
- 附上含詳細公司資料的 Excel 附錄

## 重要注意事項

- 所有市場規模資料都要註明來源，引用研究機構或方法論
- 區分 TAM 的炒作和實際可觸及的市場
- 板塊總覽很快就過時，要註明日期，並標出可能已經過期的資料
- 圖表不可少：市場規模 waterfall、競爭定位矩陣、估值散布圖
- 如果是給客戶的，要把「所以呢（so what）」對準他們的具體情況（併購標的篩選、競爭定位、進入市場）
