# 清理資料

清理作用中工作表或指定範圍裡雜亂的資料。

## 環境

- **如果在 Excel 裡執行（Office Add-in / Office JS）：**直接用 Office JS（`Excel.run(async (context) => {...})`）。用 `range.values` 讀取，用 `range.formulas = [["=TRIM(A2)"]]` 寫入輔助欄位的公式。「就地修改 vs 輔助欄位」的判斷依然適用。
- **如果是處理獨立的 .xlsx 檔：**用 Python/openpyxl。

## 工作流程

### 步驟 1：範圍

- 如果有給範圍（例如 `A1:F200`），就用它
- 否則用作用中工作表的整個已使用範圍
- 對每一欄做剖析：偵測它的主要型別（文字 / 數字 / 日期），並找出離群值

### 步驟 2：偵測問題

| 問題 | 要找什麼 |
|---|---|
| 空白 | 前後多餘的空格、連續兩個空格 |
| 大小寫 | 類別欄位裡不一致的大小寫（`usa` / `USA` / `Usa`） |
| 文字格式的數字 | 存成文字的數值；數字儲存格裡夾雜的 `$`、`,`、`%` |
| 日期 | 同一欄混用不同格式（`3/8/26`、`2026-03-08`、`March 8 2026`） |
| 重複 | 完全重複的列，以及近似重複（只差在大小寫/空白） |
| 空值 | 其他部分都有資料的欄位裡的空儲存格 |
| 型別混雜 | 一欄有 98% 是數字，卻夾了 3 筆文字 |
| 編碼 | 亂碼（`Ã©`、`â€™`）、不可列印的字元 |
| 錯誤 | `#REF!`、`#N/A`、`#VALUE!`、`#DIV/0!` |

### 步驟 3：提出修正方案

在改任何東西之前，先顯示摘要表：

| 欄位 | 問題 | 數量 | 建議修正 |
|---|---|---|---|

### 步驟 4：套用

- **優先用公式，不要寫死清理後的值**：只要清理後的輸出能用公式表達（例如 `=TRIM(A2)`、`=VALUE(SUBSTITUTE(B2,"$",""))`、`=UPPER(C2)`、`=DATEVALUE(D2)`），就把公式寫在相鄰的輔助欄位，不要在 Python 裡算好結果再蓋掉原始資料。這樣轉換過程才透明、可稽核。
- 只有在使用者明確要求，或沒有合理的公式可以對應時（例如編碼/亂碼修復），才用計算出來的值就地覆蓋
- 破壞性的操作（移除重複、填補空值、覆蓋原始資料），要先跟使用者確認
- 每一類修正做完之後（空白 → 大小寫 → 數字轉換 → 日期 → 去重），先給使用者看改了什麼的樣本，確認後再進行下一類
- 回報一份修改前/修改後的摘要，說明改了什麼
