# 盡職調查 Checklist

## 工作流程

### 步驟 1：界定盡調範圍

向使用者詢問：
- **目標公司**：名稱、產業、商業模式
- **交易類型**：平台收購（platform acquisition）、add-on、成長型股權投資、recap、carve-out
- **交易規模／複雜度**：決定盡調要做到多深
- **關鍵疑慮**：已知需要優先處理的問題（客戶集中度、法規、環境等）
- **時程**：LOI／交割預計什麼時候？

### 步驟 2：產生各工作流的 Checklist

針對所有主要工作流產生 checklist，並依產業客製：

**財務盡調**
- 盈餘品質（QoE）：營收與 EBITDA 調整
- 營運資金分析：正常化 vs. 實際
- 債務與類債務項目
- 資本支出（維持性 vs. 成長性）
- 稅務結構與風險
- 審計歷史與會計政策
- 備考（pro forma）調整（run-rate、綜效）

**商業盡調**
- 市場規模與成長（TAM/SAM/SOM）
- 競爭定位與市占率
- 客戶分析：集中度、留存率、NPS
- 定價能力與合約結構
- 銷售管線與 backlog
- 進入市場（go-to-market）效益

**法律盡調**
- 公司結構與組織圖
- 重大合約（客戶、供應商、合作夥伴）
- 訴訟歷史與未決請求
- 智慧財產組合與保護
- 法規遵循
- 僱傭協議與競業禁止

**營運盡調**
- 管理團隊評估
- 組織結構與關鍵人物風險
- IT 系統與基礎設施
- 供應鏈與供應商依賴
- 廠房與不動產
- 保險涵蓋範圍

**HR／人力盡調**
- 組織圖與人數趨勢
- 薪酬對標
- 福利與退休金義務
- 關鍵員工留任風險
- 文化評估
- 工會／勞動協議

**IT／技術盡調**（針對技術驅動的事業）
- 技術堆疊與架構
- 技術債評估
- 資安狀態
- 資料隱私合規（GDPR、CCPA、SOC2）
- 產品 roadmap 與研發支出
- 擴展性評估

**環境／ESG**（適用時）
- 環境負債
- 法規遵循歷史
- ESG 風險與機會

### 步驟 3：狀態追蹤

每個項目都要追蹤：

| 項目 | 工作流 | 優先級 | 狀態 | 負責人 | 備註 |
|------|-----------|----------|--------|-------|-------|
| QoE report | Financial | P0 | Pending | | |
| Customer interviews | Commercial | P0 | In Progress | | 10 場完成 3 場 |

狀態選項：Not Started → Requested → Received → In Review → Complete → Red Flag

### 步驟 4：紅旗摘要

維護一份盡調期間發現的紅旗清單，持續更新：
- 發現了什麼
- 屬於哪個工作流
- 嚴重程度（致命傷／重大／可處理）
- 緩解措施或解決路徑
- 對估值或交易條款的影響

### 步驟 5：輸出

- 每個工作流一個分頁的 Excel 活頁簿（預設）
- 摘要儀表板：各工作流完成百分比、未完成項目、紅旗
- 給交易團隊的每週狀態更新格式

## 依產業追加項目

依產業自動加入相關項目：
- **軟體／SaaS**：ARR 品質、cohort 分析、託管成本、SOC2
- **醫療**：法規核准、給付風險、付款方組合
- **工業**：設備狀況、環境整治、安全紀錄
- **金融服務**：監理資本、合規歷史、信用品質
- **消費**：品牌健康度、通路組合、季節性、庫存管理

## 重要注意事項

- 優先處理卡住 LOI 或交割的 P0 項目
- 標出賣方回應很慢的項目，這可能代表有問題
- 把 data room 內容跟 checklist 交叉比對，找出缺漏
- 盡調進行中要持續更新 checklist，它是一份活文件
