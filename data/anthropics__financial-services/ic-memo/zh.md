# 投資委員會備忘錄

## 工作流程

### 步驟 1：蒐集輸入

向使用者蒐集（或取自這個 session 先前的分析）：

- 公司概覽與業務描述
- 產業／市場背景
- 歷史財務資料（3 到 5 年）
- 管理層評估
- 交易條款（價格、結構、融資）
- 盡調發現（商業、財務、法律、營運）
- 價值創造計畫／100 天計畫
- 報酬分析（base、upside、downside）

### 步驟 2：草擬備忘錄結構

標準的 IC 備忘錄格式：

**I. 執行摘要**（1 頁）
- 公司描述、交易理由、關鍵條款
- 建議與重點報酬
- 前 3 大風險與緩解措施

**II. 公司概覽**（1 到 2 頁）
- 業務描述、產品／服務
- 客戶基礎與 go-to-market
- 競爭定位
- 管理團隊

**III. 產業與市場**（1 頁）
- 市場規模與成長
- 競爭格局
- 長期趨勢／順風
- 法規環境

**IV. 財務分析**（2 到 3 頁）
- 歷史表現（營收、EBITDA、利潤率、現金流）
- 盈餘品質調整
- 營運資金分析
- 資本支出需求

**V. 投資論點**（1 頁）
- 為什麼這是有吸引力的投資（3 到 5 個支柱）
- 價值創造槓桿（內生成長、利潤率擴張、併購、倍數擴張）
- 100 天優先事項

**VI. 交易條款與結構**（1 頁）
- 企業價值與隱含倍數
- 資金來源與用途（Sources & uses）
- 資本結構／槓桿
- 關鍵法律條款

**VII. 報酬分析**（1 頁）
- Base、upside 和 downside 情境
- 各情境的 IRR 和 MOIC
- 驅動報酬的關鍵假設
- 敏感度分析

**VIII. 風險因素**（1 頁）
- 依嚴重程度和可能性排序的關鍵風險
- 每項風險的緩解措施
- 致命傷風險（如果有）

**IX. 建議**
- 明確的建議：Proceed / Pass / Conditional proceed
- 關鍵條件或後續步驟

### 步驟 3：輸出格式

- 預設：排版專業的 Word 文件（.docx）
- 替代：給快速審閱用的 Markdown
- 財務和報酬要用表格，不要只有文字敘述

## 重要注意事項

- IC 備忘錄應該基於事實且平衡，誠實呈現看多和看空兩種情況
- 不要淡化風險。IC 成員反正會自己找到，可信度才是重點
- 如果使用者提供了事務所的標準備忘錄範本，就用那份
- 財務表格要對得上：檢查 EBITDA bridge、S&U 是否平衡、報酬計算是否一致
- 缺少輸入就去問，不要對交易條款或報酬做假設
