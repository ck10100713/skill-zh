# CIM 建構器

## 工作流程

### 步驟 1：蒐集來源資料

詢問有哪些可用的輸入：
- 管理層簡報
- 歷史財務報表（3-5 年）
- 預算/預測
- 公司網站與行銷素材
- 客戶資料（必要時匿名化）
- 組織圖
- 先前的簡報或董事會簡報
- 獲利品質報告（Quality of Earnings，如果有）

### 步驟 2：CIM 結構

標準的 CIM 目錄：

**I. 執行摘要（Executive Summary）**（2-3 頁）
- 公司概覽：做什麼、為什麼能贏
- 投資亮點（5-7 個關鍵賣點）
- 財務摘要：重點營收、EBITDA、成長、利潤率
- 交易概覽：出售的是什麼、預計時程

**II. 公司概覽**（3-5 頁）
- 歷史與創立故事
- 使命與價值主張
- 產品與服務說明
- 商業模式與營收來源
- 關鍵差異化與競爭優勢

**III. 產業概覽**（3-5 頁）
- 市場規模與成長動態（TAM/SAM/SOM）
- 關鍵產業趨勢與順風
- 競爭格局
- 監管環境
- 進入障礙

**IV. 成長機會**（2-3 頁）
- 內生成長槓桿（新產品、新市場、定價）
- 併購 / 附加併購機會
- 營運改善
- 技術投資
- 空白市場分析

**V. 客戶與銷售**（3-5 頁）
- 客戶概覽（數量、區隔、地理）
- 主要客戶分析（LOI 之前要匿名化）
- 客戶集中度與留存指標
- 銷售流程與進入市場策略
- 銷售管線與在手訂單

**VI. 營運**（2-3 頁）
- 組織架構
- 關鍵人員
- 設施與地理足跡
- 技術與系統
- 供應鏈 / 廠商關係

**VII. 財務概覽**（5-8 頁）
- 歷史損益表（3-5 年）
- 營收分析：依部門、地區、客戶類型
- EBITDA 橋接與利潤率分析
- 資產負債表概覽
- 現金流量摘要
- 資本支出歷史
- 營運資金分析
- 管理層預測 / 預算（如果要納入）

**VIII. 附錄**
- 詳細財務報表
- 客戶名單（匿名化）
- 產品目錄
- 管理層簡歷

### 步驟 3：草擬準則

- **語氣**：專業、據實、有說服力，但不誇大
- **敘事**：說一個故事，說明為什麼這個事業有吸引力、有護城河，而且已經站在成長的位置上
- **以數據為本**：每個論點都要有數據支撐。「強勁成長」→「2021-2024 年營收的 CAGR 為 15%」
- **視覺**：財務趨勢、市場規模、競爭定位都用圖表
- **篇幅**：總共 40-60 頁，細節足以讓買家做第一輪出價，又不會長到買家不想讀
- **保密**：要附免責聲明頁。除非賣方同意，敏感的客戶資料要匿名化

### 步驟 4：輸出

- 排版專業的 Word 文件（.docx）
- 另附含詳細財務資料的 Excel 附錄
- 圖表和附件內嵌在文件裡

## 重要注意事項

- CIM 是銷售文件：以優勢開場，但不要隱瞞重大問題（買家在盡職調查時會找到）
- 投資亮點要回應每個買家都在意的 3 件事：成長潛力、利潤率結構和護城河
- 財務標準化 / 備考調整（pro forma adjustment）要清楚標示並解釋
- 保密免責聲明和任何監管揭露事項，要跟法務一起處理
- 發出之前，要請管理層確認事實是否正確
- CIM 會設定估值預期：確保敘事能支撐開價
