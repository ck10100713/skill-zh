# 投資提案

## 工作流程

### 步驟 1：潛在客戶背景

蒐集：
- **潛在客戶姓名**與家庭資料
- **目前狀況**：有現任顧問嗎？自己操作嗎？是什麼促成這場會面？
- **資產**：預估 AUM、帳戶類型、目前持有部位（如果願意分享）
- **目標**：退休、財富保全、成長、收益、教育、遺產
- **風險承受度**：保守、穩健、積極（或問卷分數）
- **限制**：ESG 偏好、集中持股、流動性需求
- **費用敏感度**：他們現在付多少？
- **競爭對手**：他們還在考慮誰？

### 步驟 2：提案結構

**I. 關於我們事務所**（1 頁）
- 事務所概覽、歷史、AUM
- 投資理念（用白話講）
- 團隊簡介（跟這位客戶相關的人）
- 客戶服務模式（多久見一次面、有事找誰）

**II. 了解您的需求**（1 頁）
- 重述他們的目標與顧慮，讓對方知道你有在聽
- 在探索階段找出的關鍵規劃考量
- 對他們來說成功長什麼樣子

**III. 建議的投資策略**（2 到 3 頁）
- 建議的資產配置與理由
- 配置如何對應他們的目標和風險承受度
- 投資工具（ETF、共同基金、個股、另類資產）
- 考量稅務的策略（資產位置配置、稅損收割）

建議配置：

| 資產類別 | 配置 | 工具 | 理由 |
|------------|-----------|---------|-----------|
| | | | |

**IV. 預期成果**（1 到 2 頁）
- 預估成長情境（保守、穩健、樂觀）
- 達成目標的 Monte Carlo 機率
- 收益預估（如果以退休或收益為重）
- 風險指標（最大回撤、波動度）
- 與目前投資組合的比較（如果已知）

**V. 費用結構**（1 頁）
- 顧問費表（如適用則為分級）
- 底層基金費用
- 全部加總的總成本估計
- 費用與產業平均的比較
- 價值主張：他們付這筆費用能得到什麼

**VI. 如何開始**（1 頁）
- 開戶流程
- 資產轉移時程
- 轉換計畫（如果是從別的顧問轉過來）
- 最初 90 天：會發生什麼事
- 所需文件與後續步驟

### 步驟 3：客製化

- 語氣配合潛在客戶（企業高階主管 vs. 小企業主 vs. 退休人士）
- 如果他們有集中持股，要直接處理
- 如果他們拿你跟機器人理財顧問（robo-advisor）比，強調規劃和關係的價值
- 如果他們對價格敏感，先講總價值和成果，不只是費用

### 步驟 4：輸出

- 帶有事務所品牌的 PowerPoint 簡報（12 到 15 張）
- 給客戶帶回去的 PDF 版本
- 用於後續跟進 email 的一頁摘要

## 重要注意事項

- 提案要讓人感覺是個人化的，不是套範本，要引用對方的具體情況
- 不要過度吹噓績效，設定實際的預期，強調流程
- 一定要附免責聲明（預估為假設性質、過往績效等）
- 轉換計畫很重要，客戶害怕更換顧問帶來的混亂
- 48 小時內帶著提案和明確的下一步去跟進
- 對潛在客戶簡報前，合規部門必須先審閱
