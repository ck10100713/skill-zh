# 報酬分析

## 工作流程

### 步驟 1：蒐集交易輸入

向使用者詢問（或從先前的分析中取得）：

**進場：**
- 進場 EBITDA（LTM 或 NTM）
- 進場倍數（EV / EBITDA）
- 企業價值
- 交割時的淨負債
- 股權投入金額
- 交易費用與支出

**融資：**
- 優先債（x EBITDA、利率、攤還）
- 次順位債／夾層債（如有）
- 進場時的總槓桿（x EBITDA）
- 股權出資

**營運假設：**
- 營收成長率（年）
- EBITDA 利潤率走勢
- 資本支出佔營收的 %
- 營運資金變動
- 債務償還時程

**出場：**
- 持有期間（年）
- 出場倍數（EV / EBITDA）
- 出場 EBITDA（由成長假設算出）

- EBITDA 成長的貢獻
- 倍數擴張／收縮的貢獻

- 費用／支出的拖累

## 關鍵公式

- **MOIC** = 出場股權價值 / 投入股權
- **IRR** = 解 r：投入股權 × (1 + r)^n = 出場股權價值（有期間現金流時要調整）
- **報酬歸因**：
  - 成長：(出場 EBITDA - 進場 EBITDA) × 出場倍數 / 股權
  - 倍數：(出場倍數 - 進場倍數) × 進場 EBITDA / 股權
  - 槓桿：持有期間的債務償還 / 股權

## 重要注意事項

- 適用的話，報酬一律同時呈現扣費前（gross）和扣除費用／carry 後（net）
- 管理層再投資（rollover）和共同投資會改變股權投入金額，相關的話要問
- 股利再融資（dividend recap）或期間分配會大幅影響 IRR，有計畫的話要納入
- 別忘了交易成本（通常是 EV 的 2-4%），它們會降低第一天的股權價值
- 稅務考量（資產交易 vs. 股權交易、338(h)(10) 選擇）可能實質影響稅後報酬
