# Deal 篩選

## 工作流程

### 步驟 1：擷取交易事實

從提供的 CIM、teaser 或說明中擷取：

- **公司**：名稱、所在地、產業／次產業
- **描述**：做什麼的（1 到 2 句）
- **財務**：營收、EBITDA、利潤率、成長率
- **交易類型**：Platform、add-on、recap、少數股權、carve-out
- **開價／估值**：倍數，若有載明則包括企業價值
- **賣方動機**：為什麼現在賣
- **管理層**：留任入股還是退出
- **主要客戶**：集中度風險
- **主要風險**：明顯的紅旗

### 步驟 2：對照標準篩選

套用基金的投資標準（不知道就問使用者）：

| 標準 | 目標 | 實際 | 通過／不通過 |
|-----------|--------|--------|-----------|
| 營收區間 | | | |
| EBITDA 區間 | | | |
| EBITDA 利潤率 | | | |
| 成長輪廓 | | | |
| 產業契合度 | | | |
| 地區 | | | |
| 交易規模／EV | | | |
| 估值（x EBITDA） | | | |
| 客戶集中度 | | | |
| 管理層延續性 | | | |

### 步驟 3：快速評估

提供三個部分的評估：

1. **結論**：Pass / Further Diligence / Hard Pass
2. **看多理由**（2 到 3 點）：為什麼這可能是好交易
3. **看空理由**（2 到 3 點）：主要風險與疑慮
4. **關鍵問題**：第一通電話要弄清楚的事

### 步驟 4：輸出

一頁式篩選備忘錄，適合分享給合夥人，或用於 IC 的快速篩選。

## 重要注意事項

- 速度很重要，篩選應該花幾分鐘，不是幾小時
- 紅旗要直說，不要把疑慮藏起來
- 如果財務數字看起來不一致或不完整，要明確標出來
- 如果是第一次篩選，一開始就先問基金的標準
- 標準一經確認，就存進 memory 供未來的交易使用
