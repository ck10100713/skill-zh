# 晨會筆記

## 工作流程

### 步驟 1：隔夜發展

掃描整個覆蓋範圍內的相關事件：

**財報與 Guidance**
- 有任何覆蓋的公司在隔夜或盤前發布財報嗎？
- 財報驚喜（營收、EPS、關鍵指標的 beat/miss）
- Guidance 變動（上調、下調、維持）

**新聞與事件**
- 併購公告或傳聞
- 管理層異動
- 產品發布或監管決定
- 競爭同業的分析師升評／降評
- 影響該產業的總經數據或政策變動

**市場背景**
- 隔夜期貨／盤前走勢
- 產業 ETF 表現
- 相關的大宗商品或貨幣走勢
- 今天的重要經濟數據公布

### 步驟 2：晨會筆記格式

要精簡，晨會筆記應該 2 分鐘內讀完：

---

**[日期] Morning Note — [分析師姓名]**
**[覆蓋產業]**

**Top Call: [標題：PM 們必須聽到的那一件事]**
- 2 到 3 句話講關鍵發展以及為什麼重要
- 對股票的影響：目標價、重申／調整評等

**隔夜／盤前發展**
- [公司 A]：一行摘要財報／新聞 + 我們的看法
- [公司 B]：一行摘要 + 我們的看法
- [產業／總經]：相關的整個產業層級的發展

**今日重要事件**
- [時間]：[公司] 財報電話會議
- [時間]：經濟數據公布（市場預期 vs. 我們的看法）
- [時間]：研討會或投資人日

**交易想法**（如有）
- [做多/做空] [公司]：1 到 2 句論點 + 催化劑
- 風險：什麼會讓這個想法錯掉

---

### 步驟 3：財報快評

如果有覆蓋的公司發布了財報，提供快速反應：

| 指標 | 共識 | 實際 | Beat/Miss |
|--------|-----------|--------|-----------|
| Revenue | | | |
| EPS | | | |
| [關鍵指標] | | | |
| Guidance | | | |

**我們的看法**：2 到 3 句話，這對股票是好是壞？有改變我們的論點嗎？

**行動**：維持 / 升評 / 降評？調整目標價嗎？

### 步驟 4：輸出

- 給 email／Slack 發送用的 Markdown 文字
- 若需要正式發送，則用 Word 文件
- 最多 1 頁，PM 和交易員不會讀更多

## 重要注意事項

- 要有觀點，只摘要新聞卻沒有看法的晨會筆記沒有用
- 先講最重要的事，不要把標題藏起來
- 「沒有新聞」也是一份有效的晨會筆記，就寫「隔夜無重大事項，維持現有部位」
- 區分可行動的事件（財報、併購）和雜訊（次要的分析師筆記、不算事件的事）
- 為你的看法標註時間，如果你是早上 6 點寫的，要註明盤前走勢到開盤前可能會變
- 如果你錯了，在下一份晨會筆記裡承認，可信度比每次都對更重要
