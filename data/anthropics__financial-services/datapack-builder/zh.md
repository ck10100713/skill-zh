# 財務資料包建構器

為私募股權、投資銀行和資產管理建立專業、標準化的財務資料包。把來自 CIM、募資備忘錄、SEC 申報文件、網路搜尋或 MCP server 存取的財務資料，轉成可供投資委員會審閱、精緻的 Excel 活頁簿。

**重要：**整個流程中，所有 Excel 檔案的建立與操作都要用 xlsx skill。

## 關鍵成功因素

每份資料包都必須達到這些標準。任何一點沒做到，交付物就無法使用。

### 1. 資料正確性（零容忍錯誤）
- 每個數字都要追溯到來源文件，並附上頁碼
- 一律用公式計算（不能寫死的值）
- 交叉檢查小計與合計，確保內部一致
- 驗證資產負債表平衡：Assets = Liabilities + Equity
- 確認現金流量與資產負債表的變動勾稽得上

### 2. 必要規則

**規則 1：財務資料（衡量金錢的）→ 帶 $ 的貨幣格式**
觸發詞：Revenue、Sales、Income、EBITDA、Profit、Loss、Cost、Expense、Cash、Debt、Assets、Liabilities、Equity、Capex
格式：百萬用 $#,##0.0，千用 $#,##0
負數：$(123.0)，不是 -$123

**規則 2：營運資料（算數量的）→ 數字格式，不加 $**
觸發詞：Units、Stores、Locations、Employees、Customers、Square Feet、Properties、Headcount
格式：#,##0，帶千分位逗號
負數：(123)，跟表格其他部分一致

**規則 3：百分比（比率與比例）→ 百分比格式**
觸發詞：Margin、Growth、Rate、Percentage、Yield、Return、Utilization、Occupancy
格式：0.0%，一位小數
顯示：15.0%，不是 0.15

**規則 4：年份 → 文字格式，避免被插入逗號**
格式：文字，或用自訂格式避免變成 2,024
顯示：2020、2021、2022、2023A、2024E

**規則 5：情境混合時，每個指標各自用適合的格式**
範例：
```
Segment Analysis, 2022, 2023, 2024
Retail Revenue, $50.0, $55.0, $60.0
  Stores, 100, 110, 120
  Revenue per Store, $0.5, $0.5, $0.5
```
營收和每店指標用 $，店數用數字格式。

**規則 6：所有計算都用公式 → 絕對不要寫死計算出來的值**
所有小計、合計、比率和推導出來的指標，都必須是公式，不能是寫死的值。這樣才能確保正確，也能動態更新。

### 3. 專業呈現標準

**格式標準：**

**配色：兩個層次：**

**第 1 層：字型顏色（來自 xlsx skill，強制）**
- **藍色文字（RGB: 0,0,255）**：所有寫死的輸入值（歷史資料、假設），不是一般文字
- **黑色文字（RGB: 0,0,0）**：所有公式和計算
- **綠色文字（RGB: 0,128,0）**：連結到其他工作表

**第 2 層：填色（選用，用來加強呈現）**
- 填色是選用的，只有在使用者要求，或為了加強呈現時才套用
- 如果使用者要求顏色或專業格式，使用這套標準配色：
  - **區塊標題**：深藍色（RGB: 68,114,196）背景，搭配白色文字
  - **子標題/欄位標題**：淺藍色（RGB: 217,225,242）背景，搭配黑色文字
  - **輸入儲存格**：淺綠/米色（RGB: 226,239,218）背景，搭配藍色文字
  - **計算儲存格**：白色背景，搭配黑色文字
- 如果使用者有指定，可以改用自訂的品牌色

**兩層如何搭配（如果有用填色）：**
- 輸入儲存格：藍色文字 + 淺綠色填色 = 「使用者輸入的資料」
- 公式儲存格：黑色文字 + 白色背景 = 「計算出來的值」
- 工作表連結：綠色文字 + 白色背景 = 「來自另一個分頁的參照」

**字型顏色告訴你它「是什麼」。填色告訴你它「在哪裡」（如果有用的話）。**

**重要：**xlsx skill 的字型顏色是強制的。填色是選用的，預設是白色/無填色，除非使用者要求加強格式或顏色。

**一定要套用：**
- 標題粗體、靠左對齊
- 數字靠右對齊
- 子項目縮排 2 個空格
- 小計上方用單底線
- 最終合計下方用雙底線
- 凍結列/欄標題的窗格
- 邊框要極簡（只在結構上需要的地方）
- 字型一致（通常是 Calibri 或 Arial 11pt）

**絕對不要放：**
- 每個儲存格都加邊框
- 多種字型或字型大小
- 圖表，除非特別要求
- 過度的格式或裝飾

## 結構一致性
除非明確指示不同，否則使用標準的 8 個分頁結構：
1. Executive Summary
2. Historical Financials (Income Statement)
3. Balance Sheet
4. Cash Flow Statement
5. Operating Metrics
6. Property/Segment Performance（如適用）
7. Market Analysis
8. Investment Highlights

### 分頁 1：Executive Summary
目的：給忙碌的主管看的一頁概覽

內容：
- 公司概覽（2-3 句話說明商業模式）
- 關鍵投資亮點（3-5 個重點）
- 財務快照表（最近 3 年加上預測的 Revenue、EBITDA、Growth）
- 交易概覽（如適用）
- 醒目顯示的關鍵指標

格式：乾淨、標題粗體、裝飾極簡、強調關鍵數字

### 分頁 2：Historical Financials (Income Statement)
目的：完整的損益歷史

內容：
- 依部門/產品線拆解的營收
- 銷貨成本 / 營收成本
- 毛利與毛利率 %
- 詳細的營業費用（S&M、R&D、G&A）
- EBITDA 與 Adjusted EBITDA
- 線下項目（D&A、利息、稅）
- 淨利

格式：
- 年份放在欄位（文字格式：2020、2021、2022）
- $ 百萬或 $ 千（在最上方清楚註明單位）
- 所有財務資料用會計格式
- 小計上方用單底線，淨利下方用雙底線
- 所有數字靠右對齊

### 分頁 3：Balance Sheet
目的：期末的財務狀況

內容：
- 流動資產（現金、AR、存貨、預付款、其他）
- 長期資產（PP&E、無形資產、商譽、其他）
- 流動負債（AP、應計費用、一年內到期債務、其他）
- 長期負債（長期債務、遞延稅項、其他）
- 股東權益（普通股、保留盈餘、其他）

格式：
- 驗證公式：Assets = Liabilities + Equity
- 日期標示一致
- 包含營運資金計算
- 主要小計上方用單底線，最終合計用雙底線

### 分頁 4：Cash Flow Statement
目的：現金創造與使用的分析

內容：
- 營業現金流（優先用間接法）
- 投資現金流（capex、收購、資產出售）
- 籌資現金流（債務發行/償還、權益、股利）
- 現金淨變動
- 期初與期末現金餘額

格式：
- 盡可能連結到損益表和資產負債表
- 顯示淨利到營業現金流的調節
- 清楚標示現金的用途（流出）和來源（流入）

### 分頁 5：Operating Metrics
目的：非財務的 KPI 與營運資料

內容（依產業而定）：
- 單位量、客戶數、據點數
- 生產力指標（每位員工、每家店、每單位的營收）
- 產能利用率
- 市占率
- 客戶留存/流失率
- 產業特有的 KPI

**關鍵的格式注意事項：**
營運指標**不加**金錢符號。這些是數量，不是貨幣。

格式：
- 清楚註明單位（客戶、員工、店、平方英尺等）
- 帶千分位逗號的整數：1,250，不是 $1,250
- 比率用百分比：95.0%
- 數字靠右對齊

### 分頁 6：Property/Segment Performance（如適用）
目的：依事業單位、物業或部門的詳細拆解

內容：
- 各部門的營收與獲利能力
- 各據點/產品的關鍵指標
- 部門特有的 KPI
- 比較績效分析

格式：營收/EBITDA 跟財務分頁一致，營運指標用數字格式

### 分頁 7：Market Analysis
目的：產業背景與競爭定位

內容：
- 市場規模與成長趨勢
- 競爭格局概覽
- 市占率分析
- 產業標竿與同業比較
- 監管環境（如相關）

格式：敘述文字與表格並用，市場資料要註明來源

### 分頁 8：Investment Highlights
目的：關鍵投資論點的敘述性摘要

內容：
- 競爭優勢的詳細說明
- 成長機會與策略性舉措
- 風險因素與緩解策略
- 管理層評估與過往紀錄
- 投資論點摘要

格式：標題清楚、使用重點條列、段落精簡

## 逐步工作流程

### 階段 1：文件處理與資料擷取

**步驟 1.1：分析來源資料**
- 取得來源資料：上傳的文件、網路搜尋公開申報文件，或 MCP server 的資料
- 檢視資料結構，找出關鍵區段
- 找出財務報表（通常是 3-5 年的歷史資料）
- 如果有包含管理層預測，要找出來
- 記下會計年度結束日
- 任何資料品質問題都要立刻標記

**步驟 1.2：擷取財務報表**
- 找出歷史損益表資料
- 擷取資產負債表的快照（年底或季底）
- 找出現金流量表
- 如果有管理層預測，也要擷取
- 記下所有頁碼，方便追溯

**步驟 1.3：擷取營運指標**
- 找出跟產業相關的非財務 KPI
- 擷取單位經濟（unit economics）資料
- 擷取客戶/據點/產能資料
- 記錄成長指標與趨勢

**步驟 1.4：擷取市場與產業資料**
- 競爭定位資訊
- 市場規模與成長率
- 產業標竿資料
- 同業比較資訊

**步驟 1.5：記下關鍵背景**
- 交易結構與理由
- 管理團隊背景
- 來源資料裡的投資亮點
- 風險因素與考量
- 任何資料缺口或不一致

### 階段 2：資料標準化

**步驟 2.1：統一會計表達方式**
- 確保所有年度的會計科目名稱一致
- 統一收入認列的處理方式
- 找出並記錄一次性費用
- 需要時建立「Adjusted EBITDA」的調節表
- 記下任何會計政策的變更

**步驟 2.2：套用格式偵測邏輯**
對每個資料點，根據完整的脈絡決定格式：
- 讀取分頁名稱、表格標題、欄位標題和列標籤
- 套用必要規則（見上面）
- 不確定時，查看原始來源文件
- 預設用較乾淨的格式（少即是多）

**步驟 2.3：找出需要標準化的調整項目**
要記錄的常見調整：
- 重組費用（真的是非經常性的才加回）
- 股票酬勞（依產業標準加回）
- 收購相關成本（加回，並註明金額）
- 法律和解或訴訟成本（評估再次發生的風險）
- 資產出售或減損（從營運結果中排除）
- 關係人調整（標準化成市場價格）
備註：引用來源的格式依資料來源而異（文件用頁碼，網路來源用 URL，MCP 資料用 server 參照）

**步驟 2.4：建立調整明細表**
對每一項標準化調整：
- 記錄調整了什麼、為什麼
- 引用來源（文件頁碼、URL 或資料來源參照）
- 量化每一年的金額影響
- 評估再次發生的風險
- 顯示從申報數字到調整後數字的計算

**步驟 2.5：驗證資料完整性**
- 用公式確認小計加總正確
- 驗證資產負債表平衡
- 檢查現金流量跟資產負債表的變動勾稽得上
- 交叉檢查各分頁的數字是否一致
- 標記任何差異，以便調查

### 階段 3：建立 Excel 活頁簿

**關鍵：所有 Excel 檔案的操作都要用 xlsx skill。繼續之前，先讀 xlsx skill 的文件。**

**步驟 3.1：建立標準化的分頁結構**
建立含以下分頁的活頁簿：
- Executive Summary
- Historical Financials
- Balance Sheet
- Cash Flow
- Operating Metrics
- Property Performance（如適用）
- Market Analysis
- Investment Highlights

**步驟 3.2：用正確的格式建立每個分頁**
有系統地套用格式規則：
- 標題：粗體、靠左對齊、11pt 字型
- 財務資料：貨幣格式，百萬用 $#,##0.0
- 營運資料：數字格式 #,##0（不加 $）
- 百分比：0.0% 格式
- 年份：文字格式，避免被插入逗號
- 負數：用帶括號的會計格式
- 底線：小計上方用單底線，合計下方用雙底線

**步驟 3.3：插入計算用的公式**
- 所有小計與合計都必須是公式
- 適當時把資產負債表連結到損益表
- 把現金流量表同時連結到損益表和資產負債表
- 建立跨分頁參照以便驗證
- 避免寫死任何計算出來的值

### 錯誤：寫死的列偏移量

**不要用相對偏移量，表格結構一改就會壞掉：**

```python
# ❌ 錯誤：脆弱的、靠偏移量的參照

# ❌ 錯誤：魔術數字
formula = f"=B{current_row-10}*C{current_row-20}"
```

**為什麼會失敗：**
- 新增/刪除列時會悄悄壞掉
- 光看程式碼無法驗證正確性
- 在交付的 Excel 檔裡會變成除錯的惡夢

- 設定適當的欄寬（通常 12-15 個字元）

### 階段 4：情境建立（如果有預測）

**Management Case：**
照來源資料提供的內容，呈現公司的預測：
- 擷取所有管理層的假設
- 記錄成長率、利潤率擴張、資本需求
- 記下關鍵驅動因素和敏感度
- 標記任何需要保持懷疑的「曲棍球棒」轉折
- 以「Management Case」呈現，並清楚標示

**Base Case（風險調整後）：**
根據公司特有的風險因素，對管理層預測做保守調整：
- 套用營收成長的折減，反映執行風險和歷史預測準確度
- 根據產業標竿和營運槓桿，調降利潤率擴張的假設
- 如果成長有賴資本支出，就提高 capex 假設
- 如果營運資金需求被低估，就補上
- 如適用，根據整合的複雜度，延後綜效的實現
- 記錄所有調整，並附上理由和佐證分析

**Downside Case（選用，但建議用在 LBO 分析）：**
根據產業的景氣循環性和公司的弱點，做壓力測試的情境：
- 建模營收下滑，反映衰退風險或競爭壓力
- 假設壓力下的利潤率壓縮（量能槓桿反轉、定價壓力）
- 測試債務條款遵循和流動性
- 評估下檔保護
- 記錄被壓力測試的關鍵風險

**情境的文件記錄要求：**
建立假設明細表，顯示：
- 各情境的關鍵假設（營收成長、利潤率、capex %）
- 每項調整的理由
- 關鍵變數的敏感度分析
- 歷史預測準確度（如果有）
- 與產業標竿的比較

### 階段 5：品質管控與驗證

**步驟 5.1：資料正確性檢查**
驗證：
- 每個數字都能追溯到來源（抽樣檢查，並引用文件/URL/server）

## 標準化模式

### EBITDA 的常見調整

**1. 重組費用**
- 真的是非經常性的才加回（關廠、一次性遣散費）
- 如果公司每年都在重組，就**不要**加回
- 記錄具體的性質，以及為什麼不會再發生的理由
- 範例："2023 restructuring: $3.0M facility closure, documented in source materials, one-time event"

**2. 股票酬勞**
- 業界標準：在私募股權分析中加回
- 視為非現金的營業費用
- 所有期間要一致
- 如果特別高，或包含一次性的授予，要註明

**3. 收購相關成本**
- 加回交易費用、整合成本
- 依類型記錄具體金額
- 持續性的整合投資不要加回
- 每項調整都要引用來源

**4. 法律和解與訴訟**
- 真的是孤立事件才加回
- 評估再次發生的風險（單一和解 vs 一連串的訴訟）
- 記錄和解的性質
- 考慮這是否屬於正常營運範圍

**5. 資產出售或減損**
- 從營運 EBITDA 中排除資產出售的損益
- 真的是非經常性的才移除減損費用
- 記錄出售/減損的是哪些資產、為什麼
- 如果這些資產有產生營業利益，要調整營收

**6. 關係人調整**
- 把高於市價的關係人費用（租金、管理費）標準化
- 調整成市價，並附上佐證文件
- 移除透過公司報銷的個人費用
- 記錄市價比較

### 保守 vs 積極的標準化

**Management Case：**
- 納入管理層提出的所有調整
- 接受公司對「非經常性」的定義
- EBITDA 調整較積極
- 用來了解管理層的觀點

**Base Case（投資決策建議用這個）：**
- 只納入明確非經常性的項目
- 對經常出現的「一次性」費用，審視得更嚴格
- 排除推測性的調整
- 較保守，向投資委員會說明時站得住腳

## 依產業的調整

### 科技/SaaS
要擷取的關鍵指標：
- ARR（Annual Recurring Revenue）與 MRR
- 依 cohort 的客戶數
- CAC（客戶取得成本）與 LTV（生命週期價值）
- 流失率（總額與淨額）
- 淨營收留存率
- Rule of 40（Growth % + EBITDA Margin %）
- Magic number（銷售效率）

格式備註：ARR 是貨幣（$），客戶數是數字（不加 $），比率是 %

### 製造/工業
要擷取的關鍵指標：
- 生產產能與產能利用率 %
- 各產品線的生產量
- 存貨週轉
- 各產品線的毛利率
- 訂單積壓（backlog）

格式備註：單位、產能是數字（不加 $），利用率是 %，營收/成本是貨幣

### 不動產/旅宿
要擷取的關鍵指標：
- 物業/房間數/平方英尺
- 住房率 %
- ADR（Average Daily Rate）：貨幣格式
- RevPAR（Revenue per Available Room）：貨幣格式
- NOI（Net Operating Income）：貨幣格式
- Cap rate %
- FF&E 準備金

格式備註：房間數/平方英尺是數字，住房率是 %，ADR/RevPAR 是貨幣

### 醫療保健/服務業
要擷取的關鍵指標：
- 據點/設施
- 醫療提供者/員工
- 病患/就診（量的指標）
- 每次就診營收：貨幣
- 付款人組成 %
- 同店成長 %

格式備註：據點/就診數是數字，每次就診營收是貨幣，比率是 %
