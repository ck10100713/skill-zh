# Deal Tracker

## 工作流程

### 步驟 1：交易設定

每筆交易都要記錄：
- **交易名稱／代號**：Project [Name]
- **客戶**：賣方或買方名稱
- **交易類型**：賣方、買方、融資、重組
- **角色**：主辦顧問、共同顧問、公平意見書
- **交易規模**：預期企業價值
- **階段**：Pre-mandate → Engaged → Marketing → IOI → Diligence → Final bids → Signing → Close
- **團隊**：指派的 MD、VP、Associate、Analyst
- **關鍵日期**：委任日、CIM 發送日、IOI 截止日、管理層會議、最終報價截止日、目標交割日

### 步驟 2：里程碑追蹤

每筆交易追蹤關鍵里程碑：

| 里程碑 | 目標日期 | 實際日期 | 狀態 | 備註 |
|-----------|------------|-------------|--------|-------|
| 委任書簽署 | | | | |
| CIM / teaser 草擬 | | | | |
| 買家名單核准 | | | | |
| Teaser 發送 | | | | |
| NDA 簽署 | | | | |
| CIM 發送 | | | | |
| IOI 截止 | | | | |
| IOI 收件／審閱 | | | | |
| 選出短名單 | | | | |

| 最終報價截止 | | | | |

### 步驟 3：待辦事項

維護一份跨所有交易的待辦事項清單，持續更新：

| 待辦 | 交易 | 負責人 | 到期日 | 優先級 | 狀態 |
|--------|------|-------|----------|----------|--------|
| | | | | P0/P1/P2 | Open/Done/Blocked |

### 步驟 4：每週交易檢討

為每週團隊會議產生摘要：

**每筆進行中的交易：**
1. 一行狀態更新
2. 本週重要進展
3. 即將到來的里程碑（未來 2 週）
4. 阻礙或風險
5. 下週的待辦事項

**管線摘要：**
- 各階段進行中的交易總數
- 有風險的交易（錯過里程碑、流程停滯）
- 管線中的新委任／提案
- 本季預期交割

### 步驟 5：輸出

- Excel 活頁簿，包含：
  - 管線總覽（所有交易，每筆一列）
  - 每筆交易一個里程碑追蹤分頁
  - 待辦事項總清單
  - 每週檢討摘要
- 選用：給 email／Slack 發送的 Markdown 摘要

## 重要注意事項

- 至少每週更新一次 tracker，過期的 tracker 比沒有還糟
- 標出里程碑正在延誤的交易，提早預警才不會出意外
- 沒有負責人和到期日的待辦事項不會有人做，所以要寫具體
- 管線視圖應該顯示交易階段、規模和成交機率，對營收預測很有用
- 記錄買家／投資人的回饋，回饋中的規律可以用來調整策略
- 已完成／已告吹的交易另外歸檔，讓進行中的視圖保持乾淨
