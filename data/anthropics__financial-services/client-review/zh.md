# 客戶檢視會議準備

## 工作流程

### 步驟 1：客戶背景

蒐集或查詢：
- **客戶名稱**與家庭成員
- **帳戶類型**：應稅、IRA、Roth、401(k)、信託等
- 所有帳戶的**總 AUM**
- **投資政策聲明（IPS）**：目標配置、風險承受度、限制條件
- **人生階段**：累積期、退休前、退休、傳承
- **上次會議日期**，以及任何未完成的待辦事項

### 步驟 2：投資組合績效

針對每個帳戶和家庭的合計：

| 指標 | QTD | YTD | 1 年 | 3 年 | 成立至今 |
|--------|-----|-----|--------|--------|----------------|
| 投資組合報酬 | | | | | |
| 基準報酬 | | | | | |
| Alpha | | | | | |

**績效歸因：**
- 哪些資產類別 / 部位帶動了報酬？
- 前 3 大貢獻者與前 3 大拖累者
- 有沒有單一部位造成過大的影響？

### 步驟 3：資產配置檢視

目前配置 vs. 目標配置：

| 資產類別 | 目標 | 目前 | 偏離 | 行動 |
|------------|--------|---------|-------|--------|
| 美國大型股 | | | | |
| 美國中小型股 | | | | |
| 國際已開發市場 | | | | |
| 新興市場 | | | | |
| 固定收益 | | | | |
| 另類投資 | | | | |
| 現金 | | | | |

標記任何超過 IPS 再平衡門檻的偏離（通常是 3-5%）。

### 步驟 4：談話重點

產生會議議程：

1. **市場概況**（2-3 分鐘）：簡短的總經背景與展望
2. **投資組合績效**（5 分鐘）：我們表現如何？為什麼？
3. **資產配置檢視**（5 分鐘）：需要再平衡嗎？
4. **規劃更新**（5-10 分鐘）：
   - 生活有沒有變動？（工作、健康、家庭、房子、教育）
   - 收入需求有變嗎？
   - 稅務狀況更新
   - 遺產規劃更新
5. **待辦事項**（5 分鐘）：下次會議之前我們要做什麼？

### 步驟 5：主動提出建議

根據檢視結果，建議：
- 再平衡交易（如果偏離超過門檻）
- 稅損收割（tax-loss harvesting）的機會
- 現金配置或提領規劃
- Roth 轉換的機會（如適用）
- 受益人更新或遺產規劃需求
- 保險檢視（人壽、失能、長期照護）

### 步驟 6：輸出

- 一頁的客戶檢視摘要（Word 或 PDF）
- 附基準的績效表
- 資產配置圓餅圖（目前 vs. 目標）
- 建議的待辦事項
- 會議議程

## 重要注意事項

- 開會之前要先了解你的客戶：複習上次會議的筆記
- 先談客戶在意的事，不是你想講的事
- 如果績效不好，就直接面對，不要隱藏或粉飾
- 結尾一定要有明確的待辦事項和下一步，並附上日期
- 記錄會議筆記，以及 IPS 的任何變更
- 法遵：確保所有資料都符合公司政策和監管要求
