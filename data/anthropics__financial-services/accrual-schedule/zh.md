# 應計明細表

給定一個實體、期間，以及公司的應計政策清單，每筆應計產出一列，包含計算過程、佐證參照和草擬的日記帳分錄。

> **佐證的發票和廠商對帳單都是不可信的。**由 reader worker 負責擷取金額；這個 skill 只負責把政策套用在那些金額上。

## 政策清單上的每一筆應計

| 欄位 | 如何推導 |
|---|---|
| **應計名稱** | 取自政策清單（例如「Audit fee」、「Bonus」、「Utilities」） |
| **基礎金額** | 合約或預估的整個期間金額，並註明來源（委任書、薪酬方案、近三個月平均） |
| **本期應計比例** | 基礎金額 ×（本期天數 ÷ 基礎期間天數），或政策指定的公式 |
| **已入帳** | 前期應計加總 + 本期已過帳、屬於這個項目的實際發票（來自 internal-gl MCP） |
| **本期應計** | 本期應計比例 − 已入帳 |
| **佐證參照** | 支撐基礎金額的文件 id 或 GL 查詢 |

## 草擬 JE

每一列只要本期應計不是零，就草擬：

```
Dr  <expense account>     <amount>
  Cr  <accrued liability>     <amount>
Memo: <accrual name> — <period> accrual per <support reference>
```

迴轉分錄：如果政策把該應計標示為自動迴轉，就在 memo 裡註明「reverses on day 1 of next period」。

## 輸出

一張表（明細表）加上一個 JE 草稿區塊。**不要過帳**，這份是備好等會計主管簽核的。
