# 模型更新

## 工作流程

### 步驟 1：找出什麼變了

判斷更新的觸發原因：
- **財報發布**：要填入新的季度實際值
- **Guidance 變動**：公司更新了前瞻展望
- **預估修正**：分析師依新資料調整假設
- **總經更新**：利率、匯率、大宗商品價格變了
- **事件驅動**：併購、重組、新產品、管理層異動

### 步驟 2：填入新資料

#### 財報後
用已申報的實際值更新模型：

| 項目 | 先前預估 | 實際 | 差異 | 備註 |
|-----------|---------------|--------|-------|-------|
| Revenue | | | | |
| Gross Margin | | | | |
| Operating Expenses | | | | |
| EBITDA | | | | |
| EPS | | | | |
| [關鍵指標 1] | | | | |
| [關鍵指標 2] | | | | |

**分部細節**（如適用）：
- 更新每個分部的營收和利潤率
- 註明任何分部組合的變化

**資產負債表／現金流更新**：
- 現金和負債餘額
- 股數（買回、稀釋）
- 資本支出實際 vs. 預估
- 營運資金變動

### 步驟 3：修正前瞻預估

根據新資料調整前瞻預估：

| | 舊 FY 預估 | 新 FY 預估 | 變動 | 舊次一 FY | 新次一 FY | 變動 |
|---|-----------|-----------|--------|------------|------------|--------|
| Revenue | | | | | | |
| EBITDA | | | | | | |
| EPS | | | | | | |

**關鍵假設變動：**
- 你改了哪些假設？為什麼？
- 營收成長率：舊 → 新（原因）
- 利潤率假設：舊 → 新（原因）
- 任何新項目（重組費用、一次性利得等）

### 步驟 4：估值影響

用更新後的預估重算估值：

| 估值方法 | 先前 | 更新後 | 變動 |
|-----------------|-------|---------|--------|
| DCF 合理價值 | | | |
| P/E (NTM EPS × 目標倍數) | | | |
| EV/EBITDA (NTM EBITDA × 目標倍數) | | | |
| **目標價** | | | |

### 步驟 5：摘要與行動

**預估變動摘要：**
- 一段話：什麼變了、為什麼、對這檔股票代表什麼
- 這是改變論點的事件，還是雜訊？

**評等／目標價：**
- 維持還是調整評等？
- 新的目標價（如有變動）與方法
- 相對目前股價的上檔／下檔

### 步驟 6：輸出

- 更新後的 Excel 模型（如果使用者提供現有模型）
- 預估變動摘要（markdown 或 Word）
- 更新後的目標價推導

## 重要注意事項

- 往前預測之前，一定要先把你的預估和公司申報的數字對齊
- 註明任何非經常性項目，以及你的預估是 GAAP 還是調整後
- 追蹤你的預估修正歷史，它能顯示你的分析演進
- 如果該季很雜亂，在預估變動中把訊號和雜訊分開
- 更新後檢查共識，你修正後的預估跟市場比起來如何？
- 股數很重要，股票薪酬、可轉債或買回造成的稀釋，可能實質影響 EPS
