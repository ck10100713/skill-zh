# Investor Materials

做出一致、可信、而且容易自圓其說的投資人資料。

## When to Activate

- 建立或修改 pitch deck
- 撰寫投資人備忘錄或 one-pager
- 建立財務模型、里程碑計畫或資金用途表
- 回答加速器或孵化器的申請問題
- 讓多份募資文件對齊同一個事實來源

## Golden Rule

所有投資人資料都必須彼此一致。

動筆之前，先建立或確認單一的事實來源（source of truth），涵蓋：
- 營運成效指標（traction）
- 定價與營收假設
- 募資規模與工具
- 資金用途
- 團隊簡介與職稱
- 里程碑與時程

如果出現互相矛盾的數字，先停下來解決，再起草。

## Core Workflow

1. 盤點權威的事實
2. 找出缺少的假設
3. 選擇資料類型
4. 用明確的邏輯起草
5. 把每個數字都對照事實來源交叉檢查

## Asset Guidance

### Pitch Deck
建議的流程：
1. 公司 + 切入點（wedge）
2. 問題
3. 解決方案
4. 產品 / demo
5. 市場
6. 商業模式
7. 營運成效（traction）
8. 團隊
9. 競爭 / 差異化
10. 募資需求（ask）
11. 資金用途 / 里程碑
12. 附錄

如果使用者想要網頁原生的 deck，把這個 skill 搭配 `frontend-slides`。

### One-Pager / Memo
- 用一句乾淨的話說明公司在做什麼
- 說明為什麼是現在
- 儘早放入營運成效和佐證
- 讓募資需求精確
- 讓每個主張都容易驗證

### Financial Model
包含：
- 明確的假設
- 有用時，提供 bear / base / bull 三種情境
- 乾淨、一層一層的營收邏輯
- 跟里程碑連動的支出
- 當決策取決於假設時，做敏感度分析

### Accelerator Applications
- 精確回答被問的問題
- 優先講營運成效、洞察和團隊優勢
- 避免吹噓
- 內部指標要跟 deck 和模型保持一致

## Red Flags to Avoid

- 無法驗證的主張
- 沒有說明假設的模糊市場規模
- 不一致的團隊角色或職稱
- 加起來對不上的營收算式
- 在假設脆弱的地方卻誇大確定性

## Quality Gate

交付之前：
- 每個數字都符合目前的事實來源
- 資金用途和營收各層加總正確
- 假設是看得到的，沒有被埋起來
- 不靠炒作用語，故事也很清楚
- 最終資料在合夥人會議上站得住腳
