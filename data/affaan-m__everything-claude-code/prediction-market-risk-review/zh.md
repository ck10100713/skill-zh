# Prediction Market Risk Review

在預測市場的工作流程碰到使用者的財務背景、交易場所認證、投資組合資料、自動化或具備執行能力的工具之前，使用這個 skill。

## Review Gate

### 建議的界線

- 確認輸出只是資訊性質。
- 移除買進/賣出/持有/部位大小的建議。
- 讓人工的決策點保持明確。

### 交易場所與法規的界線

- 辨識交易場所的條款、地理限制、帳號上限和 API 規則。
- 相關時，把賭博、衍生性商品、證券或商品的模糊地帶標記出來，送法務審查。
- 不要繞過交易場所的限制或 rate limit。

### 資料品質

- 檢查市場流動性、價差、結算規則、過期的價格和來源時間戳記。
- 把公開的交易場所資料，跟 Itô 控管的資料分開。
- 沒有標示的話，不要混用公開和私有的來源。

### 安全

- 不要索取或儲存私鑰、助記詞或密碼。
- 不要讓 `ITO_API_KEY` 和交易場所的 API key 出現在 log 和文件裡。
- 預設使用唯讀的 scope。
- 在任何私有實作加入執行能力之前，要求有熔斷機制、支出上限、dry run 和人工核准。

### 隱私

- 盡量減少使用者的投資組合、財務和知識庫資料。
- 在公開的產出物裡，把私有來源遮蔽掉。
- 只保留 review 需要的欄位。

## 輸出格式

回傳：

1. review 的範圍
2. pass/warn/fail 的發現
3. 被擋下的動作
4. 必要的緩解措施
5. 安全的下一步

如果有人要求任何具備執行能力的步驟，要求另外有獨立的實作計畫和使用者的明確核准。
