# Investor Outreach

寫出簡短、具體、而且讓對方容易採取行動的投資人溝通內容。

## When to Activate

- 寫給投資人的陌生開發信
- 起草暖介紹的請託信
- 會議後或對方沒回覆時寄出跟進信
- 在募資過程中寫投資人近況更新
- 根據基金的投資論點或合夥人的契合度，調整溝通內容

## Core Rules

1. 每則外寄訊息都要個人化。
2. 讓請求的門檻低。
3. 用佐證，不要用形容詞。
4. 保持簡潔。
5. 絕對不要寄出任何投資人都能收到的文案。

## Voice Handling

如果使用者的語氣很重要，先執行 `brand-voice`，並重用它的 `VOICE PROFILE`。
這個 skill 要保留投資人專屬的結構和提出請求的紀律，不要自己另外重做一套平行的語氣系統。

## Hard Bans

出現以下任何一種，就刪掉重寫：
- "I'd love to connect"
- "excited to share"
- 沒有實質關聯的泛泛投資論點讚美
- 模糊的創辦人形容詞
- 乞求的語氣
- 直接提出請求更清楚時，卻用軟弱的收尾問句

## Cold Email Structure

1. 主旨：簡短而且具體
2. 開頭：為什麼特別找這位投資人
3. 提案：公司在做什麼、為什麼是現在，以及哪些佐證重要
4. 請求：一個具體的下一步
5. 署名：姓名、職稱，必要時加一個可信度的依據

## Personalization Sources

引用以下其中一項或多項：
- 相關的投資組合公司
- 公開的投資論點、演講、貼文或文章
- 共同的人脈
- 跟投資人的關注焦點有明確的市場或產品契合

如果缺少這些 context，要明講草稿還需要個人化，不要假裝已經完成。

## Follow-Up Cadence

預設：
- 第 0 天：初次外寄
- 第 4 或 5 天：簡短跟進，附上一個新的數據點
- 第 10 到 12 天：最後一次跟進，乾淨地收尾

之後就不要繼續催，除非使用者想要更長的序列。

## Warm Intro Requests

讓幫忙介紹的人輕鬆一點：
- 說明為什麼這個介紹是合適的
- 附上一段可以直接轉寄的文案
- 可轉寄的文案控制在 100 字以內

## Post-Meeting Updates

要包含：
- 具體討論過的事情
- 承諾過的答覆或更新
- 有的話，加一個新的佐證
- 下一步

## Quality Gate

交付之前：
- 訊息是真的有個人化
- 請求很明確
- 佐證很具體
- 客套的讚美和緩衝語氣都不見了
- 字數控制得很精簡
