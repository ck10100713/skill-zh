# 付費媒體實驗

1. 說明要做的決策、因果假設、實驗組、對照組、隨機化單位、母體、主要指標、護欄、最小效果和停止規則。
2. 檢查平台限制、重疊的實驗、轉換延遲、季節性、互相干擾和衡量品質。
3. 根據宣告的假設計算樣本數和期間；揭露近似的部分。
4. 一次只改一個決策面，除非設計明確要估計交互作用。
5. 事先登記排除條件、品質檢查、分析方式和決策門檻。
6. 判讀結果時，先驗證分組的完整性和資料的完整度，再估計效果和不確定性。
7. 用有版本的 JSON 回傳設定或結果判讀，並附上白話的決策。

不要反覆偷看、一看到有利的結果就停；不要把檢定力不足的雜訊說成贏家；也不要把結論推廣到沒測過的母體。
