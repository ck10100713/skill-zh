# 商品攝影變體

1. 確認擁有商品圖的使用權，並蒐集驗證過的品牌設定檔、商品事實、預計使用的版位、provider 能力、成本上限和輸出根目錄。
2. 保留商品的幾何形狀、包裝、logo、標籤、顏色和材質，除非操作者明確核准更動。
3. 定義不同的製作假設，例如攝影棚、情境使用、成分故事、尺寸/細節或生活風格；不要暗示沒有根據的商品成效。
4. 產生已核准的長寬比，並記錄來源 hash、prompt 版本、provider/model、成本、輸出 hash 和尺寸。
5. 驗證商品的真實還原度、視覺瑕疵、安全區、無障礙和政策。
6. 在 run 目錄裡以原子性的方式儲存素材和 manifest。

一定要有人審查。不要製作誤導的前後對比證據、未經授權的人物或代言，也不要靠視覺暗示做出受管制的宣稱。
