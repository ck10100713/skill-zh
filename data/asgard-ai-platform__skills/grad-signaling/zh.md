# 訊號理論

## 概述

訊號理論（Spence，1973）解釋有資訊的一方如何透過有成本的行動，向沒資訊的一方可信地傳達私有資訊。在財務領域，公司透過股利、資本結構、折價發行等機制來傳達品質，這些做法對低品質的公司來說成本太高，模仿不來。

## 何時使用

- 分析公司為什麼在有稅務劣勢的情況下仍發放股利
- 評估 IPO 折價發行是否為品質訊號
- 判斷某項公司行動是否傳達了可信的私有資訊
- 設計機制，把高品質與低品質的發行者區分開來

## 何時不要使用

- 資訊不對稱很小（雙方資訊差不多）
- 純粹的空談溝通（沒有成本的訊號不可信）
- 發訊號的成本超過發訊者得到的好處

## 假設

```
鐵律：訊號「只有」在偽造成本很高時才可信，空談不是訊號。
要達到分離均衡，訊號必須有「差異化成本」：
高品質類型負擔得起，低品質類型則貴到做不起。
```

關鍵假設：
1. 發訊者與收訊者之間存在資訊不對稱
2. 訊號成本與品質呈負相關（單一交叉性質）
3. 收訊者會根據觀察到的訊號，理性地更新信念
4. 均衡可以是分離的（類型可區分）或混同的（類型無法區分）

## 方法

### 步驟 1：找出不對稱與相關方

- 誰是有資訊的一方（發訊者）？他們握有什麼私有資訊？
- 誰是沒資訊的一方（收訊者）？他們要做什麼決策？

### 步驟 2：找出訊號及其成本結構

| 財務訊號 | 發訊者 | 為什麼有成本 |
|-----------------|--------|----------------|
| 股利 | 公司經理人 | 鎖死現金流、有稅務成本 |
| IPO 折價發行 | 發行公司 | 把錢留在桌上 |
| 發行債務 | 公司經理人 | 固定義務、破產風險 |
| 股票買回 | 公司經理人 | 耗用現金準備 |
| 教育（Spence） | 求職者 | 時間、金錢、心力 |

### 步驟 3：評估均衡類型

- **分離均衡：** 高品質類型發訊號，低品質類型不發。收訊者可以區分。
- **混同均衡：** 所有類型採取相同行動。收訊者無法區分。
- 關鍵檢驗：訊號的成本差異夠不夠大，足以維持分離？

### 步驟 4：評估訊號可信度

可信訊號的檢核清單：
- 對發訊者來說有成本嗎？
- 對低品質的發訊者成本更高嗎？
- 收訊者看得到這個訊號嗎？
- 這個訊號很難偽造，或很難低成本複製嗎？

## 輸出格式

```markdown
## 訊號分析：[公司行動 / 情境]

### 資訊結構
- 發訊者：[誰]，握有關於[什麼]的私有資訊
- 收訊者：[誰]，要針對[什麼]做決策

### 訊號評估
| 準則 | 評估 |
|-----------|------------|
| 可觀察？ | [是/否] |
| 有成本？ | [是/否，怎麼說] |
| 有差異化成本？ | [是/否，為什麼] |
| 可信？ | [是/否] |

### 均衡
- 類型：[分離 / 混同 / 半分離]
- 穩定性：[穩固 / 脆弱，為什麼]

### 意涵
- [理性的收訊者應該推論出什麼]
- [給發訊者的策略建議]
```

## 常見陷阱

- 不是每個有成本的行動都是訊號，它必須被收訊者觀察到，而且成本有差異
- 常常存在多重均衡，最後落在哪一個，取決於均衡路徑外的信念
- 就算個別來看是理性的，訊號成本對社會來說仍是無謂損失
- 當競爭把訊號成本推高到超過社會最適水準，就會出現過度訊號
- 實證上很難識別：訊號與品質之間有相關，不代表真的是在發訊號
- 制度環境很重要：強制揭露的法規可以取代有成本的訊號
