# Mixed Methods Research

## Overview

混合方法研究在單一研究或一整組研究計畫中，結合質性與量化取徑，發揮兩者的優勢。它以實用主義為基礎，依哪種方法最適合研究問題來選擇方法。它的決定性特徵不是單純兩種都用，而是在設計、方法或詮釋層級真正把兩者整合起來，產出任何一種取徑單獨都得不到的洞察。

## When to Use

- 單一取徑（只用質性或只用量化）無法充分回答研究問題
- 量化結果需要質性的解釋（為什麼會出現這個效果？）
- 質性發現需要量化的檢驗（這個模式能不能推廣？）
- 複雜的現象需要廣度（量化）和深度（質性）兩種理解

## When NOT to Use

- 研究問題用一種取徑就能完整回答
- 研究者在質性或量化方法上缺乏能力
- 資源（時間、經費、團隊）無法充分支撐兩個部分
- 對這項特定研究，質性與量化的典範假設無法調和

## Assumptions

```
IRON LAW: Mixed methods requires GENUINE INTEGRATION — running qual
and quant in parallel without connecting findings is NOT mixed methods,
it is two separate studies stapled together. Integration must occur at
design, methods, or interpretation level.
```

關鍵假設：
1. 以實用主義作為哲學基礎，對研究問題有用的，就決定方法
2. 質性與量化資料都有正當的知識主張
3. 整合是決定性特徵，不是單純合併，而是連結、融合或嵌入
4. 研究問題驅動設計的選擇，不是方法論上的門派忠誠

## Methodology

### Step 1: Select the Mixed Methods Design

| Design | Structure | Purpose |
|--------|-----------|---------|
| **Convergent** | QUAL + QUANT 同時進行 | 比較並融合發現，以求完整性或驗證 |
| **Explanatory Sequential** | QUANT → qual | 用質性來解釋、闡述或提供量化結果的脈絡 |
| **Exploratory Sequential** | QUAL → quant | 用質性發展量化要檢驗的工具、變數或類型學 |
| **Embedded** | QUANT 內嵌 qual（或反過來） | 在更大的設計中，一個部分支援另一個 |

用大寫表示主導的部分，小寫表示輔助的部分。

### Step 2: Implement Each Strand with Rigor

對每個部分各自套用完整的方法嚴謹度。質性部分遵循質性的品質標準（可信性、可轉移性）。量化部分遵循量化的標準（效度、信度）。不要為了遷就一方而犧牲另一方。

### Step 3: Integrate the Strands

各層級的整合策略：

| Level | Strategy | Example |
|-------|----------|---------|
| **Design** | 把一個部分嵌入另一個 | RCT 裡的質性訪談 |
| **Methods** | 由一個部分建構另一個 | 質性主題變成問卷題項 |
| **Interpretation** | 聯合呈現、融合或敘事編織 | 並列比較表 |

### Step 4: Draw Meta-Inferences

把兩個部分的發現綜合成後設推論，超越任何一個部分單獨能產出的。處理兩個部分之間的收斂、互補或分歧。

## Output Format

```markdown
## Mixed Methods Analysis: [Context]

### Design
- Type: [convergent / explanatory sequential / exploratory sequential / embedded]
- Priority: [QUAL+QUANT / QUANT→qual / QUAL→quant]
- Rationale: [why this design fits the research question]

### Quantitative Strand
- Method: [survey / experiment / secondary data]
- Sample: [N, sampling strategy]
- Key findings: [statistical results]

### Qualitative Strand
- Method: [interviews / focus groups / observations]
- Sample: [N, sampling strategy]
- Key findings: [themes or categories]

### Integration (Joint Display)
| Quantitative Finding | Qualitative Finding | Meta-Inference |
|---------------------|--------------------|--------------------|
| [statistical result] | [theme/quote] | [integrated insight] |

### Convergence Assessment
- Confirmed: [where qual and quant agree]
- Complementary: [where one strand adds to the other]
- Divergent: [where findings conflict — and how resolved]

### Meta-Inferences
1. [Integrated conclusion that neither strand alone could produce]
2. [Integrated conclusion that neither strand alone could produce]
```

## Gotchas

- 聯合呈現表是展示整合的黃金標準，如果你做不出一張，整合可能不存在
- 不要偏重某一個部分，除非設計明確要求（例如以 QUANT 為主的解釋型序列）
- 混合典範需要哲學上的正當理由，實用主義很常見，但不是唯一選項（辯證多元論是另一個）
- 解釋型序列需要先完成 QUANT 階段，才能設計 qual 階段，你不能一開始就把兩者都設計好
- 兩個部分的樣本數不同：量化樣本依檢定力分析，質性樣本依飽和或資訊豐富度
- 審查者常批評「準混合」的研究，也就是兩個部分根本沒有連起來，所以要把整合明確表現出來
