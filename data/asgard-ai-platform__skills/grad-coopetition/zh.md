# Co-opetition：Value Net（Brandenburger & Nalebuff，1996）

## Overview

Co-opetition 認為商業關係從來不是純競爭，也不是純合作。Value Net 模型延伸了 Porter 對競爭對手的關注，加進互補者，也就是那些產品會提高你產品價值的玩家。PARTS 框架（Players、Added value、Rules、Tactics、Scope）提供一套結構化的方法，讓你改變遊戲，而不只是照規則玩。

## When to Use

**觸發條件：**
- 使用者在分析一段同時有合作與競爭的關係
- 使用者問到和競爭對手的策略聯盟
- 使用者需要找出互補者，或描繪價值網路中的所有玩家
- 使用者提到「frenemy」、「coopetition」、「complementors」或「value net」

**When NOT to use：**
- 純競爭分析 -> 用 Porter 五力
- 組織內部的平衡 -> 用 grad-ambidexterity
- 國際市場的進入模式 -> 用 grad-oli

## Assumptions

```
IRON LAW: Every Business Relationship Contains BOTH Cooperative
          and Competitive Elements

There is NO purely competitive or purely cooperative relationship.
A supplier cooperates (provides inputs) AND competes (captures margin).
A competitor competes (takes share) AND cooperates (grows the category).

Any analysis that labels a player as ONLY competitor or ONLY partner
is incomplete. Always map BOTH dimensions.
```

- 商業是一場遊戲，但玩家可以改變遊戲，而不只是玩遊戲
- 創造價值靠合作，取得價值靠競爭
- 同一個玩家可以同時是競爭者和互補者

## Methodology

### Step 1: Map the Value Net

把焦點公司放在中心，標出四種玩家：客戶、供應商、競爭者（其產品會降低你的價值）、互補者（其產品會提高你的價值）。關鍵洞察：一個玩家可以同時扮演多個角色（Samsung 供應顯示器給 Apple，同時也賣競爭的手機）。

### Step 2: Assess Added Value

對每個玩家計算 added value：
- **Added value** = 有該玩家時的遊戲總價值，減去沒有該玩家時的遊戲總價值
- 玩家能取得的價值，絕不會超過他的 added value
- 策略應該以提高你自己的 added value，並管理其他人的 added value 為目標

### Step 3: Apply PARTS Framework

有系統地評估五個改變遊戲的槓桿：

| Lever | Question | Action |
|-------|----------|--------|
| **Players** | 誰在這場遊戲裡？該不該加入或移除玩家？ | 引進新的互補者，吸引新的競爭者來降低供應商的議價力 |
| **Added value** | 怎麼提高我們的 added value？ | 做出差異化、建立轉換成本、培養忠誠客戶 |
| **Rules** | 什麼規則在管這場遊戲？我們能改嗎？ | 契約、法規、產業標準、MFN 條款 |
| **Tactics** | 認知怎麼影響遊戲？ | 訊號傳遞、承諾、透明或製造迷霧 |
| **Scope** | 這場遊戲的邊界在哪？ | 把遊戲串起來或切開，擴大或縮小範圍 |

### Step 4: Design Co-opetition Strategy

針對每個關鍵關係，明確指出：
- 在哪裡合作（創造價值）：共同研發、制定標準、擴張市場
- 在哪裡競爭（取得價值）：定價、獲客、差異化
- 邊界規則：哪些資訊要分享，哪些要保護

## Output Format

```markdown
# Co-opetition Analysis: {Focal Firm}

## Value Net Map
- Customers / Suppliers / Competitors / Complementors: {list each, note dual roles}

## Added Value Assessment
| Player | Added Value | Leverage |
|--------|-------------|----------|
| {Focal firm} | {assessment} | {high/medium/low} |

## PARTS Analysis
| Lever | Current State | Recommended Change |
|-------|---------------|-------------------|
| Players / Added value / Rules / Tactics / Scope | {current} | {action} |

## Co-opetition Strategy
- Cooperate on: {activities} | Compete on: {activities} | Boundary rules: {policy}
```

## Gotchas

- **找出互補者最難**：逼自己問：「誰的產品讓我的產品更有價值？」最大的洞察都藏在這裡。
- **雙重角色會產生張力**：當夥伴同時也是競爭者，要明確定義資訊邊界。
- **Added value 是動態的**：每個重大動作都會改變所有人的 added value。產品上市或進入新市場後要重新評估。
- **沒有邊界的合作會造成知識外洩**：聯盟需要明確的 IP 防火牆。
- **PARTS 的重點是改變遊戲**：如果你的分析只描述了目前的遊戲，就是沒抓到重點。
