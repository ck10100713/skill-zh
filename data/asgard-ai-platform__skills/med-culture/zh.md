# 文化藝術報導

> **這個 skill 是 med-news-reporter 在藝文線上的專門化版本。** 請先讀 med-news-reporter，了解一般的 6 步驟工作流程（類型選擇、素材稽核、事實查核、平衡、倫理、識讀）。這份檔案在它之上，加上**文化線專屬的紀律**：文化挪用意識、原住民族知識保護、機構 vs. 獨立來源的標記、審美判斷的透明度，以及跨文化翻譯的陷阱。

## 概述

整理自哥倫比亞大學（Arts & Culture Concentration）、紐約大學新聞系、政大文化人類學、台大人類學系、台藝大文化政策所的文化新聞課程。涵蓋主要的文化新聞子類型：**展覽/博物館報導、表演藝術評論、藝術家側寫、文化政策/文化資產，以及藝術市場報導。**

```
鐵律：評論是被標記的意見，不是事實

審美判斷，例如「這幅畫很有力量」、「舞者不夠精準」、
「這件作品突破了界線」，是與某個批評框架綁在一起的意見。
它們一定要：(a) 標記為判斷，「不可」框架成事實；
(b) 歸屬於具名的評論家 / 思想流派 / 機構聲音，並揭露其立場；
(c) 以推理或可觀察的細節支撐，不能只是空口斷言。
事實報導（藝術家 X 於 Z 日在場館 Y 展出，媒材為 M）
可以與審美評價分開。預設的 LLM 行為會透過描述性形容詞
把兩者混在一起，讓判斷夾帶進「事實」裡
（「才華洋溢的新銳藝術家」、「令人失望的回顧展」）。
要明確地推翻這個預設：拿掉形容詞，或標明歸屬。

為什麼這件事不明顯：「才華洋溢」讀起來像是描述藝術作品
很自然的說法，不像意見。但它就是意見。讀者應該知道，
「才華洋溢」是 (i) 藝術家所屬機構的直接引述、
(ii) 立場明確的具名藝術史學者的觀察，還是
(iii) 寫作者自己假設出來的共識。
```

為什麼這件事不明顯：審美判斷會很自然地流進文字裡。一篇關於新展覽的報導，很自然會引來形容詞；預設寫成「有力量」或「引人注目」，就默默背書了一種未必普遍的解讀。可信的評論家會事先標明自己的立場。

**合理化對照表：這些辯解「不能」推翻鐵律：**

| Claude 可能會想…… | 為什麼仍然違規 |
|---|---|
| 「藝術家的藝廊稱這件作品『開創性』，所以我就用」 | 就算是機構說的，仍然是意見。要標記：「該藝廊稱該作『突破性』」，不是「突破性作品」。 |
| 「美術館網站寫『創新』，那是公開資訊」 | 機構的描述 ≠ 事實。要分開：「美術館將這項展覽描述為 X；藝評人則對 Y 有爭論。」 |
| 「『源自於』只是在描述影響，不是在評斷」 | 影響的歸因是一種批評性的主張。被點名的藝術家同意嗎？他們自己有提過這個影響，還是這是藝術史的詮釋？要講清楚。 |
| 「評論家一致讚揚這位藝術家，所以『廣受好評』是事實」 | 「一致讚揚」是誇大，抹平了批評的多元性。就算屬實，也要說：「多位評論家讚揚……」並附上姓名/來源。 |
| 「這件作品未能吸引觀眾」 | 描述可觀察的事實：「觀眾中途離場」、「參觀人數偏低」，不是詮釋。如果你推論出一個判斷，要註明是誰的詮釋。 |
| 「我只是在轉譯原作的意圖」 | 轉譯藝術意圖是詮釋，不是事實。就算有藝術家自己的說明，也要註明：「藝術家陳述的意圖是 X；評論家詮釋為 Y。」 |

## 何時使用

**觸發條件：**
- 使用者提供文化/藝術素材（展覽新聞、演出評論、藝術家訪談、文化政策、美術館新聞稿、評論草稿、演出影片節摘錄、文物借展公告），並要求寫成新聞/評論稿。
- 使用者要求「展覽報導」、「演出評論」、「藝術評論」、「藝廊側寫」、「文化政策追蹤」、「美術館專題」、「整理展覽新聞」、「寫一篇評論」、「藝術家專訪」、「評論展覽」。
- 使用者換句話說：「幫我把這份策展自述寫成報導」、「寫一篇關於 X 美術館的新聞」、「整理成一篇演出評論」、「draft a piece on this artist opening」、「turn this interview into a profile」。

**輸入訊號：**
- 有名字的藝術家、藝廊、美術館、文化機構、展覽名稱、作品名稱、演出場地、日期。
- 策展論述、藝術家訪談、評論家的評論、機構公關稿、參觀人數、文化政策文件。
- 來自藝術家、策展人、收藏家、評論家的直接引述。

**何時不要使用：**
- 以機構自己的口吻撰寫的藝廊/藝術家/美術館新聞稿 → 改用 `pr-press-release`。
- 藝術市場的價格預測或投資建議 → 改用 `fin-*`，或婉拒。
- 展覽或藝術商品的行銷文案 → 改用 `mkt-*.`
- 純粹的娛樂產業新聞（名人、頒獎典禮） → 改用 `med-entertainment`。

## 方法

### 步驟 0：一般的工作流程交給 med-news-reporter

請讀過或已載入 `med-news-reporter`，處理：素材稽核、事實查核、消息來源強度標記、平衡原則、媒體倫理檢查、媒體識讀自我檢核。**不要在這裡重新實作這些步驟。** 這份檔案專門處理步驟 1、2、3，並新增文化專屬的步驟 7（審美判斷稽核 + 跨文化敏感度稽核）。

### 步驟 1：分類文化報導的子類型

| 子類型 | 訊號 | 子範本重點 |
|----------|---------|--------------------|
| **展覽/博物館** | 開幕日期、場館、藝術家/策展人姓名、作品、主題 | 策展意圖與作品描述，與評價分開；來源標記（公關 vs. 獨立評論） |
| **演出評論** | 場館、團隊、表演者、日期、類型（劇場/音樂/舞蹈）、參加人數 | 審美判斷綁定具名的評論家或評論刊物；先描述細節，再評價 |
| **藝術家側寫** | 藝術家生平、背景、主要作品、近期展覽/駐村 | 以公開紀錄呈現職涯軌跡；引述標明出處；除非有引用，避免「新星」 |
| **文化政策/文化資產** | 文化部政策、文資法、世界遺產、古蹟保存、文化補助機制 | 政策文字 + 利害關係人的影響 + 納入原住民/少數族群的聲音；法律/行政上的準確 |
| **藝術市場** | 拍賣、藝術基金、畫廊銷售、藝術家身價、收藏趨勢 | 價格 ≠ 藝術品質（把事實與市場訊號分開）；利益衝突揭露（拍賣行估價人、經紀人的持股） |

如果素材橫跨多個子類型（例如藝術家的第一場大型美術館個展），依照*主要的新聞驅動力*分類。

### 步驟 2：來源審查與機構聲音標記

**每個被引述的文化機構，在第一次提到時，都必須標記其公關利益傾向：**

- ❌ 含糊：「該美術館表示...」
- ✅ 具體：「國立故宮博物院策展部主任王大明表示...」
- ✅ 當公關利益有關時：「舉辦單位 / 參展藝廊林小華表示...」（表示機構有宣傳上的利益）
- ✅ 當獨立時：「獨立評論家 / 藝評人 王大明表示...」或「ArtForum 評論員表示...」

**來源層級標記**（擴充 med-news-reporter 的層級，加入文化專屬的層級）：

| 層級 | 範例 | 處理方式 |
|------|----------|-----------|
| **公開紀錄 / 官方文件** | 文化部施政報告、世界遺產名單、古蹟登錄公告、展覽官方新聞稿 | 直接引用；註明來源是機構。 |
| **策展/藝術家陳述（具名）** | 策展人訪談、藝術家自述、美術館展覽說明頁面 | 附上角色標記的直接引述；註明：這是機構的框架，不是獨立的觀點。 |
| **獨立評論家/評論者** | 藝評人刊登於獨立媒體之評論、學者論文、展評 | 直接引述；附上刊物/資歷，讓讀者校準其立場。 |
| **收藏家 / 經紀人** | 拍賣公司、畫廊、私人收藏家 | 引述時揭露利益：「Sotheby's 估價為 [價格]」表示拍賣行在高估值上有利益。 |
| **觀眾/社群** | 參觀者的意見、原住民/少數族群社群對文化資產的觀點 | 納入這些聲音，尤其是在討論文化挪用、原住民族知識或社群衝擊時。 |

### 步驟 3：文化專屬的風險檢查

除了 med-news-reporter 的一般倫理檢查之外，再加上：

1. **文化挪用 (Cultural Appropriation) 稽核**：
   - 如果報導的是跨文化的藝術作品（西方藝術家描繪東亞意象等）：報導有沒有納入來源文化 / 原生社群的觀點？還是只有外人的框架？
   - 報導應該標明：「受西方評論家讚賞其美學創新」vs.「受東亞藝術家團體批評，未經致謝就挪用」。
   - 如果某項實踐是神聖的（宗教儀式、部落傳統），報導是把它框架成「外部觀察」，還是隱含地當成常識？要標明這個框架。

2. **原住民族傳統智慧創作保護條例 (Indigenous IP Protection)**：
   - 報導原住民族的藝術、文化符號、神話或音樂時：確認使用是否需要部落同意。
   - 報導中避免把原住民族知識當成「公共領域」。如果作品取樣了原住民族的符號，要查證藝術家是否取得同意並給予署名。

3. **著作權與合理使用 (Copyright & Fair Use in Arts Criticism)**：
   - 引用詩、歌詞、作品描述時：查閱 `references/ethics_and_law.md` 的合理使用門檻。
   - 在評論中引用整首詩 = 侵害著作權。節錄 + 標明出處 = 合理使用。

4. **肖像權與肖像/攝影中的隱私**：
   - 如果作品描繪的是可辨識的人：必要時加上同意 / 隱私的免責聲明。
   - 如果藝術家受訪時表達私人看法：尊重不具名的訊號（off-record）。

5. **拍賣 / 估價的利益揭露**：
   - 引用作品估值或市場價格時：說明是誰估價/鑑價，以及他們的財務利益。
   - 「Sotheby's 估計該作品價值新台幣 500 萬元」≠「該作品價值新台幣 500 萬元」。前者是事實（帶有金錢利益的拍賣行預測）；後者是偽裝成事實的意見。

### 步驟 4：審美判斷稽核（文化專屬的新增項目）

輸出之前，掃過草稿，檢查：

1. **判斷形容詞稽核**：標出每一個審美主張（「有力量」、「細膩」、「缺乏原創」、「創新」、「縈繞心頭」）。對每一個：換成 (a) 可觀察的細節，或 (b) 歸屬於具名的評論家 / 刊物 / 流派，並揭露其立場，或 (c) 沒有依據就刪掉。
2. **策展 vs. 獨立的框架**：這篇報導是否主要仰賴美術館/藝廊自己對展覽的描述？如果是，要明確標示（「美術館將這項展覽描述為……」），並加入獨立評論家的觀點來平衡。
3. **價格與價值的滑移**：檢查有沒有「作品以新台幣 1,000 萬元成交，證明其重要性」這類說法（把市場訊號與藝術判斷混為一談）。把它們分開：「以新台幣 1,000 萬元成交（市場訊號）」vs.「評論家認為其重要性在於 X」（判斷）。
4. **翻譯損失的揭露**：如果評論的是翻譯過的作品（戲劇、詩、歌劇劇本），註明原文可能帶有翻譯時流失的層次。例如：「對白中原本的台語雙關語，無法翻成英文。」
5. **納入少數/原住民族的聲音**：在文化資產、挪用或社群文化衝擊的報導中，報導是否納入受影響社群的聲音，還是只有機構/專家的聲音？沒有的話要標出來。

### 步驟 5：跨文化敏感度與框架稽核

1. **內部 vs. 外部的框架**：描述宗教儀式、原住民族典禮或少數族群的文化實踐時，報導有沒有標記觀察者是內部人還是外部人？例如：「根據民族誌學者的觀察……」vs.「從社群內部來看……」，意味著不同的認識論位置。
2. **本質化檢查**：避免「X 文化本質上就是 Y」的框架。改成：「在 X 社群的 Y 傳統脈絡中，這項實踐意味著 Z」（具體的，不是普遍的）。
3. **政治敏感度（中國/台灣/香港的用詞）**：討論作品出處或藝術家國籍時，使用精確的用詞。「台灣製造」≠「中國藝術家」≠「香港當代」。查證藝術家/作品如何自我認同。
4. **譯者/口譯者的署名**：如果作品標題或藝術家陳述是非英語的語言，要附上譯者的姓名。翻譯是詮釋，讀者應該知道是誰詮釋的。

## 常見陷阱

- **「機構聲音」和「評論」不能混為一談**: 美術館的展覽說明頁面、策展自述都有推廣展覽的利益。獨立評論家的批評角度可能很不同。不要讓讀者以為策展人的「大膽創新」 vs 評論家的「形式疲軟」是同一種聲音。前者標註為機構立場,後者標註為獨立評論。
- **「票房好」≠「藝術優秀」;「拍賣價高」≠「大師傑作」**: 商業成功是市場訊號,不是藝術判準。一篇報導若寫「該藝術家因作品拍賣創高價成為新興大師」,實際上混淆了。應寫「作品在拍賣會達 X 價格,業界視為市場認可;藝評人對其藝術貢獻的評估則不一」。
- **評論寫作的「事實基礎」**: 說「畫面色彩大膽」需要能指出「怎樣的色彩配置」(可驗證的觀察);說「表演力度不足」需要能說「與同場演員的對比」或「與該演員其他演出的對比」(comparative fact)。光說評價不說依據,讀者無法判讀你的品味是否值得採納。
- **翻譯作品評論須註明**: 評論一齣外文劇本、一首譯詩、一本譯作時,至少要說「根據 X 譯者的譯本」。不同譯者的詮釋差很大;讀者該知道你評的是哪個版本。
- **文化挪用辨識不易,但框架要誠實**: 「西方藝術家詮釋東亞文化」不自動等於挪用,也不自動等於無罪。應報導:該社群怎麼看?藝術家有無致謝 / 協作?評論家怎麼爭論?不要預設立場,要呈現爭議的樣貌。
- **原住民族相關報導時,應主動求聲音**: 涉及原民文化藝術、傳統工藝、文化資產時,報導中應包含部落 / 社群的視角,不要只引學者 / 官方。其聲音的缺席本身就是個信號。

## 限制

- **不執行即時的機構事實查證**：這個 skill 會標出需要查證的主張，例如美術館開放時間、展覽日期或策展人資歷；它不會檢查即時的美術館網站或機構資料庫。編輯必須自行查證，或由使用者提供最新資訊。
- **不裁定文化挪用**：這個 skill 會標出文章缺少來源文化的聲音或適當框架的情況；它不會對某件事是否構成挪用做出最終判斷。那個判斷屬於受影響的社群與有見識的評論家，這個 skill 只確保報導納入他們的觀點。
- **跨文化的詮釋本質上有爭議**：描述來自另一種文化的藝術作品，一定涉及詮釋。這個 skill 要求明確的框架（內部/外部視角），但無法消除根本的認識論挑戰。
- **翻譯中流失的原文**：評論翻譯作品時，這個 skill 會標出這個問題，但無法解決它。要完整處理翻譯損失，需要原文，或明確地諮詢學者/譯者。
- **價格資料有時效性**：藝術品的估值與拍賣估價會變動。一定要對照目前的市場資料查證，不要把歷史價格當成現在的事實。
