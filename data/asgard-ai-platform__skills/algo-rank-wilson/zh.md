# Wilson Score 排名

## 概述

Wilson Score 區間給出「真實正面評價比例」的信賴下界。和簡單平均不同，它會懲罰評分數少的項目，避免只有 1 則 5/5 評論的項目，排在有 1000 則評論、4.8/5 的項目前面。每個項目的計算是 O(1)。

## 何時使用

**觸發條件：**
- 評論數差異很大時，依使用者評分替項目排名
- 建立對評論多的項目公平的「最高評分」或「best of」榜單
- 用信賴度來排序二元回饋（讚／倒讚）

**何時不要用：**
- 連續型分數（改用貝氏平均）
- 比較樣本數差不多的項目時（簡單平均就夠了）

## 演算法

```
鐵律：樣本數不同時，絕對不要用簡單平均排名
1 則評論的 5.0 平均，並不比 1000 則評論的 4.8 好。
Wilson Score 的下界把樣本的不確定性算進去了：
評分少的項目會得到「較低」的下界，
正確反映我們對它真實品質的不確定。
```

### 階段 1：輸入驗證
每個項目要蒐集：正面評分數（p）、總評分數（n）。星等評分要轉成二元（例如 4-5 星 = 正面）。
**關卡：** 所有項目 n > 0、已選定信賴水準（通常是 95%，z=1.96）。

### 階段 2：核心演算法
1. 計算觀察到的比例：p̂ = positive / total
2. Wilson 下界：(p̂ + z²/2n - z × √(p̂(1-p̂)/n + z²/4n²)) / (1 + z²/n)
3. 依 Wilson 下界由高到低排名（對真實品質的保守估計）

### 階段 3：驗證
檢查：正面評論多的項目，要排在比例相同但評論少的項目前面。評論非常少的項目有被適度懲罰。
**關卡：** 人工檢視排名符合直覺。

### 階段 4：輸出
回傳排好名的項目，附上分數和信賴區間。

## 輸出格式

```json
{
  "rankings": [{"item": "Product_A", "wilson_lower": 0.89, "positive": 950, "total": 1000, "proportion": 0.95}],
  "metadata": {"confidence": 0.95, "z": 1.96, "items_ranked": 500}
}
```

## 範例

### 輸入輸出範例
**輸入：** 項目 A：1 正面 / 共 1（100%）。項目 B：950 正面 / 共 1000（95%）。
**預期：** B 排名較高。Wilson 下界：A ≈ 0.05、B ≈ 0.94。單一一則評論幾乎給不了任何信心。

### 邊界情況
| 輸入 | 預期 | 原因 |
|-------|----------|-----|
| 0 則評論 | 無法排名 | n=0，沒有定義。排除或給最低分 |
| 0 正面，共 100 | 分數非常低 | 真的是爛項目，信心很高 |
| 100 萬正面，共 100 萬 | 下界 ≈ 1.0 | 樣本龐大，對 100% 的信心很高 |

## 常見陷阱

- **二元轉換**：5 星評分的話，正面／負面的門檻很重要。4 星以上算正面？還是 3 星以上？不同門檻會產生不同排名。
- **不適用連續資料**：Wilson Score 是給比例（二元結果）用的。連續評分要用帶先驗的貝氏平均。
- **冷啟動**：沒有評論的新項目沒辦法排名。可以設最低評論數門檻，或用貝氏平滑。
- **信賴水準的選擇**：信賴度越高（99%），對小樣本的懲罰越重。95% 是標準，但要依你的使用情境調整。
- **依下界排序是保守的**：這個做法偏袒知名項目。如果是為了探索發現，可以考慮也提升上界高的項目（潛在的遺珠）。
