# 史料考證

## 概述

史料考證是一套系統性的方法，用來評估資訊是否可信。它原本來自歷史學方法論，如今在這個充斥假訊息、把意見當事實、以及 AI 生成內容的資訊環境中，已是不可或缺的能力。

## 框架

```
鐵律：沒有任何來源是自動可信的

每個來源，包括學術期刊、政府資料與信譽良好的媒體新聞，
都可能有偏見、錯誤與限制。可信度是被評估出來的，
不是被預設的。「這是《紐約時報》/ 中央社的報導」並不夠，
他們在報導「什麼」？依據「什麼」證據？其他來源有沒有佐證？
```

### 來源分類

**一手來源**：來自當時/事件的直接證據（原始文件、原始資料、目擊者的說法、原創研究、官方紀錄）

**二手來源**：對一手來源的分析或詮釋（教科書、回顧性文章、新聞分析、傳記）

**三手來源**：對一手與二手來源的彙編（百科全書、Wikipedia、資料庫），是起點，不是終點

### 來源可信度的四項檢驗

**1. 外部考證**：來源是真的嗎？
- 誰創作的？他們是他們自稱的那個人嗎？
- 什麼時候創作的？日期前後一致嗎？
- 這是原件，還是被改動過？
- 發表的刊物/平台信譽良好嗎？

**2. 內部考證**：內容可靠嗎？
- 作者在這個主題上有專業嗎？
- 作者可能有什麼偏見或利益？
- 有沒有引用證據？能不能查證？
- 推理合乎邏輯嗎？結論有證據支持嗎？

**3. 三角驗證**：多個獨立的來源是否一致？
- 檢查 3 個以上獨立的來源（不是同一份原始報導的複本）
- 「獨立」是指不同的作者、不同的組織、不同的方法
- 獨立來源之間的一致，會增強信心

**4. 時效性**：資訊夠新嗎？
- 什麼時候發表的？之後情況有沒有改變？
- 對於變化快速的主題（AI、政策、市場），連 6 個月前的來源都可能過時

### 假訊息的警訊

| 警訊 | 說明 |
|----------|-----------|
| 沒有標明作者或組織 | 誰在為這個主張背書？ |
| 有情緒性語言卻沒有證據 | 目的是挑起情緒，不是提供資訊 |
| 沒有引用一手來源 | 主張沒有可追溯的證據 |
| 「研究顯示」卻沒說是哪項研究 | 含糊地訴諸權威 |
| 單一來源在許多網站上被放大 | 同一個主張被複製，而不是獨立查證 |
| 好得不像真的 / 太離譜 | 極端的主張需要極端的證據 |
| 網址/網域模仿有信譽的來源 | Fakecnn.com、bbc-news.co（不是 bbc.co.uk） |

## 輸出格式

```markdown
# 來源評估：{來源/主張}

## 來源身分
- 作者/組織：{誰}
- 刊物：{哪裡}
- 日期：{何時}
- 類型：一手 / 二手 / 三手

## 可信度評估
| 檢驗 | 評估 | 證據 |
|------|-----------|---------|
| 外部（真實嗎？） | ✓/⚠/✗ | {推理} |
| 內部（可靠嗎？） | ✓/⚠/✗ | {推理} |
| 三角驗證（有佐證嗎？） | ✓/⚠/✗ | {查過的其他來源} |
| 時效性（夠新嗎？） | ✓/⚠/✗ | {日期的相關性} |

## 警訊
- {偵測到的任何警訊}

## 結論
- 可信度：高 / 中 / 低
- 建議行動：{信任 / 進一步查證 / 捨棄}
```

## 範例

### 正確的應用
**情境：** 評估一則瘋傳的社群貼文，宣稱「台灣的 GDP 將在 2027 年超越南韓」

| 檢驗 | 評估 | 證據 |
|------|-----------|---------|
| 外部 | ⚠ | 匿名帳號、沒有機構隸屬、圖表沒有資料來源 |
| 內部 | ✗ | 用的是名目 GDP（不是購買力平價）、只挑半導體產業的預測、忽略匯率波動 |
| 三角驗證 | ✗ | IMF 與世界銀行的預測都沒有顯示這樣的趨近，沒有任何有信譽的分析師做出這個主張 |
| 時效性 | ✓ | 本月發布 |

**警訊**：情緒化的標題（「台灣碾壓南韓」）、沒有引用一手資料來源、只有一張沒有出處的圖表
**結論**：可信度低，捨棄 ✓

### 不正確的應用
- 「這是路透社的，所以一定是真的」 → 可信度是被預設的，不是被評估的。就算是有信譽的來源，也可能出錯、過時，或用特定方式框架議題。違反鐵律。

## 常見陷阱

- **有偏見 ≠ 不可靠：** 每個來源都有立場。工會關於工作條件的報告有偏見，但可能包含準確的資料。偏見與準確度要分開評估。
- **Wikipedia 是起點：** 它是附有參考資料的三手來源。順著參考資料找到一手/二手來源。不要把 Wikipedia 當成證據來引用，要引用 Wikipedia 所引用的東西。
- **AI 生成的內容：** AI 可以產生有說服力、卻是捏造的「來源」（假論文、假引述、假統計）。要確認引用的來源真的存在。
- **共識 ≠ 真理，但是強烈的訊號：** 科學共識（氣候變遷、疫苗安全）是目前能取得的最強證據。與共識相左的孤立「專家」，需要非比尋常的證據。
- **來源的可信度取決於領域：** 心臟科醫師在心臟疾病上是可信的來源，在經濟學上則不是。要讓專業與主張相符。
