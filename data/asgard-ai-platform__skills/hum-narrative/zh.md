# 敘事與說故事

## 概述

故事是人類最自然的溝通形式。敘事結構讓資訊有情感上的份量、好記、有意義。這個 skill 把說故事的原則套用到商業情境：品牌故事、簡報、提案與變革溝通。

## 框架

```
鐵律：每個故事都需要張力

沒有衝突或張力的敘事，是報告，不是故事。張力可以是
待解決的問題、現況與理想狀態之間的落差，或是要克服的障礙。
沒有張力，觀眾就沒有理由繼續聽下去。
```

### 故事弧線（通用結構）

1. **鋪陳**（現狀）：建立世界、角色與正常狀態
2. **觸發**（引爆事件）：有什麼打破了現狀，可能是問題、機會或發現
3. **上升動作**（掙扎）：嘗試處理這個破壞，遇到障礙
4. **高潮**（轉折點）：決定性的時刻，可能是突破、決定或揭露
5. **結局**：新的局面，什麼改變了、學到了什麼

### 品牌故事框架

| 要素 | 問題 | 範例 |
|---------|---------|---------|
| **創立神話** | 這家公司為什麼存在？ | 「我們創立的原因，是因為我們找不到 X……」 |
| **敵人** | 你在對抗什麼不對的事？ | 「這個產業把客戶當成數字」 |
| **任務** | 你想達成什麼？ | 「我們的使命是讓每個人都能取得 X」 |
| **價值觀** | 什麼原則在指引你？ | 「我們相信透明、簡單，以及……」 |
| **轉變** | 你創造了什麼改變？ | 「我們的客戶從為 X 所苦，變成在 Y 上蓬勃發展」 |

### 商業情境中的說故事

**簡報**：用一個故事開場（Pathos），再轉到資料（Logos）。「讓我跟你們說說一位客戶……」→「而她並不孤單，這是資料。」

**募資簡報（Pitch deck）**：問題（張力）→ 解決方案（你的產品）→ 成果（證明故事正在奏效）→ 願景（故事怎麼收尾）

**變革溝通**：現狀（熟悉的）→ 為什麼需要改變（張力）→ 未來狀態的願景（結局）→ 我們怎麼到那裡（計畫）

**資料說故事**：不要只秀圖表。要加上框架：「我們原本預期 X 會發生。結果發生的是 Y。原因是這樣，意義是這樣。」

## 輸出格式

```markdown
# 敘事設計：{情境}

## 故事弧線
1. **鋪陳**：{現狀}
2. **觸發**：{什麼打破了它}
3. **掙扎**：{面對的挑戰}
4. **高潮**：{轉折點}
5. **結局**：{新的狀態}

## 關鍵要素
- 張力：{核心衝突}
- 角色：{觀眾認同的對象}
- 賭注：{如果張力沒被化解會怎樣}
- 轉變：{什麼改變了}

## 應用
{如何把這個敘事融入具體的溝通情境}
```

## 範例

### 正確的應用
**情境：** 一家台灣永續包裝新創的品牌故事
- **鋪陳**：「台灣每年產生 840 萬公噸的廢棄物。大多數包裝只用一次就丟掉。」
- **觸發**：「我們的創辦人在包裝工廠工作，每週都看著一卡車一卡車的塑膠膜直接送進掩埋場。」
- **掙扎**：「我們花了 2 年、失敗了 47 個原型，想做出跟塑膠一樣耐用的甘蔗基包裝。」
- **高潮**：「第 48 號原型成功了。一樣耐用，90 天內可完全堆肥。」
- **結局**：「現在台灣有 200 多個食品品牌使用我們的包裝。我們已經讓 500 公噸的廢棄物不必進掩埋場。」
- **張力清楚，角色讓人有共鳴，賭注是具體的** ✓

### 不正確的應用
- 「我們公司成立於 2019 年。我們賣永續包裝。我們的營收是新台幣 5,000 萬元。」 → 只有事實，沒有敘事結構。沒有張力、沒有角色、沒有弧線。這是報告，不是故事。違反鐵律。

## 常見陷阱

- **客戶才是英雄，不是你：** 在品牌說故事中，客戶應該是主角，在你的幫助下克服挑戰。你的品牌是嚮導（導師），不是英雄。
- **真實 > 戲劇性：** 誇大的故事一旦被發現就會反噬。用真實的故事、真實的資料、真實的人。
- **各文化的敘事規範不同：** 西方的敘事偏好個人英雄與線性弧線。東亞的敘事可能更強調集體努力與循環模式。要配合文化脈絡。
- **不要把所有東西都硬塞進故事裡：** 有些資訊用事實、表格或清單來傳達比較好。把敘事用在情感框架上，不是每個資料點。
- **故事長度必須配合情境：** 電梯簡報 = 30 秒的故事。主題演講 = 15 分鐘的故事。年報 = 多章節的故事。依格式調整細節。
