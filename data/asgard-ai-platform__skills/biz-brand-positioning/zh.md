# 品牌定位（Brand Positioning）

## 概述

品牌定位定義的是，品牌相對於競爭對手，在目標顧客心中占據的獨特位置。它結合定位宣言（文字）、認知地圖（視覺）和品牌個性（情感）。定位是 STP（鎖定誰）和執行（怎麼傳達）之間的橋樑。

## 何時使用

**觸發條件：**
- 使用者在建立或更新品牌識別
- 使用者需要和競爭對手做出差異化
- 使用者問「我們有什麼不一樣？」或「顧客怎麼看我們？」
- 使用者的品牌感覺大眾化或沒有焦點

**何時不要用：**
- 市場區隔 → 先用 STP（定位在鎖定目標之後）
- 戰術性的行銷組合 → 用 4P/7P
- 產品功能決策 → 用價值主張圖（Value Proposition Canvas）或 JTBD

## 框架

```
鐵律：定位在顧客的心裡，不在你的型錄上

定位講的是「感知」，不是現實。你沒辦法決定自己的位置，
是顧客決定的。你可以透過一致的訊號去影響它，
但最終的檢驗是：「顧客想到 [品類] 的時候，會想到我們嗎？」

定位宣言是一個「目標」，要透過顧客研究，
驗證它和實際的感知相符。
```

```
鐵律：一個品牌只有一個定位

一個品牌不能同時占據兩個位置。「我們最便宜，而且最高端」
不是定位，是混亂。如果你需要用不同的定位服務不同的客群，
就用不同的品牌或子品牌。
```

### 步驟 1：定義競爭框架

在定位之前，先釐清：
- **品類**：顧客把你歸在哪個品類？
- **競爭集合**：你被拿來和誰比較？（可能和你以為的競爭對手不同）
- **目標客群**：來自 STP，你要定位在誰的心裡？

### 步驟 2：撰寫定位宣言

用這個範本：

```
對於 [目標客群]，
[品牌] 是 [品類／競爭框架]
中 [差異點，也就是讓你與眾不同的「唯一」一件事]，
因為 [可信的理由，也就是你能做到的證明]。
```

規則：
- 一個差異點，不是一串清單
- 差異點（POD）必須和目標相關，而且和競爭對手不同
- 可信的理由必須可驗證，不能只是嚮往

### 步驟 3：建立認知地圖

把你的品牌和競爭對手畫在二維地圖上：
- **選兩條軸**，要對目標客群最重要（例如價格 vs 品質、便利 vs 客製化）
- **畫出**競爭集合中的所有品牌，依據顧客的感知（不是你內部的看法）
- **找出空白地帶**：沒有任何品牌占據的缺口

### 步驟 4：定義品牌個性

用 Aaker 框架挑選 3-5 個個性特質：

| 構面 | 特質 |
|-----------|--------|
| **真誠（Sincerity）** | 腳踏實地、誠實、健康、開朗 |
| **刺激（Excitement）** | 大膽、有活力、富想像力、跟得上潮流 |
| **能力（Competence）** | 可靠、聰明、成功 |
| **精緻（Sophistication）** | 上流、迷人、優雅 |
| **粗獷（Ruggedness）** | 戶外、堅韌、強壯 |

### 步驟 5：找出品牌原型（選填）

把品牌對應到榮格的 12 種原型之一：
- 英雄、亡命之徒、魔法師、純真者、探險家、智者、創造者、統治者、照顧者、小丑、愛人、凡人

原型會引導語氣、視覺識別和說故事的方式。

## 輸出格式

```markdown
# 品牌定位：{品牌}

## 競爭框架
- 品類：...
- 競爭集合：{列出競爭對手}
- 目標客群：{來自 STP}

## 定位宣言
對於 {目標}，{品牌} 是 {品類} 中 {POD}，因為 {RTB}。

## 認知地圖
| 品牌 | 軸 1（{屬性}） | 軸 2（{屬性}） |
|-------|---------------------|---------------------|
| 我們的品牌 | 高/中/低 | 高/中/低 |
| 競爭者 A | ... | ... |
| 競爭者 B | ... | ... |

**找到的空白地帶**：{缺口描述}

## 品牌個性
- 特質：{3-5 個特質}
- Aaker 構面：{主要構面}
- 原型：{原型名稱}
- 語氣：{描述}

## 定位驗證
- 與目標的相關性：✓/✗
- 與競爭對手的差異化：✓/✗
- 可信度／可兌現性：✓/✗
```

## 範例

### 正確的應用

**情境：** 一個台灣精釀啤酒品牌的定位

**宣言**：「對於追求獨特飲酒體驗、愛冒險的 25-40 歲都會上班族，島嶼啤酒是歌頌在地食材（龍眼蜜、烏龍茶、荔枝）的台灣精釀啤酒，因為我們在台北的啤酒廠，只用來自台灣的植物原料小批量釀造。」

**認知地圖**（價格 vs 在地識別）：
| 品牌 | 價格 | 在地識別 |
|-------|-------|---------------|
| 島嶼啤酒 | 高 | 非常高 |
| 台灣啤酒 | 低 | 中 |
| Kirin / Asahi | 中 | 低（進口） |
| Jim & Dad's | 高 | 中 |

**品牌個性**：刺激（富想像力、有活力）+ 真誠（健康）。原型：探險家。

### 錯誤的應用

**哪裡出錯：**
- 「我們定位成高端、平價又方便」→ 三個差異點 = 沒有明確的定位。違反鐵律：一個品牌只有一個定位。
- 定位宣言是依據執行長的願景，沒有做顧客研究 → 定位是感知，不是意圖。違反鐵律：定位在顧客的心裡。

## 常見陷阱

- **定位 ≠ 標語**：標語是定位的創意表達，不是定位本身。「Just Do It」是標語；Nike 的定位是「對於認真的運動員，Nike 是啟發競爭卓越的表現型品牌，因為有世界級運動員代言和創新的產品技術。」
- **認知地圖的軸線影響極大**：軸線選錯 = 地圖誤導。要從顧客研究中選軸線（顧客實際上用哪些面向做比較？），不要用內部指標。
- **重新定位很昂貴**：改變已建立的定位，需要大量投資和多年的一致性。可以的話，一開始就做對。
- **品牌個性必須在所有接觸點保持一致**：如果你的個性是「刺激又大膽」，但網站看起來像銀行的，就有落差。
- **品類的選擇會塑造競爭**：定義你的品類，就定義了你的競爭對手。「健康點心棒」要和 KIND、Clif 競爭。「代餐」則要和 Soylent、Huel 競爭。同樣的產品，不同的品類，不同的定位。
