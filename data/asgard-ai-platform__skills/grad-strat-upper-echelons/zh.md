# 高階梯隊理論

## 概述

高階梯隊理論（Hambrick & Mason，1984）提出，組織的成果（策略選擇與績效）有一部分可以由高階管理團隊（TMT）的特徵來預測。高階主管面對的是複雜、模糊的情境，他們會透過自己的經歷、價值觀與個性這層濾鏡來詮釋。可觀察的人口統計特徵，則被當作這些認知基礎的代理指標。

## 何時使用

- 分析 TMT 的組成如何影響策略方向
- 從高階主管的背景輪廓預測策略行為
- 評估董事會/TMT 的多元性對決策品質的影響
- 評估 CEO 接班對組織策略的衝擊

## 假設

```
鐵律：只有在管理裁量權很高的時候，管理者特徵才能預測策略成果。
在高度管制的產業或受限的環境中，高階主管的特徵會被環境決定論蓋過。
在把成果歸因於 TMT 輪廓之前，一定要先評估裁量權。
```

關鍵假設：
1. 策略決策複雜又模糊，不是完全理性的
2. 高階主管透過個人的認知濾鏡來詮釋情境
3. 可觀察的人口統計特徵（年齡、任期、教育、職能背景）可作為認知基礎的代理指標
4. TMT 這個整體很重要，不只是 CEO 一個人

## 方法

### 高階梯隊模型

```
客觀情境 → 高階主管的感知（經過濾） → 策略選擇 → 績效
                      ↑
              TMT 特徵
              （以人口統計作為認知的代理指標）
```

### 主要的 TMT 特徵與策略預測

| 特徵 | 策略傾向 |
|---------------|-------------------|
| **較年輕的 TMT** | 更敢冒險、創新、成長策略 |
| **任期較長** | 策略持續不變、較少變革、堅守現狀 |
| **職能多元** | 策略選項更廣、決策更全面 |
| **產出職能背景**（行銷、業務） | 成長、多角化 |
| **轉換職能背景**（營運、會計） | 效率、成本控制 |
| **教育程度較高** | 更多創新、能容忍模糊 |
| **TMT 異質性** | 決策較好但較慢、衝突較多 |

### 分析步驟

1. **評估管理裁量權**：環境是否寬鬆到讓 TMT 的特徵有發揮空間？
   - 產業裁量權（管制、成長、集中度）
   - 組織裁量權（董事會權力、資源取得）
   - 個人裁量權（CEO 權力、授權範圍）
2. **建立 TMT 輪廓**：蒐集人口統計與背景資料
3. **把特徵對應到預測的策略傾向**：使用上面的表
4. **拿預測跟實際觀察到的策略比對**：TMT 輪廓能解釋策略選擇嗎？
5. **找出落差**：TMT 的組成在哪裡造成策略盲點？

### 管理裁量權的調節因素

| 因素 | 高裁量權 | 低裁量權 |
|--------|----------------|----------------|
| 產業管制 | 管制少 | 管制嚴格 |
| 市場成長 | 高成長 | 成熟/衰退 |
| 董事會警覺 | 被動的董事會 | 積極、獨立的董事會 |
| 公司績效 | 績效強（有餘裕） | 危機（受限） |

## 輸出格式

```markdown
## 高階梯隊分析：[情境]

### 管理裁量權評估
- 產業裁量權：[高/中/低]：...
- 組織裁量權：[高/中/低]：...
- 整體：[足夠/不足以做高階梯隊分析]

### TMT 輪廓
| 主管 | 年齡 | 任期 | 職能背景 | 教育 | 關鍵經歷 |
|-----------|-----|--------|----------------------|-----------|----------------|
| [姓名]    | ... | ...    | [職能]           | [學位]  | [重要經歷]      |

### TMT 組成摘要
- 平均任期：... | 異質性：[高/中/低]
- 主要職能背景：...
- 預測的策略傾向：...

### 策略與輪廓的吻合度
- 預測的方向：...
- 實際觀察到的策略：...
- 落差/盲點：...
```

## 範例

### 好的範例
分析一家科技公司的 TMT：平均年齡年輕（42 歲）、平均任期短（3 年）、職能多元度高、工程背景強。裁量權高（快速成長、管制輕的市場）。預測：積極創新、快速 pivot 的策略。實際觀察：與預測相符。盲點：財務/營運方面的代表性不足，可能導致擴張時出問題。

### 不好的範例
把一家公用事業公司的保守策略，歸因於它較年長的 TMT，卻沒評估管理裁量權。公用事業受到嚴格管制，裁量權低，不管人口統計特徵如何，任何 TMT 都很可能採取類似的策略。

## 常見陷阱

- 人口統計是不完美的代理指標，認知這個「黑箱」仍有一部分沒被打開
- TMT 異質性有曲線效果：多元過頭會造成癱瘓
- CEO 的強勢可以蓋過 TMT 組成的效果，要另外評估 CEO 的權力
- 這套理論是機率性的，不是決定論，人口統計製造的是傾向，不是必然
- 較新的研究強調人口統計之外的心理特質（傲慢、自戀、過度自信）
- 選擇與社會化效應：企業可能會挑選符合現有策略的 TMT，造成內生性問題
