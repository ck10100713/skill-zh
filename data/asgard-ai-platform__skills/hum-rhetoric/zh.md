# 修辭學：說服的藝術

## 概述

Aristotle 指出說服的三種模式：Ethos（可信度）、Pathos（情感）、Logos（邏輯）。有效的說服會依照受眾與情境，按適當的比例運用這三者。

## 框架

```
鐵律：三種訴求都要用，並依受眾校準

只有 Logos 能說服分析師，但會讓主管覺得無聊。只有 Pathos
能打動人心，但缺乏實質內容。只有 Ethos 則是靠可能並不存在的名聲。

每一次有說服力的溝通，都必須三者並用，並依受眾調整比重：
- 技術型受眾：以 Logos 為主，Ethos 輔助
- 主管型受眾：以 Pathos（願景）為主，Logos（資料）輔助
- 大眾型受眾：以 Ethos（信任）為主，用 Pathos 放大
```

### 三種訴求

**Ethos**（可信度）：他們為什麼該信任「你」？
- 專業、資歷、過往紀錄、共同的價值
- 要及早建立，如果受眾不信任你，其他一切都不重要
- 技巧：引述資歷、提到共同經驗、誠實承認自己的限制

**Pathos**（情感）：他們為什麼該「在乎」？
- 故事、生動的語言、共同的價值、急迫感、嚮往、恐懼
- 創造行動的動機，光靠邏輯很少能打動人
- 技巧：個人軼事、具體的例子、感官語言、修辭問句

**Logos**（邏輯）：他們為什麼該「相信」？
- 資料、證據、邏輯推理、結構
- 為情感上的反應提供理性的依據
- 技巧：統計數字、案例研究、因果關係、比較、類比

### 修辭手法

| 手法 | 做了什麼 | 範例 |
|--------|-------------|---------|
| **首語重複（Anaphora）** | 重複開頭的詞句 | 「我們將戰鬥……我們絕不投降……我們將……」 |
| **三項並列（Tricolon）** | 三個一組 | 「生命、自由，以及對幸福的追求」 |
| **對偶（Antithesis）** | 把對立的東西並置 | 「不要問國家能為你做什麼，要問你能為國家做什麼」 |
| **修辭問句** | 答案顯而易見的問題 | 「我們真的等得起嗎？」 |
| **隱喻/類比** | 用具體的東西比喻抽象的東西 | 「這個專案是我們的登月計畫」 |
| **交錯配列（Chiasmus）** | 顛倒的平行結構 | 「我們不是累了才停，而是做完了才停」 |

### 分析步驟（用於評估修辭）

1. **辨識修辭情境**：說話者、受眾、目的、脈絡
2. **描繪訴求**：文本在哪裡用了 Ethos、Pathos、Logos？
3. **辨識手法**：哪些修辭技巧放大了訊息？
4. **評估成效**：訴求的平衡是否符合受眾？訴求是否真誠？
5. **指出弱點**：修辭在哪裡薄弱、操弄，或與受眾不搭？

## 範例

### 正確的應用
**情境：** 分析一份新創的募資簡報
- **Ethos**（第 2 張投影片）：「我們的團隊在 Google 和 Meta 累計有 15 年經驗」，建立技術上的可信度 ✓
- **Pathos**（第 1 張投影片）：「想像一下，你的孩子在發燒，卻要等 3 週才能掛到醫生」，透過一個有共鳴的情境創造急迫感 ✓
- **Logos**（第 5 張投影片）：「TAM 為 42 億美元，年複合成長率 18%（McKinsey，2024）」，有資料支持的市場機會 ✓
- **平衡**：很適合投資人這種受眾（Pathos 開場 → Ethos 團隊 → Logos 市場）

### 不正確的應用
- 一份 20 張投影片的簡報，全是資料，沒有故事也沒有情感鉤子 → 全是 Logos，沒有 Pathos。投資人是先憑感覺決定，再用理性去合理化。違反鐵律：三種訴求都需要。

## 常見陷阱

- **Ethos 很脆弱：** 一個不誠實的說法，就會摧毀所有可信度。絕對不要誇大資歷或資料。
- **沒有 Logos 的 Pathos 就是操弄：** 純粹的情感訴求，沒有證據，就是煽動。一定要提供邏輯上的支撐。
- **要知道你的受眾的 Ethos 門檻：** 在台灣，學術頭銜與機構隸屬帶有很強的 Ethos。在矽谷，新創的出場經驗與投資組合公司更重要。要校準。
- **書面 vs 口語：** 書面修辭更依賴 Logos（讀者可以重讀並驗證）。口語修辭更依賴 Pathos 和 Ethos（聽眾是即時處理的）。
- **反修辭：** 理解修辭也能幫你「抵抗」操弄。當有人純粹訴諸情感、沒有任何證據時，要能認出來。
