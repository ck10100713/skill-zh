# Flow Theory

## Overview

心流理論（Csikszentmihalyi，1990）描述一種完全沉浸在活動中的心理狀態，這時一個人的技能被相稱的挑戰完全調動。心流出現在焦慮（挑戰超過技能）和無聊（技能超過挑戰）之間的狹窄通道，需要明確的目標、即時的回饋，以及感知到的技能與挑戰平衡。

## When to Use

- 診斷為什麼使用者或學習者失去投入（無聊）或放棄（焦慮或挫折）
- 設計學習系統、遊戲或生產力工具中的難度曲線
- 評估職場條件是否利於持續的深度工作
- 安排任務結構，讓內在動機和表現最大化

## When NOT to Use

- 失去投入是外部因素（薪酬、政治）造成的，不是任務設計
- 任務本質上就是例行工作，無法有意義地重組
- 當成萬用的生產力處方：心流取決於狀態，不一定能達成，也不一定值得追求

## Assumptions

```
IRON LAW: Flow occurs ONLY when perceived challenge matches
perceived skill — too easy breeds boredom, too hard breeds
anxiety. Both dimensions are SUBJECTIVE perceptions, not
objective measurements.
```

關鍵假設：
1. 心流是自成目的的，活動本身就帶來內在獎勵，不依賴外部結果
2. 明確的近端目標和即時回饋是必要的前提條件，不是可有可無的加分
3. 心流通道是動態的，隨著技能成長，挑戰必須升級才能維持平衡

## Methodology

### Step 1 — Map the Skill-Challenge Space

把目標活動標在體驗象限上：

```
High Challenge
      |
 Anxiety  |  FLOW
      |
------+----------
      |
 Apathy   |  Boredom
      |
      Low Skill ——————— High Skill
```

### Step 2 — Assess Flow Preconditions

檢查三個必要條件：
- **Clear goals**：這個人在每個時刻都知道下一步該做什麼嗎？
- **Immediate feedback**：他們能即時判斷自己是成功還是失敗嗎？
- **Skill-challenge balance**：任務難度有按他們目前的能力校準嗎？

### Step 3 — Identify Flow Blockers

常見的阻礙：打斷、模糊的目標、延遲的回饋、固定的難度（沒有自適應調整）、多工、自我意識、外部評價壓力。

### Step 4 — Design Flow-Conducive Environment

- 用鷹架搭出難度進程（逐步提高挑戰）
- 提供即時、有資訊量的回饋
- 把打斷和 context 切換降到最低
- 在做法上給予自主權，同時維持明確的目標
- 加入精熟的訊號，讓技能的成長看得見

## Output Format

```markdown
## Flow Analysis: [Context]

### Current State Diagnosis
- Perceived skill level: [Low/Medium/High]
- Perceived challenge level: [Low/Medium/High]
- Current experience zone: [Flow/Anxiety/Boredom/Apathy]

### Precondition Check
| Condition | Status | Evidence |
|-----------|--------|----------|
| Clear goals | [Met/Unmet] | [observation] |
| Immediate feedback | [Met/Unmet] | [observation] |
| Skill-challenge match | [Met/Unmet] | [observation] |

### Flow Blockers
- [Blocker and its impact]

### Design Recommendations
1. [Challenge calibration change]
2. [Feedback mechanism improvement]
3. [Environmental modification]
```

## Gotchas

- 心流是主觀狀態，同樣難度的同一項任務，依個人感知的技能，可能產生心流，也可能產生無聊
- 心流不一定是正面的，它可能出現在會上癮或有害的活動中（賭博、無止境滑手機），符合倫理的設計需要護欄
- Csikszentmihalyi 最初的研究使用經驗取樣法（ESM），有自我報告的限制
- 團體心流（例如爵士樂團、運動團隊）除了個人心流之外還有額外條件：共同目標、平等參與、溝通
- 心流不需要最高難度，適中且匹配良好的挑戰就夠了，而且更能持久
- 心流被打斷後的恢復時間很長（15 到 25 分鐘），零碎的行程會讓人進不了心流
