# 新聞記者：專業新聞寫作

## 概述

濃縮自 26 所新聞學院（政大、台大、Columbia、Missouri、Medill、UC Berkeley、Sciences Po、中文大學、港大 JMSC 等）的寫作流程。把原始素材（逐字稿、數據、活動筆記、直接引述）轉成可發表的稿件，涵蓋四種經典類型：即時新聞、調查報導、特稿、評論。

```
IRON LAW: No Unsourced Facts

Every concrete fact in the finished piece — names, titles, numbers, dates,
places, quotes, causal claims — must trace to material the user provided.
Anything missing is marked [待查證: specific description] in the draft,
NOT silently filled in with plausible-sounding invention. This holds even
when the gap is small ("probably around 30%", "most likely Tuesday"):
either the source exists or the placeholder stays. A fabricated plausible
detail is a defamation / retraction / trust-collapse vector — treat it as
radioactive. When in doubt, ask the user before writing, not after.
```

為什麼這件事不直覺：LLM 預設會「補上」資訊讓文字順暢（一個合理的職稱、一個整數、一句修順的引述）。在新聞業，這是已發表的不實內容最常見的來源。鐵律就是用來壓住這個預設行為的。

**合理化對照表：以下這些說法都「不能」推翻鐵律：**

| Claude 可能會想… | 為什麼這樣還是違規 |
|---|---|
| 「使用者說『大約 400』，我進位成 500，文字比較乾淨」 | 任何憑空加上的精確度都是捏造。用提供的數字，不然就用 [待查證]。 |
| 「這個市場規模大家都知道，不需要來源」 | 就算是公開知識，也要能追溯到使用者提供的素材，不然就要標記。 |
| 「我只是重建引述的意思，不是確切的字句」 | 用轉述加註出處；絕對不要重建成直接引述。 |
| 「這個缺口很小，不重要」 | 重不重要是編輯要判斷的，不是寫稿的人。佔位標記要留著。 |
| 「補一個合理的分析師估計，讓報導更完整」 | 捏造專家意見是 LLM 新聞寫作最常見的失敗。不行。 |

## 何時使用

**觸發條件：**
- 使用者提供原始素材（逐字稿、訪談、活動筆記、數據、新聞稿、紀錄），並要求把它變成類似新聞的稿件。
- 使用者要求「news article」、「report」、「feature」、「op-ed」、「column」、「commentary」、「investigation」、「profile」、「long-form story」、「稿件」、「深度報導」、「專稿」、「評論」。
- 使用者換句話說：「幫我寫成新聞稿」、「潤成一篇報導」、「整理成專訪」、「寫一篇關於 X 的評論」、「把逐字稿做成 feature」。
- 使用者要求「把公關新聞稿改寫成新聞」（具體來說：拿公關素材，產出新聞語氣的報導）。

**輸入訊號：**
- 素材裡有具名的人、組織、時間、地點、數字或直接引述，也就是可能出現在真實新聞報導裡的內容。
- 有明確或隱含的發表意圖（「給編輯室用」、「我們要發表這篇」、「要投稿到 X 媒體」）。
- 要求裡提到中立、平衡、出處標註或事實查核。

**何時不要用：**
- 當事公司以自家口吻發的新聞稿或公告 → 用 `pr-press-release`。
- 行銷文案、廣告創意、landing page 文案 → 用 `mkt-*`。
- 社群貼文草稿（短篇、宣傳性質）→ 用 `pr-social-copywriting`。
- 沒有發表意圖的內部會議紀錄／摘要 → 用 `ops-meeting-minutes`。

## 方法

### Step 1：判斷稿件類型

從四種類型挑一個，然後讀對應的參考檔：

| 類型 | 訊號 | 讀這個 |
|------|---------|------|
| **即時新聞／硬新聞** | 事件、記者會、公告，5W1H 齊全 | `references/type_breaking_news.md` |
| **調查報導／深度報導** | 多方來源、隱藏的事實、系統性問題、文件交叉比對 | `references/type_investigative.md` |
| **特稿／長篇敘事** | 人物側寫、場景、敘事弧線、以主題驅動 | `references/type_feature.md` |
| **評論／專欄／op-ed** | 立場、詮釋、論證 | `references/type_opinion.md` |

如果不明確，**問使用者**，不要猜。如果素材橫跨多種類型，就依使用者指定的類型。

### Step 2：素材盤點與找出缺口

起草之前：

1. **列出手上有的事實**：素材裡的人物、時間、地點、事件、數字、引述。
2. **標記來源強度**：
   - 一手（逐字稿、原始文件、現場筆記）→ 可直接使用。
   - 二手（其他媒體轉述、轉傳訊息）→ 必須交叉查證。
   - 傳言／沒有來源 → 不能用，或明確標示為「據稱」／「未經證實」。
3. **標記缺口**：5W1H 缺了哪個？有沒有對立方？數字有沒有來源？引述有沒有前後文？**每個缺口都要在稿子裡以 `[待查證: specific description]` 浮現，或是一開始就問。**

如果來源強度或查證方式不清楚，參考 `references/fact_checking.md`。

### Step 3：套用類型範本

> **鐵律檢查：** 只能用 Step 2 素材盤點中確認過的名字、數字和引述。任何缺少的事實 → `[待查證: description]`，不要自己補。

依 Step 1 載入的參考範本寫作。跨類型通用的原則：

- **導言（Lead）**：30–50 字；即時新聞用倒金字塔，特稿可以用場景／人物／提問式導言。
- **出處標註**：直接引述 `「…」王小明說。` ／ 間接引述 `王小明表示…`。**不要改變引述的意思**；整理標點可以。
- **匿名來源**：只有在 (a) 消息來源面臨真實風險，而且 (b) 沒有其他選擇時才用。要說明理由（「為避免遭報復而要求匿名」）。
- **數字**：一律要註明來源。比例要搭配絕對數字（「裁員 30%，約 1,200 名員工」）。避免誤導性的比較。
- **平衡**：報導指控或爭議時，**要給被指控的一方回應的機會**。如果對方拒絕或聯絡不上，要寫出來（「多次聯繫 X 公司；截至發稿時未獲回應」）。
- **揭露**：業配內容、聯盟行銷利益、利益衝突，都要在文末揭露。

寫作風格的預設：

- **具體勝過抽象**：寫「月薪 3 萬 2 千元」，不要寫「薪資不高」。
- **動詞勝過形容詞**：「抨擊」／「質疑」／「譴責」比「嚴重地反對」好。
- **主動勝過被動**：「警方逮捕嫌犯」，被動只在要強調受詞時才用。
- **短句**：平均 ≤ 40 字；連續超過 3 個複合句就要警覺。
- **禁止**：沒有來源的讀心（「他心中十分憤怒」→ 改寫成行為：「他拍桌大聲表示…」）；過度渲染的形容詞（「令人震驚」）；立場外洩（「正義的警方終於逮到嫌犯」）；傳聞（「聽說」／「有人說」）。

### Step 4：媒體倫理檢查（必做）

**輸出之前，你必須把 `references/media_ethics.md` 裡下面每一項都做完。** 不要因為「這篇看起來很乾淨」就跳過，因為這個清單就是要推翻這種判斷。

1. 有誹謗風險嗎？（對具名的真實人物做出未經查證的負面宣稱）
2. 有侵犯隱私嗎？（未經同意揭露私人資訊）
3. 消息來源有受到保護嗎？（匿名來源能不能從細節被重新辨識出來？）
4. 是特殊類別的題材嗎？（未成年人、性侵被害人、自殺，台灣法律有特定限制）
5. 有沒有未揭露的利益衝突？
6. 圖片／素材的授權？

**只要有任何一項不確定，就要在輸出裡明確警告使用者。** 不要默默放行。

### Step 5：媒體識讀自我檢查（必做）

**輸出之前，你必須把 `references/media_literacy.md` 裡下面每一項都做完。** 一篇「感覺很平衡」的稿子是最常見的失敗模式，這個清單抓的就是直覺漏掉的東西。

1. 導言有沒有誇大（標題黨）？標題和內文對得上嗎？
2. 事實和意見有沒有混在一起？事實性的宣稱用陳述語氣；意見用轉述語氣（「批評者認為」、「專家表示」）。
3. 這篇稿子是在訴諸情緒而不是證據嗎？
4. 數據的呈現有沒有可能誤導（基期、挑選過的時間區間、把相關當因果）？
5. 有沒有標出來源層級（官方／當事人／第三方／匿名）？
6. 如果有 AI 協助產生或整理任何內容，有沒有揭露？

### Step 6：輸出成稿

依下面的輸出格式輸出。如果使用者明確要純稿件、不要 meta footer，就省略 footer，但 Step 4–5 還是要在內部做完。

遇到以下情況，**停下來問使用者**：

1. 素材缺少 5W1H 當中的 2 項以上。
2. 素材涉及未成年人、性侵害、自殺，或資訊不完整的醫療題材。
3. 對另一方的指控只有單一來源。
4. 沒有指定類型，而素材橫跨多種類型。
5. 素材有矛盾（同一件事有兩個版本）。
6. 要求的篇幅跟素材量不符（例如用 200 字的簡報要寫 3000 字的調查報導）。

所有缺口一次問完，不要來回問。

## 輸出格式

```markdown
# [Headline: ≤ 20 chars, concrete people/events]

**副標**: (optional, 15–25 chars)

[Lead paragraph]

[Body paragraphs…]

---

**稿件類型**: 即時新聞 / 深度調查 / 特稿 / 評論
**字數**: approx. XXX
**消息來源層級**: 一手訪談 N 則 / 二手引用 N 則 / 匿名 N 則
**待查證事項**:
- [ ] [specific item]

**倫理／識讀檢核摘要**:
- 平衡原則: ✅ / ⚠️ (reason)
- 匿名來源揭露: ✅ / N/A
- 利益揭露: ✅ / N/A
- 情緒化字眼: ✅ / ⚠️ (list)
- 數據來源: ✅ / ⚠️ (list)
```

## 範例

### 好的範例

**情境：** 使用者提供一份 1,200 字的記者會逐字稿，內容是一家台北餐飲 SaaS 新創宣布 A 輪募資。素材包含：執行長的引述、領投方合夥人的引述、募資金額（NT$120M）、目前客戶數（400+）、目標市場（日本）、具名的公司。

**分析：**
1. Step 1：歸類為即時新聞（事件驅動、5W1H 齊全）→ 載入 `references/type_breaking_news.md`。
2. Step 2：素材盤點：5W1H 完整；所有數字都能追溯到逐字稿；兩則直接引述都有正確標註出處；找到的缺口：沒有提供日本市場規模的數字。在稿子裡標為 `[待查證: 日本餐飲 SaaS 滲透率來源]`。
3. Step 3：倒金字塔導言：WHO（新創）+ WHAT（NT$120M A 輪）+ WHEN（今天）+ WHY（拓展日本）。後面的段落補上數據、投資人引述、產品細節。執行長的引述逐字使用。
4. Step 4：倫理檢查：沒有未成年人／被害人／私人資訊的風險；沒有未揭露的利益衝突；有一位投資人是大型創投（公開資訊）。
5. Step 5：識讀檢查：沒有標題黨；事實和投資人對未來的陳述分得清楚（「合夥人 X 表示團隊『有機會達到…』」）；數字都搭配來源。
6. 輸出包含 meta footer，標出那一個 `[待查證]` 項目和平衡評級。

結果：一篇可發表的硬新聞稿，新聞編輯只需要查證那一個標出來的數據點。沒有捏造的事實、沒有立場外洩、沒有倫理隱患。

### 壞的範例

**情境：** 輸入素材同上。寫稿的人為了讓稿子「更順」：(a) 把 400 個客戶進位成「超過 500」讓文字比較乾淨，(b) 把執行長的引述改寫成更有力的版本，(c) 加了一句「市場分析師預期日本擴張第一年可帶來 500 萬美元 ARR」，卻沒有提供任何分析師來源，(d) 因為「現在看起來很乾淨」就把 `[待查證]` footer 拿掉。

**哪裡出了問題：**
- (a) 捏造了更大的客戶數字，違反鐵律。就算是「進位」也是造假。
- (b) 修改引述會改變出處的歸屬。就算意思沒變，那也不是那個人說的話，有誹謗／準確性的風險。
- (c) 憑空捏造「分析師預期」，是典型的 LLM 幻覺模式。編輯會馬上把它抽掉，整篇稿子就死了。
- (d) 把稽核 footer 拿掉看起來比較漂亮，卻藏住了真正的信任問題：沒有 `[待查證]` 標記，下游的編輯根本沒有訊號知道 (c) 從來沒被查證過。

總結：讀起來很流暢，但這四個修改每一個都是會被開除等級的新聞錯誤。鐵律的全部意義就是擋下這些預設行為。

## 注意事項

- **「聽起來像真的引述」就是捏造的開端**：如果某句引述不是逐字稿裡的原話，就不要根據前後文「重建」它。用轉述加註出處，或標 `[引言待查證]`。重建的引述是新聞系學生犯錯最大宗的來源。
- **台灣的法律風險跟美國不同**：刑法 310（誹謗罪）即使陳述屬實，若缺乏公共利益也適用；偵查不公開限制報導進行中偵查的細節，就算記者知道也一樣；性侵害犯罪防治法禁止揭露可能辨識出性侵被害人的資訊。凡是碰到這些的內容，發表前先看 `references/media_ethics.md`。
- **WHO 自殺報導守則是強制的，不是選擇性的**：不要描述方式、地點，也不要刊登遺書。一定要附上求助專線的文字。很多編輯室的危機，都是因為「覺得有新聞價值」而跳過這條。
- **平衡 ≠ 虛假對等**：給對方回應的機會是必須的；在證據一面倒的情況下硬造一個「兩造各有道理」的框架，是在誤導。如果被指控的一方拒絕回應，就寫出來；不要用臆測的辯護來湊數。
- **匿名來源 ≠ 沒有出處的來源**：每個匿名來源都還是要在稿子裡看得到匿名的理由。「一位消息人士表示」卻沒有任何脈絡，是警訊，不是專業做法。
- **標題和內文不符是最快毀掉信任的方式**：如果標題承諾的比內文交代的多，就改標題，絕對不要把內文灌水。自我檢查時，最後再重讀標題，對照實際的內文。

## 限制

- **不會對照外部來源查證事實宣稱。** 這個 skill 檢查的是內部一致性並標出缺口；它不會對資料庫、法院紀錄或其他外部系統做即時查證。使用者必須自己做，或提供已查證的素材。
- **以台灣為中心的法律框架。** 媒體倫理與法律紅線引用的是台灣法律（刑法 310、個資法、偵查不公開、性侵害犯罪防治法、兒少法）。用在美國／歐盟／香港的司法管轄區時，一般原則仍適用，但具體法條需要替換。
- **超過約 5,000 字的長篇調查。** 對於書籍等級的專案、多篇系列報導或紀錄片處理，這裡的範本只涵蓋單篇稿件的工藝；跨系列的敘事架構需要這個 skill 以外的額外規劃。
- **不能取代法律審查。** 稿子裡有具名指控時，不管這個 skill 的倫理檢查有沒有過，不經律師審閱就發表還是有風險。
- **不會自己產生原創報導。** 如果提供的素材不夠，這個 skill 會標出缺口，但不會自己去找其他來源。
