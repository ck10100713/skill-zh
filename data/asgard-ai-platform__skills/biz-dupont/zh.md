# 杜邦分析（DuPont Analysis）

## 概述

杜邦分析把 ROE 拆成三個相乘的成分：淨利率 × 資產週轉率 × 權益乘數。這能看出 ROE 是由獲利能力、效率還是槓桿所驅動，對診斷和比較至關重要。

## 何時使用

**觸發條件：**
- 使用者問「我們的 ROE 為什麼高／低？」
- 使用者在比較不同公司的財務績效
- 使用者需要找出哪個營運槓桿能提高報酬
- 使用者在分析營收以外的獲利能力

**何時不要用：**
- 公司估值 → 用 DCF
- 完整的比率分析 → 用財務比率 skill
- 策略定位 → 用 SWOT

## 框架

```
鐵律：三因子分解

ROE = 淨利率 × 資產週轉率 × 權益乘數
    = (淨利/營收) × (營收/總資產) × (總資產/權益)

三個因子「都必須」計算和分析。只報告 ROE 而不分解，
就像只報告發燒，卻沒檢查症狀。
```

```
鐵律：高槓桿 ≠ 好績效

高權益乘數（資產/權益）會透過負債灌高 ROE。
一家利潤率 5%、週轉率 1.0x、槓桿 6x 的公司，ROE 是 30%，
但只要一季表現不好，就面臨無力償債。
當槓桿是主要驅動因素時，一定要標出來。
```

### 步驟 1：計算三個成分

| 成分 | 公式 | 衡量什麼 |
|-----------|---------|-----------------|
| 淨利率 | 淨利 / 營收 | 獲利能力：每一塊錢營收有多少變成利潤 |
| 資產週轉率 | 營收 / 總資產 | 效率：資產創造營收的能力 |
| 權益乘數 | 總資產 / 股東權益 | 槓桿：負債把股權報酬放大多少 |

### 步驟 2：診斷驅動因素

把每個成分和產業基準及趨勢做比較：
- **利潤率驅動的 ROE**：高端品牌、科技公司（高利潤率、較低週轉）
- **週轉率驅動的 ROE**：零售、速食（低利潤率、高週轉）
- **槓桿驅動的 ROE**：銀行、不動產（中等利潤率、高槓桿），要標出風險

### 步驟 3：趨勢分析

計算 3-5 年的杜邦成分。找出：
- 哪個成分在改善／惡化？
- ROE 的改善是來自營運（利潤率、週轉率），還是財務操作（槓桿）？

### 步驟 4：同業比較

比較各競爭對手的杜邦成分，找出相對的強項／弱項。

## 輸出格式

> ⚠️ **小數 vs 百分比**：隨附的腳本回傳的 ROE 和所有利潤率／負擔成分，都是**小數**
> （`0.2014` 代表 20.14%，不是 `20.14`）。下方的敘述表格為了人類閱讀，會呈現成百分比，
> 但 JSON 輸出和任何下游 pipeline 都必須一致使用小數。

```markdown
# 杜邦分析：{公司}

## ROE 分解

| 成分 | 數值 | 產業平均 | 趨勢（3 年） |
|-----------|-------|-------------|-------------|
| 淨利率 | X% | X% | ↑/↓/→ |
| 資產週轉率 | X.Xx | X.Xx | ↑/↓/→ |
| 權益乘數 | X.Xx | X.Xx | ↑/↓/→ |
| **ROE** | **X%** | **X%** | ↑/↓/→ |

## 診斷
- 主要的 ROE 驅動因素：{利潤率 / 週轉率 / 槓桿}
- 風險警示：{如果適用，說明槓桿的疑慮}

## 同業比較
| 公司 | 利潤率 | 週轉率 | 槓桿 | ROE |
|---------|--------|----------|----------|-----|
| {公司} | X% | X.Xx | X.Xx | X% |
| {同業 A} | ... | ... | ... | ... |

## 建議
1. {該改善哪個槓桿、怎麼改善}
```

## 範例

### 正確的應用
**情境：** 兩家台灣零售業者的杜邦分析

| | 公司 A | 公司 B |
|---|---|---|
| 淨利率 | 2% | 8% |
| 資產週轉率 | 3.5x | 1.2x |
| 權益乘數 | 2.0x | 2.0x |
| **ROE** | **14%** | **19.2%** |

診斷：公司 A 是週轉率驅動（高銷量、低利潤率的零售）。公司 B 是利潤率驅動（高端定位）。兩者槓桿相近，ROE 的差異來自營運 ✓

### 錯誤的應用
- ROE 是 25%，沒有分解就報告為「很優秀」。結果是：利潤率 3%、週轉率 1.0x、槓桿 8.3x → 幾乎完全由槓桿驅動，風險極高。違反鐵律：必須分解。

## 常見陷阱

- **延伸的 5 因子杜邦**：要更深入分析的話，把利潤率拆成稅負 × 利息負擔 × 營業利益率。在比較不同稅制地區時很有用。
- **負權益會讓模型失效**：有累積虧損的公司可能權益為負，使乘數失去意義。要註明，並改用其他指標。
- **一次性項目會扭曲利潤率**：要使用正規化／調整後的淨利，避免因資產出售、減損或法律和解造成單一年度的暴衝。
- **週轉率因產業而差異極大**：輕資產的事業（SaaS）天生週轉率高。重資本的事業（製造業）週轉率低。只在同產業內比較。
