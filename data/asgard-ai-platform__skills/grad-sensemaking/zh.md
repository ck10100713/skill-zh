# Weick 的 Sensemaking 理論

## 概述

Sensemaking 理論由 Karl Weick 提出，解釋人們如何把未知的東西放進某個框架裡，好讓它變得可以理解、可以行動。它本質上是回溯性的、社會性的、持續進行的：人們是看了自己做過什麼，才發現自己在想什麼。

## 何時使用

- 分析組織如何詮釋（或誤判）模糊事件
- 研究危機應變與組織失敗
- 理解在動盪環境中，身分認同如何影響詮釋
- 診斷為什麼早期警訊被漏掉或被忽略

## 何時不要使用

- 情境是例行且結構明確的（sensemaking 處理的是新奇而模糊的情況）
- 理性決策模型就足以解釋行為
- 重點在結果，而不是詮釋的過程

## 假設

```
鐵律：Sensemaking 是回溯性的，人們是在行動「之後」才理解情境，
不是之前。任何分析如果假設行動者先搞懂情境、再決定怎麼做，
就把 sensemaking 的因果順序顛倒了。
```

關鍵假設：
1. 行動先於理解：人們是用行動走進意義裡的
2. 合理性比準確性重要：夠好的故事就能促成行動
3. Sensemaking 是社會性的：共享的意義是協商出來的，不是個人各自發現的
4. 身分認同的建構，決定了人們會注意到什麼、怎麼詮釋

## 方法

### 步驟 1：找出 Sensemaking 事件

選出觸發 sensemaking 的那個模糊或造成中斷的事件，並界定時間範圍。

### 步驟 2：套用 Sensemaking 的七個特性

| 特性 | 要問的問題 |
|----------|----------------|
| **身分認同建構** | 行動者對「我們是誰」的認知，如何左右他們的詮釋？ |
| **回溯** | 哪些過去的行動被重新詮釋，好讓情況變得說得通？ |
| **行動造境（Enactment）** | 行動者的行動，如何創造出他們之後要回應的環境？ |
| **社會性** | 意義是怎麼在團體成員之間協商出來的？ |
| **持續進行** | 隨著情況展開，sensemaking 如何演變？ |
| **擷取線索** | 哪些線索被注意到、哪些被忽略？為什麼？ |
| **合理性重於準確性** | 採用了哪個「夠好」的故事？犧牲了哪些準確性？ |

### 步驟 3：找出 Sensemaking 的崩解點

找出 cosmology episode（意義徹底喪失）、承諾陷阱，或行動造境導致自我實現預言的情況。

### 步驟 4：評估後果

評估所建構（或沒建構成）的意義，如何影響組織的行動與結果。

## 常見陷阱

- Sensemaking 不等於詮釋：它包含行動與行動造境，不只是認知
- 不要以為 sensemaking 會產出正確的理解，它產出的是「能行動」的理解
- 回溯偏誤：分析者必須避免把事後的清晰感，套在當時真的很模糊的情況上
- 行動造境的意思是，行動者有部分是在「創造」自己面對的情境，因果是循環的
- 在危機中，sensemaking 的崩解（cosmology episode）有時比事件本身更重要
- Weick 對 Mann Gulch 和 Tenerife 的分析是經典案例，但不要把它們當成唯一的應用領域
