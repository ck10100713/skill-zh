# 損益兩平分析（Break-Even Analysis）

## 概述

損益兩平分析找出總營收等於總成本的那個點，也就是不賺也不賠。它把成本分成固定和變動，再算出需要多少銷量（單位數或營收），才能透過邊際貢獻（contribution margin）涵蓋固定成本。

## 框架

```
鐵律：固定與變動的分類必須嚴謹

固定成本「不會」隨銷量變動（租金、薪資、保險）。
變動成本會隨銷量「按比例」變動（原料、每單位運費、佣金）。

「薪資」不一定是固定的，業務佣金就是變動的。
「租金」不一定是固定的，抽成式租約就是變動的。
分類錯誤會直接破壞損益兩平的計算。
```

### 核心公式

```
每單位邊際貢獻 = 售價 - 每單位變動成本
損益兩平單位數 = 固定成本 / 每單位邊際貢獻
損益兩平營收 = 固定成本 / 邊際貢獻率
邊際貢獻率 = 每單位邊際貢獻 / 售價
安全邊際 = (實際銷售額 - 損益兩平銷售額) / 實際銷售額
營運槓桿度（DOL）= 邊際貢獻 / 淨利
```

### 步驟 1：分類所有成本

把每一項成本分成固定或變動。對於半變動成本（例如電費有基本費加用量費），要拆成固定和變動兩部分。

### 步驟 2：計算損益兩平點

- **單一產品**：BEP 單位數 = 固定成本 / 每單位 CM
- **多個產品**：依產品組合用加權平均 CM，然後 BEP = 固定成本 / 加權 CM

### 步驟 3：評估安全邊際

目前的銷售高出損益兩平多少？安全邊際越高 = 對景氣下滑的抗壓性越強。

### 步驟 4：情境分析

測試：價格降 10% 會怎樣？銷量降 20% 呢？固定成本增加呢？建立一張情境表。

## 範例

### 正確的應用
**情境：** 台灣一家珍珠奶茶店的損益兩平
- 固定成本：NT$150,000/月（租金 NT$60K、人事 NT$70K、水電 NT$20K）
- 變動成本：NT$25/杯（原料 NT$15、杯子／吸管 NT$5、包材 NT$5）
- 價格：NT$55/杯
- CM = NT$30/杯（54.5%）
- **BEP = 150,000 / 30 = 5,000 杯/月 ≈ 167 杯/天** ✓

### 錯誤的應用
- 把員工薪資分類為變動成本 → 對一家員工是固定配置（不是按杯計酬）的店來說，薪資是固定的。這樣會低估 BEP。違反鐵律。

## 常見陷阱

- **階梯式固定成本**：租金在你需要第二個據點之前是固定的。人事在你需要多一個班次之前是固定的。這些成本會在某些銷量門檻「跳階」，要把它們建模成在各自相關範圍內的固定成本。
- **多產品的事業**：大多數真實的事業都賣多種產品。要用加權平均 CM，或用營收（而不是單位數）來算 BEP。
- **損益兩平忽略貨幣的時間價值**：BEP 告訴你銷量，不會告訴你什麼時候能達到。一個在 10,000 單位損益兩平、但要花 3 年才到得了的事業，現金可能會先燒完。
- **邊際貢獻不是毛利**：毛利用的是銷貨成本（COGS，可能包含固定的製造費用）。CM 只用變動成本。
