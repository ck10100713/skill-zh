# 蘇格拉底式提問

## 概述

蘇格拉底法透過有紀律的提問，來檢視想法、揭露假設、發展更深的理解。它不直接給答案，而是引導思考者透過自己的推理發現洞見，讓結論更持久，也對他個人更有意義。

## 框架

```
鐵律：連續超過 3 個問題都沒有總結，只會製造混亂，不會產生洞見

套用蘇格拉底式提問的 agent，預設會拋出一長串沒有上限的問題。
大約 3 個問題之後，思考者就會斷掉思路，他們無法把問題的層級
記在工作記憶裡。每 2-3 個問題就要暫停，「總結」思考者到目前
為止透露了什麼（「所以你的立場是 X，因為 Y，但你對 Z 不確定，
對嗎？」），然後再繼續。
沒有這個檢查點，整場對話感覺會像審問，不像有引導的探問。

另外：絕對不要問一個答案已經藏在措辭裡的問題。
「你不覺得 X 有問題嗎？」是偽裝成問題的誘導性斷言。
改成「X 會帶來什麼後果？」
```

### 引導流程

1. **釐清**思考者的主張，要精確
2. **探查假設**：這個主張要成立，什麼必須為真？
3. **要求證據**：什麼支持這個信念？夠不夠充分？
4. **引入對立的視角**：批評者會怎麼說？
5. **探索意涵**：如果是對的，會推導出什麼？如果是錯的，什麼會改變？
6. **綜合**（鐵律的檢查點）：總結、確認理解，然後再繼續

關於六種問題類型（釐清、假設、證據、視角、意涵、後設問題）與鷹架技巧（產婆術），見 [`references/facilitation-guide.md`](references/facilitation-guide.md)。

## 輸出格式

套用蘇格拉底式提問時，輸出一個有結構的問題序列：

```markdown
# 蘇格拉底式探問：{主題}

## 起點立場
{思考者目前的信念或問題}

## 問題序列
1. [釐清] {問題}
   → 預期的洞見：{這會揭露什麼}
2. [假設] {問題}
   → 預期的洞見：{這會浮現什麼}
3. [證據] {問題}
   → 預期的洞見：...
4. [視角] {問題}
   → 預期的洞見：...
5. [意涵] {問題}
   → 預期的洞見：...

## 目標洞見
{思考者透過這個序列應該得到的結論}
```

## 範例

### 正確的應用
**情境：** 學生說「AI 會取代所有工作」

**蘇格拉底式序列：**
1. [釐清]「你說『所有工作』，是真的每一份工作，還是大部分的工作？」
2. [證據]「你看到了什麼證據，讓你這麼認為？」
3. [假設]「你對 AI 的能力做了什麼假設？有沒有哪些任務需要 AI 做不到的東西？」
4. [視角]「從歷史上看，工業革命這類先前的技術革命之後，就業發生了什麼事？」
5. [意涵]「如果 AI 取代了所有工作，人們要怎麼賺錢，去買 AI 生產出來的東西？」

→ 學生得到更細緻的看法：AI 會轉變工作，不會消滅所有工作 ✓

### 不正確的應用
- 學生：「AI 會取代所有工作」→ 老師：「不會。原因是……」→ 直接給了答案。這不是蘇格拉底式的。違反鐵律。

## 常見陷阱

- **蘇格拉底法可能讓人覺得有敵意：** 提問時要帶著真誠的好奇，不要像交互詰問。「我很好奇……」可以緩和語氣。
- **要知道何時該停：** 如果思考者感到挫折或在原地打轉，就給個提示或轉向。這個方法是為學習服務，不是為了自尊。
- **不是所有情境都適合蘇格拉底式提問：** 緊急決策、時間緊迫的情況，以及純事實的問題（「法國的首都是哪裡？」），都不適合用蘇格拉底式探問。
- **引導者必須真的在聽：** 下一個問題應該回應思考者說了什麼，不是照著預先寫好的劇本走。彈性是必要的。
- **文化敏感度：** 在某些文化中，質疑權威或在公開場合被質問，會讓人不自在。要調整場合（一對一、書面）與措辭。
