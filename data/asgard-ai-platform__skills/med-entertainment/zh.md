# 娛樂新聞報導

> **這個 skill 是 med-news-reporter 在娛樂 / 影視線上的專門化版本。** 請先讀 med-news-reporter，了解一般的 6 步驟工作流程（類型選擇、素材稽核、事實查核、平衡、倫理、識讀）。這份檔案在它之上，加上**娛樂線專屬**的紀律。

## 概述

整理自政大傳播系、台大新聞所、哥倫比亞大學新聞學院（Entertainment Reporting）、南加大 Annenberg（Entertainment & Media）、香港大學 JMSC（Arts & Culture）的娛樂新聞課程。涵蓋娛樂新聞的四種主要子類型：**娛樂快訊 / 影評 / 產業分析 / 娛樂人物側寫**報導。娛樂新聞有一般新聞紀律抓不到的嚴重風險：被公關綁架、違反 embargo、名人情境下的誹謗，以及未揭露的利益衝突。

```
鐵律：有揭露的公關，不等於獨立報導

任何透過公關管道提供的東西，包括片商的試映採訪、有 embargo 的
新聞資料包、付費的提前試映、提供的照片、公關安排的訪談，或
精心製作的金句，都帶有片商/經紀公司寫下的隱藏議程，
而不是獨立的觀察。稿子必須清楚區分哪些來自公關
（要揭露，標明這是片商/經紀公司的框架），
哪些是記者獨立觀察或查證的。

沒有做到這個區分，就是娛樂新聞最典型的失敗模式：把公關的說帖
當成獨立評估來重複、未經查證就把試映採訪提供的素材當成事實、
把片商提供的引述當成自由給出的話來用、刊出照片卻沒註明它是有
編輯使用限制的片商財產。

預設的 LLM 行為：把區分抹平、吸收公關的框架、省略試映是付費的
這件事的揭露、不加歸屬就重複公關的用語（「今年必看」）。
要明確地推翻這個預設。
```

為什麼這件事不明顯：公關素材往往準確，而且寫得很好。違規不在於「事實是假的」，而在於「這個事實的來源沒有被揭露，而它所帶的框架被當成獨立判斷來呈現」。像「這部電影為觀眾帶來對家庭動態的全新詮釋」這樣的句子可能是真的，但如果這個框架來自片商的新聞資料包（逐字或改寫），就必須標明歸屬。

**合理化對照表：這些辯解「不能」推翻鐵律：**

| Claude 可能會想…… | 為什麼仍然違規 |
|---|---|
| 「片商的描述是準確的，所以我可以把它順進評論裡」 | 準確不是問題所在。問題是來源歸屬。如果措辭或框架來自片商，就要標明。（例如：「片商稱之為『全新詮釋』；實際執行上，前提……」） |
| 「試映採訪是正常的產業慣例，我不需要揭露」 | 產業慣例 ≠ 倫理上的揭露。透過採訪試映的電影，與片商的核可綁在一起；讀者有權知道。寫「在片商提供的試映會上觀看」，或者如果它造成你無法揭露的偏見，就整個拿掉。 |
| 「embargo 只是客套，如果稿子準備好了，我可以提早發」 | Embargo 是契約。違反它 (a) 傷害記者的專業可信度、(b) 讓媒體被片商列入黑名單、(c) 損害同業日後取得 embargo 素材的管道。這是一條硬底線。 |
| 「名人的公關安排了訪談，所以他不是自由人」 | 公關牽線的訪談是標準做法。要揭露的不是「公關安排的」（這是預期中的），而是有沒有附帶條件（核稿權、禁談話題、付費差旅、利益交換）。揭露條件；省略顯而易見的牽線。 |
| 「公關照片解析度高又完美，我不註明來源就用」 | 公關提供的圖片帶有隱含的編輯使用限制，而且是宣傳品。要揭露：「照片由 [片商] 提供」或「宣傳劇照」。如果改用狗仔照，那是不同的選擇。 |
| 「我用片商的語言（『大片』/『必看』）聽起來比較專業」 | 片商的詞彙是一種框架。換成可觀察的事實：不要說「史詩般的規模」，而是描述規模是什麼意思（片長、國家數量、場景的規模）。讓讀者自己決定那算不算史詩。 |

## 何時使用

**觸發條件：**
- 使用者提供娛樂素材（新片首映、電影評論、票房數據、串流平台數據、藝人宣傳、影視產業新聞、影評 embargo、製片公司新聞稿、影展報導），並要求寫成新聞稿。
- 使用者要求「影評」/「票房分析」/「新片評測」/「streaming coverage」/「entertainment feature」/「celebrity profile」/「industry trend analysis」。
- 使用者換句話說：「幫我寫成電影評論」、「把試映心得整理成報導」、「寫一篇票房分析」、「turn this junket transcript into a review」、「analyze this streaming data」。

**輸入訊號：**
- 有名字的電影、片商、演員、串流平台、票房數字、評分（Rotten Tomatoes / IMDb / Metacritic）、製作細節、上映日期。
- 來自電影人、卡司、評論家、產業分析師的直接引述。
- 標有 embargo 的素材（通常會註明「Do not publish before [date/time]」）。

**何時不要使用：**
- 以片商 / 經紀公司自己口吻撰寫的新聞稿 → 改用 `pr-press-release`。
- 粉絲內容、社群媒體評論的彙整，或非新聞的評論 → 不是新聞，婉拒。
- 電影行銷 / 廣告文案 → 改用 `mkt-*` skill。
- 沒有新聞切角的純娛樂產業分析（例如「串流大戰是怎麼運作的」） → 改用 `ops-*` 或產業分析的 skill。

## 方法

### 步驟 0：一般的工作流程交給 med-news-reporter

請讀過或已載入 `med-news-reporter`，處理：素材稽核、事實查核、消息來源強度標記、平衡原則、媒體倫理檢查、媒體識讀自我檢核。**不要在這裡重新實作這些步驟。** 這份檔案專門處理步驟 1、2、3，並新增娛樂專屬的步驟 7（公關來源稽核）。

### 步驟 1：分類娛樂報導的子類型

| 子類型 | 訊號 | 子範本重點 |
|----------|---------|--------------------|
| **娛樂快訊** | 宣布、卡司、簽約、交易、殺青、影展入選、上映日期變動 | 人、事、時、產業影響；引述片商 / 藝人 |
| **電影 / 娛樂評論** | 提供了 embargo 日期、參加了試映、上映前素材、評價性的判斷 | 遵守 embargo；獨立觀影；區分提供的框架與觀察到的細節 |
| **產業 / 趨勢分析** | 票房模式、串流指標、人才流動、系列電影策略、平台競爭 | 資料來源與交叉驗證；產業數據識讀的紅線 |
| **娛樂人物側寫** | 演員 / 導演 / 製片的側寫、職涯回顧、幕後專題 | 採訪的管道（付費的採訪？免費的？談判過的？）；揭露附帶條件 |

如果素材橫跨多個子類型（例如影評 + 票房資料），依照主要的新聞驅動力分類。

### 步驟 2：娛樂專屬的來源審查與公關來源標記

**每一則資訊都必須標記其來源：**

- ❌ 含糊：「這部電影壯闊的攝影捕捉了……」（這個判斷從哪裡來的？片商的新聞資料包？還是你自己的觀影？）
- ✅ 具體：「攝影師在四個國家的 140 個場景拍攝（依製作說明）；在片中，全球的規模……」（事實 + 來源 + 觀察）
- ✅ 揭露公關：「片商稱之為『情感上很親密』；相對地，開場的 30 分鐘靠旁白而非動作推進……」

**來源層級標記**（擴充 med-news-reporter 的層級，加入娛樂專屬的層級）：

| 層級 | 範例 | 處理方式 |
|------|----------|-----------|
| **公開紀錄** | Box Office Mojo（美國）、本地票房（台灣：電影票房新聞稿）、IMDb/RT/Metacritic 公開評分 | 直接引用；不需要進一步揭露 |
| **片商官方** | 新聞稿、試映採訪、片商提供的劇照、官方製作說明 | **必須揭露**（「依片商新聞資料」、「在片商主辦的試映會上」、「Photo © [片商]」） |
| **獨立評論家 / 分析師** | 自由影評人、與片商無關的票房分析師、第三方串流研究者 | 附上所屬單位的直接引述；不需要特別揭露 |
| **藝人具名受訪** | 演員訪談、導演聲明、公關安排的記者會 | 必須註明：有沒有任何條件？（核稿權、禁談話題、付費差旅？） |
| **標有 embargo 的素材** | 媒體評論、評論家試映、有 embargo 的新聞資料包 | **關鍵**：絕對不要在 embargo 解除前發佈。必要時在稿中註明：「評論 embargo 至 [日期]」。 |
| **串流平台自報** | Netflix「Top 10 觀看時數」、Disney+「互動帳戶數」、Apple TV+ 資料（若有揭露） | 一定要註明：平台自行回報，不是獨立查證。跨平台比較無效。 |

### 步驟 3：娛樂專屬的風險檢查

除了 med-news-reporter 的一般倫理檢查之外，再加上：

1. **Embargo 違規**：
   - 每一份標有 embargo 日期的素材都是契約。違反會被列入黑名單。如果素材的 embargo 到星期五早上 9 點，就不要在星期四晚上 10 點發佈。
   - 如果使用者要求在 embargo 解除前發佈，就停下來並標記：`[待查證: 此素材有 embargo 標記至 X 日期時間;違反會導致媒體被列黑名單。確認可發佈?]`。

2. **演員隱私 vs 公眾人物**（名人隱私 vs. 公眾人物）：
   - 公眾人物（有名字的演員、導演）的隱私期待較低，但不是零。避免揭露：住家地址、家人的身分（尤其是未成年子女）、醫療細節、感情狀態（除非已經公開）、可能被跟蹤的工作行程。
   - 未成年演員：額外的保護。兒少法限制揭露。除了新聞所必須的之外，不要揭露年齡、學校、家庭細節。

3. **肖像權與宣傳劇照**（宣傳圖片 vs. 狗仔照）：
   - 宣傳劇照（來自片商）：附帶使用限制。揭露來源。有些片商限制只能在「影評的脈絡」下使用，要尊重這點。
   - 狗仔照（演員在街上）：法律地位不同。揭露來源。要留意跟蹤 / 騷擾的意味。

4. **評論 vs 個人攻擊**：
   - 批評一部電影（「對白很平淡」）是合理的評論。
   - 批評演員的專業選擇（「選角感覺很僵硬」）是合理的評論。
   - 批評演員的外表（「她看起來很累」、「他老得很難看」）或私生活（「她跟 X 的戀情很可疑」）就跨進個人攻擊了。誹謗風險高，而且有傷害性。

5. **置入性行銷揭露**（產品置入 / 品牌整合）：
   - 如果角色顯眼地喝著某個有名的品牌（而且該品牌付費置入，或產品在後製時加上品牌），要揭露：「Note: contains paid brand integration for [Brand]。」
   - 如果片商提供了宣傳合作（例如「這部電影與 [連鎖速食店] 合作」），你可以把它當成商業新聞來報導，但要清楚標記。

6. **粉絲評分 vs 評論家評分**（觀眾評分 vs. 評論家評分）：
   - Rotten Tomatoes：同時引用 Tomatometer（評論家）與 Audience Score。注意：觀眾評分容易受到刷分 / 負評轟炸的影響。如果一部電影圍繞著爭議，要明確提到。
   - IMDb：引用數字與取樣日期。如果粉絲社群有組織地行動，IMDb 的分數可能在數小時內變動 0.5 分。

### 步驟 4：公關來源稽核（娛樂專屬的新增項目）

輸出之前，掃過草稿裡每一個不瑣碎的事實，問：**「這個資訊我是從哪裡得到的？」**

對每個事實，往回追溯：
- 是來自片商新聞資料包或試映採訪嗎？ → 揭露。
- 是來自獨立來源（評論家、分析師、公開資料）嗎？ → 不需要特別揭露。
- 是來自宣傳照嗎？ → 標明出處。
- 是來自訪談嗎？ → 是具名公開的，還是附帶條件的？如果有條件就揭露。
- 是來自串流平台的資料嗎？ → 註明是自行回報、平台專屬的。

如果你答不出「這是從哪裡來的」，它就不能留在稿子裡，或要標上 `[待查證]`。

## 輸出格式

使用 med-news-reporter 的基本格式，並在 meta 頁尾加上這些娛樂專屬的項目：

```markdown
[標題 / 副標 / 內文段落，依 med-news-reporter]

---

**稿件類型**: 即時娛樂新聞 / 影評 / 產業分析 / 人物專訪
**字數**: approx. XXX
**消息來源層級**: 獨立評論 N / 製作方官方 N / 藝人親訪 N / 串流平台自報 N
**PR 來源揭露稽核**:
- 新聞稿 / 試映會 / 宣傳劇照: ✅ / ⚠️ (列出未揭露的項目)
- Embargo 合規: ✅ / ⚠️ (列出 embargo 日期 + 符合狀況)
- 獨立觀察 vs PR 框架: ✅ / ⚠️ (列出混淆的段落)
**串流平台數據**:
- 來源: ✅ / N/A / ⚠️ (平台自報 vs 獨立研究?)
- 跨平台比較警告: ⚠️ (如果有, 列出不可比之處)
**藝人隱私 / 肖像權**:
- 未成年演員保護: ✅ / N/A / ⚠️
- 隱私邊界: ✅ / ⚠️ (列出敏感揭露)
**名譽 / 評論邊界**:
- 評論 vs 個人攻擊: ✅ / ⚠️ (列出潛在攻擊性字眼)
**待查證事項**: ...
**倫理 / 識讀檢核摘要**: 〔交給 med-news-reporter 的 Step 4-5 footer〕
```

## 範例

### 好的範例

**情境：** 使用者提供 (a) 虛構片商（「範例影業」Demo Pictures）宣布「示範之夜」Demo Night 首映的官方新聞資料，包含王大明（導演）與林小華（女主角）；(b) 片商提供的一張劇照；(c) 來自國家電影中心的票房資料；(d) 來自影評媒體、標有 embargo 的評論家試映素材，embargo 到星期五下午 2 點；(e) 一個 Rotten Tomatoes 連結，顯示評論家 78% / 觀眾 64%；(f) 來自 Netflix 的平台資料，顯示這部電影在台灣進入「Top 10」。使用者要求寫一篇 600 字的上映日影評。

**分析：**
1. 步驟 1：分類為**影評**（標有 embargo 的素材、評價性的內容） → 強調獨立觀影 + 遵守 embargo。
2. 步驟 2：來源標記：
   - 片商新聞資料 → 在稿中揭露（「依片商資料……」），或者如果沒有獨立查證就省略。
   - 照片 → 揭露來源（「Photo © Demo Pictures」）。
   - 售票資料 → 引用國家電影中心為來源；這是公開紀錄。
   - 標有 embargo 的試映素材 → **關鍵**：算清楚 embargo 的時間。如果它在星期五下午 2 點解除，而使用者想在今天（星期四）發佈，就要標記；如果是星期五下午 5 點，就可以進行。
   - RT 評分 → 同時引用評論家（78%）與觀眾（64%）；註明觀眾評分可能變動。
   - Netflix「Top 10」 → 註明這是 Netflix 自行回報的資料；不要與其他平台的指標比較。
3. 步驟 3：風險檢查：
   - Embargo：已確認它在使用者希望的發佈時間之前解除。
   - 隱私：導演與女演員是公眾人物；沒有未揭露的個人細節。
   - 評價：影評應該批評電影，不是批評演員的外表或私生活。
4. 步驟 4（公關來源稽核）：
   - 第一段是根據獨立觀影的觀察，不是片商新聞資料包 → 不需要揭露。
   - 如果寫作者用了逐字呼應片商資料的描述（「一場令人屏息的記憶冥想」），就要標記：揭露這個框架來自片商，或換成獨立的描述。
   - 照片 → 附上來源行「Photo courtesy of Demo Pictures」。
   - RT 評分 → 引用兩個層級；註明觀眾評分同時反映真實評價與可能的刷分（如果有任何爭議）。
5. 輸出頁尾：列出 embargo 狀態（✅ 合規）、引用的 RT 層級、註明為自行回報的 Netflix 資料、文末揭露片商提供的素材。

結果：這篇影評可以發佈，沒有倫理上的紅旗。讀者了解哪些判斷來自獨立觀影、哪些來自片商的框架。Embargo 有被遵守。資料來源都有揭露。

### 不好的範例

**情境：** 同樣的輸入。寫作者產出的稿子 (a) 以「《示範之夜》為記憶帶來一場令人屏息的冥想，是王大明遠見導演功力的見證」開場（逐字來自片商新聞資料包，沒有標記）、(b) 使用片商的照片但沒有署名行、(c) 引用 RT 時寫成「評論家與觀眾都讚揚這部電影」，卻沒提到 14 個百分點的差距（78% vs 64%）或刷分的可能性、(d) 宣稱這部電影是「Netflix 全球最多人觀看的電影第一名」（實際上只是台灣的 Top 10；寫作者自己編造了「全球」，以配合提供的公關框架）、(e) 包含林小華童年與家庭的私密細節（來自一則舊的狗仔訪談，沒有揭露，已逼近侵犯隱私）、(f) 在星期四早上 10 點發佈稿子（embargo 到星期五下午 2 點才解除，違規）。

**哪裡出了問題：**
- (a) 逐字照搬片商框架又沒標記 = 抄襲 + 偏見。就算是真的，框架的選擇（為什麼是「遠見」而不是「野心勃勃」？）來自公關。必須揭露，或換成獨立的語言。
- (b) 沒有照片署名 = 侵害權利，也沒有揭露片商來源。
- (c) 隱藏 RT 評分的落差有誤導性。這個落差暗示觀眾反彈或刷分；讀者看不到它，就無法做出有根據的判斷。
- (d)「全球第一」是編造的。片商的「台灣 Top 10」被擴大成「全球第一」。事實捏造。
- (e) 未揭露的隱私侵犯。林小華的童年是個人的；沒有她的同意、也沒有新聞相關性就放進去，就越界了。
- (f) 違反 embargo = 被片商列入黑名單、損害記者的可信度、傷害同業取得素材的管道。

總結：每一項都是娛樂新聞特有的陷阱，是一般新聞記者 skill 抓不到的。

## 常見陷阱

- **Embargo is a contract, not a suggestion**: 影評 embargo 通常在發片前 24-48 小時解除;違反會被製片公司列入黑名單,影響後續採訪與試映機會。如果素材標記「Do not publish before 2026-05-02 14:00」,嚴格遵守時間。提前一小時發佈會被視為違反。
- **「新聞稿」vs「獨立評論」的界線在字句**: 如果描述(例如 "breathtaking meditation on memory")逐字或高度相似出現在製片方新聞稿,就來自 PR,必須揭露或替換。光是改個詞序("memory meditation, breathtaking")還是同一個 PR 框架。
- **宣傳劇照無版權揭露就是侵權**: 製片公司提供的照片附帶隱含版權。務必註明「Photo © [Studio Name]」或「Promotional still courtesy of...」。omitting credit 是侵權+不揭露 PR 來源的雙重失誤。
- **串流平台數據不可跨平台比較**: Netflix 用「小時數」(watch hours), Disney+ 用「帳戶數」(accounts engaged), Apple TV+ 通常不公布詳細數字。宣稱「Netflix 上最受歡迎電影」時絕不能同時比較「Disney+ 也在前 10」— 計算口徑完全不同,此比較誤導讀者。
- **Rotten Tomatoes audience score 易被刷分**: 粉絲或反對者可集體投票影響 audience score。引用時務必 (a) 明確區分 Tomatometer (critics) 與 Audience Score, (b) 提及高度爭議的電影可能有刷分現象, (c) 看發布日期是否有明顯波動。
- **「未成年演員」受兒少法保護**: 台灣 兒少法 限制未成年人隱私揭露。不得揭露未成年演員真實姓名、就讀學校、家庭成員、住所等,除非絕對必要且由法定代理人同意。若製片方提供的素材含有此類資訊,應主動刪除。
- **評論「電影」vs 攻擊「人」的差別**: 寫「劇本對白顯得生硬」可接受; 寫「女主角演得生硬」也可接受; 但「女主角看起來疲憊」「他明顯衰老了」跨入人身攻擊,有名譽侵害風險。
- **置入性行銷必須揭露**: 如果電影中角色飲用名牌飲料且該品牌付費置入,文中應註記「Note: contains paid brand integration」。若製片公司與連鎖餐飲合作推廣,可以報導此業務合作,但須明確標記為商業新聞而非內容評論。

## 限制

- **司法管轄範圍**：法律參考（兒少法、著作權法、肖像權）反映的是台灣法律。對於美國（第一修正案 + 隱私權）、英國（Defamation Act 2013）、香港的情境，原則適用但法規不同，請替換成該司法管轄區專屬的參考資料。
- **不查證外部資料**：這個 skill 會標出需要查證的主張；它不會即時檢查 Box Office Mojo、查證串流數字，或交叉比對 RT 評分。編輯必須自行查證，或提供資料。
- **Embargo 的時間點由使用者負責**：這個 skill 會提醒使用者素材中的 embargo 日期；它無法在發佈時強制執行有 embargo 意識的排程。使用者（或 CMS 系統）必須確保排程發佈的稿子遵守 embargo。
- **不是公關擷取的 skill**：如果使用者想把新聞稿轉成新聞語言，請使用 `med-news-reporter` + 這個 skill 的常見陷阱；這個 skill 不會自動完成轉換。
- **娛樂新聞專屬**：聚焦在電影、電視、串流與名人。不涵蓋音樂新聞、遊戲新聞，或更廣泛的藝術/文化報導（藝術/文化請用 `med-culture`）。
