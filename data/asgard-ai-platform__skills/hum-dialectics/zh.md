# 辯證分析

## 概述

辯證法是一種透過矛盾來推理的方法。它不在對立的立場（正題 vs 反題）之間二選一，而是尋找一個超越兩者的合題，保留各自有效的部分，同時在更高層次上化解矛盾。

## 框架

```
鐵律：合題 ≠ 妥協

合題「不是」「各退一步」。它是一個「新的」立場，
透過在更高的抽象層次上重新框架問題，來化解矛盾。

妥協：「A 做一半、B 做一半」
合題：「A 和 B 之間的矛盾，揭示出真正的答案是 C」
```

### 辯證的過程

1. **正題**：清楚陳述最初的立場，並以鋼人的方式呈現
2. **反題**：清楚陳述對立的立場，並以鋼人的方式呈現
3. **找出矛盾**：兩者之間具體存在什麼張力？
4. **檢視各自對在哪裡**：每個立場包含什麼真理？
5. **綜合**：什麼更高層次的理解，能在保留兩者有效成分的同時化解矛盾？

### 當合題變成新的正題，過程就會重新來過，這就是辯證式的進展。

## 輸出格式

```markdown
# 辯證分析：{主題}

## 正題
{立場 A，以鋼人方式呈現}
- 它對在哪裡：...
- 它在哪裡失敗：...

## 反題
{立場 B，以鋼人方式呈現}
- 它對在哪裡：...
- 它在哪裡失敗：...

## 矛盾
{這些立場之間具體存在什麼張力}

## 合題
{化解矛盾的更高層次立場}
- 從正題保留：...
- 從反題保留：...
- 超越之處：...
```

## 範例

### 正確的應用
**情境：**「公司應該優先考慮股東價值還是利害關係人價值？」

- **正題**（Friedman）：公司存在的目的是極大化股東報酬。社會責任是政府的工作。聚焦股東價值能帶來效率與財富。
- **反題**（Freeman）：公司必須服務所有利害關係人，包括員工、社區、環境。只看股東會造成外部性與不平等。
- **矛盾**：股東價值可能要求傷害利害關係人，利害關係人價值則可能降低報酬。
- **合題**：長期的股東價值「需要」利害關係人的健康。剝削員工、污染環境、疏遠客戶的公司，會摧毀長期價值。當時間範圍拉長，矛盾就消解了：只要時間夠長，利害關係人價值「就是」股東價值 ✓

### 不正確的應用
- 「合題是：50% 聚焦股東、50% 聚焦利害關係人」 → 這是妥協，不是合題。違反鐵律。

## 常見陷阱

- **不是所有對立都是辯證的：** 有些矛盾是真正的二選一（你不能同時在兩個地方）。辯證法適用於概念上的張力，不適用於物理上的不可能。
- **鋼人處理是必要的：** 如果你把正題或反題弱化地呈現，合題就會很淺。在綜合之前，先把每個立場給到最強的形式。
- **合題也可能是錯的：** 你做出了合題，不代表結果就有效。合題必須獨立評估。
- **無限遞迴的風險：** 合題變成新的正題，產生新的反題…… 要知道何時停手。合題是獲得洞見的工具，不是無止盡的過程。
