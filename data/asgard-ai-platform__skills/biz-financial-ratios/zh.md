# 財務比率分析（Financial Ratio Analysis）

## 概述

財務比率分析把原始財報，轉換成橫跨五個類別、可比較的指標。比率只有放在脈絡中才有意義，要和產業基準、歷史趨勢和同業公司做比較。

## 何時使用

**觸發條件：**
- 使用者手上有財報，需要評估公司的健康狀況
- 使用者在比較不同公司的財務績效
- 使用者在做盡職調查或信用分析
- 使用者問「這家公司財務健康嗎？」或「分析這些數字」

**何時不要用：**
- 估值 → 用 DCF 或可比公司法
- ROE 的深入分析 → 用杜邦分析
- 策略評估 → 用 SWOT

## 框架

```
鐵律：沒有脈絡的比率毫無意義

流動比率 1.5，單獨看沒有意義。1.5 算好嗎？要和下列比較：
1. 產業平均（零售約 1.2、製造業約 1.8）
2. 公司自己的趨勢（去年是 2.0？→ 流動性在惡化）
3. 同業（競爭對手是 2.5？→ 相對偏弱）

絕對不要在沒有至少一個比較基準的情況下回報比率。
```

```
鐵律：每次都要涵蓋全部五個類別

只分析獲利能力，會漏掉一家即將違約的高槓桿公司。
只分析流動性，會漏掉一家獲利公司的成長潛力。
要涵蓋全部五個類別，才是完整的圖像。
```

### 五個類別

**1. 獲利能力（Profitability）**：公司有在賺錢嗎？
| 比率 | 公式 | 衡量什麼 |
|-------|---------|----------|
| 毛利率 | (營收 - COGS) / 營收 | 生產效率 |
| 營業利益率 | EBIT / 營收 | 核心事業的獲利能力 |
| 淨利率 | 淨利 / 營收 | 最終獲利能力 |
| ROE | 淨利 / 權益 | 對股東的報酬 |
| ROA | 淨利 / 總資產 | 資產生產力 |

**2. 流動性（Liquidity）**：付得出短期債務嗎？
| 比率 | 公式 | 健康值 |
|-------|---------|---------|
| 流動比率 | 流動資產 / 流動負債 | > 1.5 |
| 速動比率 | (流動資產 - 存貨) / 流動負債 | > 1.0 |
| 現金比率 | 現金 / 流動負債 | 視情況而定 |

**3. 槓桿（Leverage）**：用了多少負債？
| 比率 | 公式 | 衡量什麼 |
|-------|---------|----------|
| 負債權益比 | 總負債 / 權益 | 資本結構 |
| 利息保障倍數 | EBIT / 利息費用 | 償付債務的能力 |
| 負債資產比 | 總負債 / 總資產 | 資產的融資方式 |

> ⚠️ **「負債」的定義**：這個 skill（和隨附的腳本）在槓桿比率中，把「負債」定義為
> **總負債（Total Liabilities）**，不是「只有長期負債」，也不是「只有附息負債」。
> 教科書裡這兩種替代定義都存在，且會算出差異很大的比率。如果你需要不同的定義，
> 要明確記錄這個選擇並手動計算，不要默默替換。

**4. 效率（Efficiency）**：資產用得好嗎？
| 比率 | 公式 | 衡量什麼 |
|-------|---------|----------|
| 存貨週轉率 | COGS / 平均存貨 | 存貨管理 |
| 應收帳款週轉率 | 營收 / 平均應收帳款 | 收款速度 |
| 資產週轉率 | 營收 / 總資產 | 資產生產力 |
| 現金轉換週期 | DIO + DSO - DPO | 現金週期的速度 |

**5. 估值（Valuation）**：股價合理嗎？
| 比率 | 公式 | 衡量什麼 |
|-------|---------|----------|
| P/E | 股價 / EPS | 股價相對盈餘 |
| EV/EBITDA | 企業價值 / EBITDA | 股價相對現金創造力 |
| P/B | 股價 / 每股淨值 | 股價相對淨資產 |
| 殖利率 | 每股股利 / 股價 | 收益報酬 |

### 分析流程

1. **計算**財報中所有相關的比率
2. **比較**產業基準和 3 年趨勢
3. **辨識**警訊（惡化的趨勢、與同業相比的離群值）
4. **綜合**出橫跨全部五個類別的財務健康結論
5. **建議**針對弱項的行動

## 輸出格式

> ⚠️ **小數 vs 百分比**：隨附的腳本回傳所有獲利能力比率
> （`gross_margin`、`operating_margin`、`net_margin`、`roa`、`roe`）都是**小數**，
> `0.35` 代表 35%，不是 `35.0`。流動性和槓桿比率本身就是沒有單位的倍數
> （例如 `current_ratio: 2.125`）。只在給人看的 markdown 報告裡呈現百分比，
> JSON 輸出絕對不要用百分比。

```markdown
# 財務比率分析：{公司}

## 摘要儀表板
| 類別 | 狀態 | 關鍵指標 |
|----------|--------|-----------|
| 獲利能力 | 🟢/🟡/🔴 | {代表性比率} |
| 流動性 | 🟢/🟡/🔴 | {代表性比率} |
| 槓桿 | 🟢/🟡/🔴 | {代表性比率} |
| 效率 | 🟢/🟡/🔴 | {代表性比率} |
| 估值 | 🟢/🟡/🔴 | {代表性比率} |

## 詳細比率
{每個類別一張表，包含比率、數值、產業平均、趨勢}

## 警訊
- {附上資料的具體疑慮}

## 整體評估
{綜合的財務健康結論}
```

## 範例

### 正確的應用
**情境：** 台灣一家電子製造商的比率分析

| 比率 | 公司 | 產業 | 趨勢 | 警示 |
|-------|---------|----------|-------|------|
| 毛利率 | 18% | 22% | ↓ 從 21% | 🔴 低於同業，且在下滑 |
| 流動比率 | 1.8 | 1.5 | → 穩定 | 🟢 足夠 |
| D/E | 1.2 | 0.8 | ↑ 從 0.9 | 🟡 槓桿上升 |
| 存貨週轉率 | 4.2x | 6.0x | ↓ 從 5.1x | 🔴 存貨周轉慢 |

綜合：獲利能力減弱 + 存貨堆積 + 槓桿上升 = 前方可能有營運資金危機 ✓

### 錯誤的應用
- 單獨回報「毛利率 18%」這個事實 → 沒有比較。18% 是好還是壞？違反鐵律：沒有脈絡的比率。
- 只分析獲利能力比率，漏掉 4.5x 的 D/E → 公司的利潤率看起來很健康，實際上卻是危險的過度槓桿。違反鐵律：全部五個類別。

## 常見陷阱

- **產業影響極大**：5% 的淨利率對軟體業很糟（預期 20-30%），但對生鮮零售業很出色（預期 2-3%）。一定要在產業內做基準比較。
- **一次性項目**：重組費用、資產出售或法律和解，會扭曲該期間的比率。要使用調整後的數字，或註明這個扭曲。
- **季節性事業**：不同季末的比率，說的是不同的故事。要用過去 12 個月，或比較去年同一季。
- **表外項目**：營業租賃（IFRS 16 之前）、特殊目的實體和或有負債，可能不會出現在標準比率中。要檢查附註。
- **成長型公司看起來「不健康」**：高成長的公司，往往就是設計成獲利能力低、槓桿高、現金流為負。脈絡很重要。
