# 交易成本經濟學（TCE）

## 概述

TCE 透過分析進行交易的成本，來解釋企業的邊界。Williamson（1975、1985）主張，在有限理性與投機行為的前提下，人們選擇治理結構（市場、混合、層級），是為了讓生產成本與交易成本的總和最小。

## 何時使用

- 自製或外購的決策
- 評估外包、聯盟或垂直整合
- 為企業間的交易設計契約保障
- 分析為什麼某些產業的垂直整合程度比較高

## 假設

```
鐵律：治理方式的選擇取決於交易特性
（資產專屬性、不確定性、頻率），「不是」取決於企業的偏好、
傳統或意識形態。治理結構一旦不對盤，
就會產生本來可以避免的成本，最終還是得修正。
```

關鍵假設：
1. **有限理性**：行為者想要理性，但只能做到有限程度
2. **投機行為**：有些行為者會狡詐地追求私利
3. 交易的特性各不相同，因此需要不同的治理方式

## 方法

### 交易特性

| 面向 | 低 | 高 |
|-----------|-----|------|
| **資產專屬性** | 通用資產，容易重新配置 | 專用/特化資產，有被綁死的風險 |
| **不確定性** | 結果可預測，容易訂契約 | 無法預測，契約不完整 |
| **頻率** | 一次性或很少發生 | 重複發生的交易 |

### 資產專屬性的類型
- 地點專屬性（位置）
- 實體資產專屬性（特化設備）
- 人力資產專屬性（特化知識）
- 專用資產（為特定買方所做的投資）
- 品牌資本
- 時間專屬性（時機很重要）

### 治理選擇框架

1. **評估資產專屬性**：最主要的區辨變數
2. **評估不確定性**：環境與行為上不可預測的程度
3. **評估頻率**：交易重複發生的頻繁程度
4. **對應到治理方式：**
   - 低專屬性 + 低不確定性 → **市場**（價格機制）
   - 中度專屬性 → **混合**（契約、聯盟、合資）
   - 高專屬性 + 高不確定性 → **層級**（垂直整合）
5. **評估保障措施**：人質、可信承諾、監督

## 輸出格式

```markdown
## TCE 治理分析：[情境]

### 交易概況
| 面向 | 評估 | 證據 |
|-----------|-----------|----------|
| 資產專屬性 | [低/中/高]：[類型] | ... |
| 不確定性 | [低/中/高] | ... |
| 頻率 | [低/中/高] | ... |

### 治理建議
- 建議的結構：[市場/混合/層級]
- 理由：...
- 需要的保障措施：...

### 不對盤的風險
- 目前的治理方式：[結構]
- 預測的無效率：...
```

## 範例

### 好的範例
一家晶片製造商評估要不要外包一項客製化的製造流程：實體資產專屬性高（專用設備）、不確定性高（技術快速變動）、頻率高，TCE 的結論是層級（自己製造），並針對每個面向給出清楚的理由。

### 不好的範例
因為「比較便宜」就建議外包，卻沒評估資產專屬性或投機風險。TCE 要求評估交易特性，不能只比較現貨價格。

## 常見陷阱

- 資產專屬性是最重要的變數，一定要先評估
- TCE 把投機行為當作一種可能性，不是必然，但治理必須防範它
- 混合式治理有很多形式（加盟、合資、長期契約），要講清楚是哪一種
- TCE 是比較性的，不是絕對的，要比較各種治理選項，不要孤立地評估
- 忽略行為假設（有限理性、投機行為），就是誤用這個框架
