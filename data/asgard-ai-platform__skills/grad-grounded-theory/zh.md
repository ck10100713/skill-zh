# Grounded Theory (Glaser & Strauss)

## Overview

紮根理論是一套有系統的方法，用來建構紮根於質性資料的理論。透過資料蒐集、編碼和比較的反覆循環，研究者發展出概念和類別，最終形成一套解釋性的理論。這個方法最初由 Glaser 和 Strauss（1967）提出，後來分成 Glaser 學派（湧現式）和 Strauss 學派（結構式）兩個變體。

## When to Use

- 既有理論不足或不存在時，建構新理論
- 在研究不足的領域探索過程、互動或經驗
- 產生和特定脈絡綁在一起的實質理論
- 研究問題問的是「這裡到底發生了什麼？」，而不是檢驗假設

## When NOT to Use

- 檢驗或驗證既有理論（用演繹方法）
- 研究問題需要測量頻率或大小
- 研究者無法投入反覆的資料蒐集（理論取樣需要彈性）

## Assumptions

```
IRON LAW: In grounded theory, theory EMERGES from data — imposing a
pre-existing framework violates the methodology's core principle. If
you begin with a hypothesis and seek confirmation, you are NOT doing
grounded theory.
```

關鍵假設：
1. 理論必須紮根於有系統的資料蒐集與分析
2. 資料蒐集和分析同時進行，並且反覆迭代
3. 理論取樣根據浮現的類別，引導下一步去哪裡蒐集資料
4. 決定何時停止蒐集資料的是理論飽和，不是樣本數

## Methodology

### Step 1: Open Coding

把資料拆成一個個獨立的事件、事故或想法。為每個片段指定初始的編碼（標籤）。盡可能用 in-vivo 編碼（參與者自己的話）。資料有多少值得編的，就產生多少編碼，不要太早過濾。

### Step 2: Axial Coding

把開放編碼歸成更高階的類別。用編碼典範（條件、行動/互動、後果）找出類別之間的關係。建立子類別，具體說明某個類別在何時、何地、為何以及如何出現。

### Step 3: Selective Coding

找出核心類別，也就是所有其他類別都整合在它周圍的中心現象。有系統地把所有類別和核心類別連起來。寫出一條敘述這套理論的故事線。

### Step 4: Theoretical Integration

透過持續比較來精煉理論。對照資料驗證。產出一套有明確定義的概念、命題和邊界條件的實質理論。報告編碼決策的稽核軌跡。

## Output Format

```markdown
## Grounded Theory Analysis: [Context]

### Core Category
- Central phenomenon: [the core category label]
- Definition: [what it means in this context]

### Category Structure
| Category | Properties | Dimensions | Relationship to Core |
|----------|-----------|------------|---------------------|
| [name]   | [key properties] | [range/variation] | [how it relates] |

### Coding Paradigm
- **Causal conditions**: [what leads to the phenomenon]
- **Context**: [specific conditions shaping action]
- **Intervening conditions**: [broader structural conditions]
- **Action/Interaction strategies**: [how actors respond]
- **Consequences**: [outcomes of action/interaction]

### Theoretical Propositions
1. [Proposition linking categories]
2. [Proposition linking categories]

### Saturation Evidence
- Categories saturated: [list]
- Data sources: [count and type]
- Point of saturation: [when no new properties emerged]
```

## Gotchas

- 不要一開始就做會讓編碼產生偏見的文獻回顧，Glaser 堅持要等理論浮現後才做文獻回顧
- 持續比較是指事件對事件的比較，不只是類別對類別
- 理論取樣和立意取樣不一樣，它由浮現的理論驅動，不是預先設定的標準
- Glaser 學派和 Strauss 學派的差異很大，要說明你遵循哪一種
- 理論飽和是指類別不再浮現新的屬性，不只是不再有新的編碼
- 全程寫備忘錄（memo）是必要的，不是可選的，備忘錄記錄的是分析的邏輯
