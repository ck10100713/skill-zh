# Narrative Research

## Overview

敘事研究透過人們講述自己生活的故事來研究人類經驗。故事不只是事件的報告，而是意義的主動建構，它依時間組織經驗、賦予因果，並塑造身分認同。這個方法保留敘事的完整性，不把它切碎，同時留意結構（故事怎麼講）、內容（講了什麼）和脈絡（為什麼講、講給誰聽）。

## When to Use

- 理解個人如何理解關鍵的人生事件或轉變
- 探索身分認同隨時間的建構與轉變
- 研究文化、組織或政治敘事如何塑造經驗
- 時間順序和脈絡對理解現象至關重要

## When NOT to Use

- 現象不涉及經驗或時間（用概念分析）
- 參與者無法或不願意講述自己的經驗
- 目標是萃取離散的變數，或檢驗因果假設
- 橫斷面的快照資料就夠了

## Assumptions

```
IRON LAW: In narrative research, the STORY is the unit of analysis —
fragmenting narratives into coded themes destroys the temporal and
contextual meaning. If you reduce stories to thematic codes, you are
doing thematic analysis, NOT narrative research.
```

關鍵假設：
1. 人類是說故事的存在，敘事是我們組織經驗的主要方式
2. 故事是有情境的表演，受聽眾、脈絡和目的影響
3. 時間性是構成性的，意義從事件的順序和連結中浮現
4. 研究者透過訪談關係，是敘事的共同建構者

## Methodology

### Step 1: Elicit the Narrative

用單一的生成性問題（例如「請告訴我……的故事」）進行敘事訪談。讓敘述者自己安排講述的結構。在主要敘事結束之前，避免用追問打斷。依研究焦點，蒐集生命故事、口述歷史，或特定事件的敘事。

### Step 2: Analyze Narrative Structure

用結構要素檢視故事「怎麼」被講述：

| Element | Description |
|---------|-------------|
| **Abstract** | 這個故事在講什麼？ |
| **Orientation** | 誰、什麼時候、在哪裡、什麼情境？ |
| **Complicating action** | 然後發生了什麼？（情節） |
| **Evaluation** | 所以呢？這件事對敘述者為什麼重要？ |
| **Resolution** | 最後發生了什麼？ |
| **Coda** | 回到現在；寓意或教訓 |

（Labov 的結構模型；用在非西方的敘事形式時，視需要調整。）

### Step 3: Interpret Meaning and Identity

分析故事傳達「什麼」：轉折點、角色定位、能動性、因果和道德框架。檢視敘述者如何為自己定位（英雄、受害者、倖存者、行動者）。找出故事順應或抗拒的主流敘事。

### Step 4: Contextualize and Present

把敘事放進更廣的社會、文化和歷史脈絡中。以重新述說的敘事（Clandinin 和 Connelly），或分析性的敘事呈現發現，在保留故事完整性的同時，提供學術上的詮釋。

## Output Format

```markdown
## Narrative Analysis: [Context]

### Narrator Profile
- Pseudonym: [name]
- Context: [relevant background]
- Narrative type: [life story / episodic / oral history]

### Narrative Structure
| Structural Element | Content |
|-------------------|---------|
| Abstract | [summary of what the story is about] |
| Orientation | [setting, characters, initial situation] |
| Complicating action | [key events and turning points] |
| Evaluation | [narrator's assessment of meaning] |
| Resolution | [how events resolved] |
| Coda | [return to present, lesson drawn] |

### Identity Positioning
- Self-positioning: [how the narrator presents themselves]
- Agency: [active agent / constrained / victim / survivor]
- Master narratives: [aligned with or resisting which cultural stories]

### Temporal and Contextual Meaning
- Turning points: [pivotal moments that reorganize the narrative]
- Causality: [how the narrator explains why things happened]
- Silences: [what is notably absent from the story]

### Implications
1. [What this narrative reveals about the phenomenon]
2. [How it connects to broader social or cultural narratives]
```

## Gotchas

- 不要把敘事編碼成碎片，要把故事當作有內部結構的整體來分析
- 同一個人在不同時間，可能用不同方式講述同樣的事件，敘事不是固定的事實
- 研究者對故事的影響不可避免，需要對共同建構保持反身性
- Labov 的模型是為個人經驗的口述敘事發展的，不一定適用所有敘事形式
- 生命故事研究有倫理上的複雜性：參與者在說故事的流動中，可能透露超過原本打算的內容
- 要區分敘事分析（故事本身是對象）和敘事的分析（把故事當成找主題的資料），它們是不同的方法
