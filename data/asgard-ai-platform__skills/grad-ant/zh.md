# 行動者網絡理論（ANT）

## 概述

行動者網絡理論把人類與非人類的實體對稱地視為「行動元（actants）」，它們透過轉譯的過程形成網絡。ANT 由 Latour、Callon 和 Law 發展而成，追蹤異質的網絡如何被組裝、穩定，有時又如何瓦解，並拒絕預先區分社會與技術。

## 何時使用

- 描繪一項技術、創新或實務是如何被接受（或失敗）的
- 分析人造物、標準或裝置在穩定社會安排中的角色
- 追蹤科學與技術中的爭議與網絡建構
- 理解為什麼一個看似不錯的創新沒能被採用

## 何時不要用

- 分析需要強烈的規範性判斷（ANT 是描述性的，不是規範性的）
- 需要巨觀層級的結構性解釋（ANT 抗拒預先給定的社會範疇）
- 非人類的能動性跟研究問題無關

## 假設

```
IRON LAW: Non-human actors have AGENCY in ANT — treating technology
as a passive tool violates the framework's core principle. If your
analysis strips agency from artifacts, you are NOT doing ANT.
```

關鍵假設：
1. 廣義對稱：人類與非人類的行動者用相同的分析語彙來描述
2. 社會、技術與自然之間，沒有預先的區分
3. 分析單位是網絡，不是個人或結構
4. 穩定是一種成就，不是既有的狀態，網絡需要持續的維護

## 方法論

### 步驟 1：找出爭議或創新

選擇要追蹤的現象。跟著行動者走，不要硬套既有的範疇。

### 步驟 2：描繪行動元

列出網絡中所有相關的人類與非人類行動者（人、組織、技術、文件、標準、自然實體）。

### 步驟 3：追蹤轉譯的四個時刻（Callon, 1986）

| 時刻 | 說明 |
|--------|-------------|
| **問題化（Problematization）** | 一個焦點行動者定義問題，並把自己定位成義務通行點 |
| **利益賦予（Interessement）** | 裝置和策略把其他行動者鎖進被提議的角色 |
| **招募（Enrollment）** | 行動者接受並扮演被分配到的網絡角色 |
| **動員（Mobilization）** | 被招募的行動者開始代表更廣泛的群體，網絡因而穩定 |

### 步驟 4：評估網絡的穩定性

評估網絡是否撐得住，並注意抵抗、背叛或瓦解的點。

## 輸出格式

```markdown
## ANT Analysis: [Context]

### Focal Actor and Problematization
- Focal actor: [who/what defines the problem]
- Obligatory passage point: [the framing that makes the focal actor indispensable]

### Actant Map
| Actant | Type | Role in Network | Interests |
|--------|------|-----------------|-----------|
| [name] | [human/non-human] | [role] | [what they want] |

### Translation Process
1. **Problematization**: [how the problem was defined]
2. **Interessement**: [devices used to lock actors in]
3. **Enrollment**: [how actors accepted roles]
4. **Mobilization**: [how representatives stood for wider groups]

### Network Stability Assessment
- Stabilizing factors: ...
- Points of fragility: ...
- Black boxes formed: ...

### Implications
1. [Key insight about the network]
2. [What would happen if key actants were removed]
```

## 常見陷阱

- 「不要」把非人類當作單純的「脈絡」，它們在分析上必須有同等的份量
- ANT 不解釋網絡「為什麼」形成，它描述的是網絡「如何」形成
- 避免把「網絡」當成隱喻，在 ANT 中，網絡是經驗上追蹤出來的，不是預設的
- 研究者必須「跟著行動者走」，而不是從上方硬加範疇
- ANT 被批評缺乏規範性的力量，如果需要做評價，要搭配批判理論
- 當一個網絡穩定到內部運作變得看不見時，就發生了黑箱化（black-boxing）
