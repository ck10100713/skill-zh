# 行銷組合：4P / 7P

## 概述

4P（Product 產品、Price 價格、Place 通路、Promotion 推廣）框架用來整理戰術性的行銷決策。服務業要擴充成 7P，加上 People 人員、Process 流程和 Physical Evidence 實體證據。和 STP（策略層面）不同，行銷組合是**戰術性**的：STP 回答「要賣給誰？」之後，行銷組合回答「怎麼執行？」

## 何時使用

**觸發條件：**
- 使用者在規劃產品上市或 go-to-market
- 使用者需要稽核或重新設計行銷組合
- 使用者問「這個該怎麼定價？」、「該在哪裡賣？」或「要怎麼推廣？」
- 使用者已完成 STP，需要下一步

**何時不要用：**
- STP 還沒做之前，沒有目標的組合是失焦的
- 策略層級的決策 → 用 STP、SWOT 或 Ansoff
- 品牌識別的工作 → 用品牌定位

## 框架

```
鐵律：所有的 P 內部必須一致

4 個／7 個 P 必須互相強化。奢華的產品（Product）
定價卻很低（Price），還在折扣店販售（Place），
搭配大眾市場的廣告（Promotion），這是自相矛盾的。
每一個 P 都要講同一個故事。

定案之前，要檢查：「價格和產品相配嗎？通路和價格相配嗎？
推廣和通路相配嗎？」
```

```
鐵律：行銷組合跟隨 STP

組合必須是「為」STP 中找出的目標客群設計的。
不同客群需要不同的組合。沒有特定目標客群就設計的 4P，
只是猜的。
```

### 4P（產品與服務業皆適用）

**Product 產品**：你賣什麼
- 核心利益、功能、品質水準、設計、品牌
- 產品線的廣度與深度、包裝、保固
- 問題：「目標客群需要什麼？我們的產品怎麼滿足他們？」

**Price 價格**：客戶付多少
- 定價策略：成本加成、價值導向、競爭導向、滲透、吸脂
- 折扣、付款條件、目標客群的價格敏感度
- 問題：「目標客群願意付多少？價格傳達了我們什麼樣的定位？」

**Place 通路**：客戶怎麼拿到
- 配銷通路：直營、零售、線上、批發、市集平台
- 通路涵蓋：密集、選擇性、獨家
- 物流、庫存、地理上的可得性
- 問題：「目標客群期待在哪裡買？我們怎麼把產品送到那裡？」

**Promotion 推廣**：客戶怎麼得知
- 廣告、銷售促進、公關、人員銷售、數位行銷
- 內容行銷、社群媒體、網紅合作
- 問題：「目標客群從哪裡獲得資訊？什麼訊息能引起共鳴？」

### 擴充的 3P（服務業）

**People 人員**：誰提供服務
- 員工訓練、面對客戶的態度、招募標準
- 客戶在共創服務體驗中扮演的角色

**Process 流程**：服務怎麼提供
- 服務遞送的步驟、標準化 vs 客製化、等待時間
- 科技賦能、自助服務選項

**Physical Evidence 實體證據**：服務品質的有形線索
- 店面設計、網站 UX、制服、收據、包裝
- 客戶能看到、摸到或體驗到、並傳達品質訊號的任何東西

### 逐步做法

1. **確認目標客群**（來自 STP）
2. **針對目標設計每一個 P**
3. **檢查所有 P 之間的內部一致性**
4. **找出缺口**：哪一個 P 最弱？
5. **排定行動優先順序**：哪一個 P 對目標客群影響最大？

## 範例

### 正確的應用

**情境：** 一個高端台灣茶品牌，在便利商店賣瓶裝茶的 4P

| P | 決策 | 理由 |
|---|----------|-----------|
| 產品 | 冷泡單一產區烏龍、350ml 玻璃瓶、極簡標籤 | 高端定位需要高端的包裝，並和 PET 瓶茶明確區隔 |
| 價格 | NT$65（一般瓶裝茶是 NT$25-35） | 價值導向定價；目標客群（25-40 歲都會上班族）把茶視為小奢侈，不是大宗商品 |
| 通路 | 選擇性配銷：只放 7-ELEVEN 的 City Café 區，不上一般貨架 | 獨家陳列強化高端定位；City Café 區傳達「咖啡等級的品質」 |
| 推廣 | Instagram KOL 合作 + 店內試飲活動 | 目標客群追蹤生活風格 KOL；試飲活動降低高價位的嘗試門檻 |

**一致性檢查**：高端產品 ✓ → 高端價格 ✓ → 選擇性通路 ✓ → 嚮往感的推廣 ✓。所有的 P 都在講同一個故事。

### 錯誤的應用

**哪裡出錯：**
- 高端玻璃瓶茶（Product）賣 NT$25（Price），在每一家店都有（Place），還搭配降價促銷（Promotion）→ 每一個 P 都和高端定位矛盾。違反鐵律：內部一致性。
- 設計組合時沒有指定目標客群 → 決策沒有依據。違反鐵律：組合跟隨 STP。

## 常見陷阱

- **價格不只是一個數字**：價格傳達定位。7-ELEVEN 賣 NT$65 的茶，傳達的是「高端但平易近人」。賣 NT$25，傳達的是「大宗商品」。數字本身就是一則訊息。
- **通路決策很難回頭**：進入折扣通路會永久侵蝕高端定位。退出某個通路又會疏遠既有客戶。要謹慎選擇。
- **數位改變了通路和推廣**：對線上業務來說，Place = 平台（蝦皮 vs 自有網站 vs LINE 購物），Promotion = 內容 + 廣告 + SEO。框架依然適用。
- **所有服務業都適用 7P**：只要有真人在提供服務，就需要 People、Process 和 Physical Evidence。有客戶成功團隊的 SaaS 產品，就是服務業。
- **推廣 ≠ 只有廣告**：推廣包含公關、活動、銷售、合作、內容。不要預設就是「下廣告」，要讓管道對準目標客群會注意的地方。
