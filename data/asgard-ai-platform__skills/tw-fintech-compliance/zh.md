# 台灣金融科技合規

## 框架

```
IRON LAW: In Fintech, Regulation Comes BEFORE Product
（鐵律：在金融科技，法規先於產品）

不像多數科技產品可以先上線再迭代，台灣的金融服務
必須「先取得執照」。沒有適當執照就營運是刑事犯罪（不只是罰款）。
在寫任何程式碼「之前」，先確定你的監理類別和執照要求。
```

### 金管會監理框架

**金融監督管理委員會（FSC）** 監管台灣所有金融服務：

| 類別 | 適用法律 | 是否需要執照 | 金管會主管單位 |
|----------|-------------|-----------------|-------------|
| **電子支付** | 電子支付機構管理條例 | 電子支付機構許可 | 銀行局 |
| **第三方支付** | 第三方支付服務業管理辦法 | 登記（較輕） | 銀行局 |
| **P2P 借貸** | 金融科技發展與創新實驗條例（沙盒）或群眾募資規則 | 個案認定 | 證券期貨局 |
| **智能投顧** | 證券投資信託及顧問法 | 投資顧問執照 | 證券期貨局 |
| **保險科技** | 保險法 | 保險經紀人/代理人執照 | 保險局 |
| **VASP（加密貨幣）** | 虛擬資產服務提供者管理辦法（2024） | VASP 登記 + AML 合規 | 證券期貨局 |
| **開放銀行** | 金融機構間資料共享指引 | 與銀行建立 API 合作 | 銀行局 |

### 電子支付 vs 第三方支付

| 特性 | 電子支付 | 第三方支付 |
|---------|---------------------------|-------------------------------|
| 儲值 | 有（電子錢包） | 沒有（僅代收代付） |
| P2P 轉帳 | 可以 | 不行 |
| 資本額要求 | NT$500M 以上 | NT$5M |
| 執照 | 金管會核准（12-18 個月） | 登記（1-3 個月） |
| 例子 | LINE Pay Money、街口支付、icash Pay | 綠界 ECPay、藍新 NewebPay |

### VASP（加密貨幣）法規（2024 年起）

| 要求 | 細節 |
|------------|--------|
| 登記 | 必須向金管會登記為 VASP |
| AML/CFT | 完全遵循洗錢防制法 |
| KYC | 所有使用者都要身分驗證 |
| 保管 | 必須隔離客戶資產 |
| 行銷 | 廣告受限（不得承諾報酬） |
| 申報 | 向調查局申報可疑交易報告（STR） |

### AML/KYC 要求（所有金融服務）

| KYC 等級 | 何時需要 | 蒐集的資料 |
|-----------|-------------|---------------|
| **簡化** | 低風險、小額交易 | 姓名、身分證字號、出生日期 |
| **標準** | 開戶、多數交易 | + 地址、職業、資金來源 |
| **加強** | 高風險客戶、PEP、大額交易 | + 詳細的財富來源、持續監控 |

**持續性義務：**
- 交易監控（異常模式）
- 向法務部調查局申報可疑交易報告（STR）
- 制裁名單篩查（OFAC、UN、EU 名單）
- 紀錄保存：帳戶結清後 5 年以上

### 監理沙盒（金融科技創新實驗）

| 面向 | 細節 |
|--------|--------|
| 目的 | 在不需完整執照的情況下，測試創新金融服務 |
| 期間 | 最長 18 個月（可延長到 36 個月） |
| 申請 | 向金管會提交：創新說明、消費者保護計畫、風險評估 |
| 核准時間 | 60 個工作日 |
| 範圍限制 | 必須界定使用者人數、交易上限、地理範圍 |
| 退場計畫 | 取得完整執照的路徑，或有序結束 |

### 開放銀行（三個階段）

| 階段 | 共享的資料 | 狀態 |
|-------|-----------|--------|
| 第一階段 | 產品資訊（利率、費用） | 2019 年上線 |
| 第二階段 | 客戶資訊（經同意） | 2021 年上線 |
| 第三階段 | 交易發動（付款、轉帳） | 開發中 |

## 常見陷阱

- **第三方支付 vs 電子支付**：差別在於儲值。如果你的 app 持有客戶的錢（電子錢包），就需要重得多的電子支付執照（資本額 NT$500M）。如果只是處理付款（把錢從買家轉給賣家），第三方支付登記就夠了。
- **沙盒不是捷徑**：沙盒讓你暫時免於執照要求，但你還是必須遵守 AML、消費者保護和資料隱私。而且要商業化，你還是得取得完整執照。
- **VASP 法規很新，還在演變**：2024 年的 VASP 規則是台灣第一部完整的加密貨幣法規。預期會有修正和額外的指引。要建立有彈性、可調整的合規基礎設施。
- **外國金融科技進入台灣**：外國公司必須設立台灣的實體，並取得台灣專屬的執照。在其他司法管轄區的執照不能移轉過來。
- **這是教育性質的指引，不是法律/法規建議**：金融法規很複雜，違規的處罰包括刑事責任。請聘請專精台灣金融服務的法規事務律師。
