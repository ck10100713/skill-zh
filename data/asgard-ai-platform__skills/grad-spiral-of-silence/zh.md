# 沉默螺旋

## 概述

沉默螺旋理論（Noelle-Neumann，1974）解釋個人對意見氣候的感知（受媒體與社會觀察所影響），如何左右他們表達看法的意願。當人們覺得自己的意見屬於少數時，害怕被社會孤立，就會自我審查，形成一個螺旋：被感知為少數的那一方越縮越小。

## 何時使用

**觸發條件：**
- 分析為什麼某些意見會從公共討論中消失
- 研究感知到的意見氣候與發言意願之間的關係
- 評估媒體在塑造多數/少數意見認知上的角色

**何時不要使用：**
- 研究哪些議題受到關注（改用議題設定）
- 分析議題如何被詮釋（改用框架理論）
- 研究團體極化動態（改用社會認同理論）

## 假設

```
鐵律：螺旋「只」會在帶有道德色彩的議題上啟動

這個機制需要：
1. 議題必須帶有「道德色彩」（偏離主流會受到真實的社會制裁）
2. 個人具備「準統計感」：他們會持續觀察意見環境，
   判斷自己屬於多數還是少數
3. 「害怕孤立」促使人們順從：人們寧可沉默，
   也不願被社會排除
在價值中立或純事實性的議題上，意見氣候對表達意願幾乎沒有影響。
```

## 方法

### 步驟 1：找出議題
選一個帶有道德色彩、具爭議的議題，在這種議題上，持少數立場會受到社會制裁是合理的。

### 步驟 2：衡量對意見氣候的感知
對受訪者調查：(a) 自己的意見、(b) 他們認為的多數意見、(c) 他們認為的未來意見趨勢。

### 步驟 3：評估發言意願
使用「火車測驗」（Noelle-Neumann）：在漫長的火車旅程中，你願意跟陌生人討論這個話題嗎？衡量公開表達意見的意願。

### 步驟 4：分析螺旋
檢驗被感知為少數的身分，是否預測發言意願下降，並控制意見強度、人口特徵與媒體使用。

## 輸出格式

```markdown
# 沉默螺旋分析：{議題}

## 意見分布
- 實際意見分布：{調查資料}
- 感知到的多數：{人們「以為」大多數人相信什麼}
- 認知落差：{實際多數與感知多數之間的差距}

## 發言意願
- 自認屬於多數者：{表達意願}
- 自認屬於少數者：{表達意願}
- 螺旋證據：{自認少數者的發言意願是否較低？}

## 媒體的角色
- 媒體呈現的意見氣候：{媒體把哪一方呈現為主流}
- 一致性：{各家媒體呈現的意見氣候是否相近？}

## 調節因素
- 硬核份子：{不管氣候如何都會發言的人}
- 議題類型：{道德色彩的程度}
- 線上 vs 線下：{表達情境的差異}
```

## 常見陷阱

- **線上表達改變了動態：** 社群媒體可能削弱螺旋（匿名降低了害怕孤立的程度），也可能強化它（群起圍攻、取消文化）。原始理論早於數位傳播。
- **硬核份子存在：** 不是每個人都會自我審查。「硬核份子」和意見領袖不管感知到的氣候如何都會發言。螺旋適用的是順從的多數。
- **媒體的一致性是關鍵：** 螺旋需要媒體「一致」，如果各家媒體呈現的意見氣候不同，個人收到的是混雜的訊號，螺旋就會減弱。
- **文化差異：** 害怕孤立的程度因文化而異。個人主義文化的螺旋可能比順從規範較強的集體主義文化來得弱。
- **參照團體很重要：** 人們是在自己的「參照團體」裡評估意見氣候，不是整個社會。一個人可能在全球是少數，卻在當地是多數。
