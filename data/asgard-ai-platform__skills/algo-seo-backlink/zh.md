# 反向連結品質評估（Backlink Quality Assessment）

## 概述

反向連結分析會用品質指標（DA/DR、相關性、錨點文字多樣性、毒性）評估外部連入的連結，藉此評估網站站外 SEO 的強度。品質評估是啟發式的，用第三方指標（Moz DA、Ahrefs DR）當作 PageRank 的代理。

## 何時使用

**觸發條件：**
- 要稽核網站的反向連結檔案，檢視 SEO 健康度
- 要找出並 disavow 有毒或垃圾的連結
- 要依競爭對手分析來規劃連結建置策略

**何時不要用：**
- 要最佳化站內內容時（用內容 SEO）
- 要從原始連結圖計算真正的 PageRank 時（用 PageRank 演算法）

## 演算法

```
鐵律：反向連結的「品質」重於數量
一個來自高權威、主題相關網域的連結，
比數百個來自低品質網站的連結更有價值。
每個連結都要從以下幾點評估：
1. 權威度（連出網域的 DA/DR）
2. 相關性（連出頁面和目標頁面的主題吻合度）
3. 位置（編輯內文中的 > 頁尾／側邊欄）
4. 錨點文字（自然多樣 > 完全比對的關鍵字堆砌）
```

### 階段 1：輸入驗證
從 Ahrefs、Moz 或 Search Console 匯出反向連結資料。必要欄位：參照網域、DA/DR、錨點文字、連結類型（dofollow/nofollow）、首次發現日期。
**關卡：** 完整的反向連結匯出，並附有權威度指標。

### 階段 2：核心演算法
1. 依參照網域去重（分析時每個網域只算一個連結）
2. 替每個連結評分：權威度（0-100）× 相關性（0-1）× 位置權重
3. 標記有毒連結：DA < 10、不相關的外語、連結農場模式、PBN 跡象
4. 計算檔案指標：參照網域總數、DR 分布、錨點文字多樣性指數

### 階段 3：驗證
把標記為有毒的連結，和已知的垃圾資料庫交叉比對。驗證錨點文字的分布符合自然的模式（品牌 > URL > 關鍵字 > 其他）。
**關卡：** 有毒連結已辨識、錨點檔案已分析。

### 階段 4：輸出
回傳檔案評估，附上連結品質分布和行動項目。

## 輸出格式

```json
{
  "profile": {"referring_domains": 450, "avg_dr": 35, "toxic_count": 23, "anchor_diversity": 0.78},
  "actions": [{"type": "disavow", "domains": ["spam1.com"], "reason": "link farm pattern"}],
  "metadata": {"tool": "ahrefs", "export_date": "2025-01-15"}
}
```

## 範例

### 輸入輸出範例
**輸入：** 500 個反向連結、200 個參照網域
**預期：** 分布：15% DR 60 以上、40% DR 20-59、45% DR 0-19。標記 23 個有毒網域要 disavow。

### 邊界情況
| 輸入 | 預期 | 原因 |
|-------|----------|-----|
| 所有連結都來自同一個網域 | 檔案多樣性低 | 依賴單一來源有風險 |
| 90% 是完全比對的錨點 | 有錨點文字被懲罰的風險 | 不自然的錨點模式 |
| 零反向連結 | 先專注在內容 | 不存在的東西沒辦法最佳化 |

## 常見陷阱

- **DA/DR 是第三方的估計值**：它們是 PageRank 的近似，但「不是」Google 的指標。兩個工具對同一個網域的權威度常常有出入。
- **Nofollow 仍然重要**：Google 把 nofollow 當作「提示」。來自 DR 90 網站的 nofollow 連結仍有 SEO 價值，只是比 dofollow 少。
- **謹慎 disavow**：Google 的 disavow 工具是最後手段。disavow 正當的連結會傷害你自己的檔案。只對明確有毒／垃圾的連結做 disavow。
- **錨點文字的操弄**：完全比對的錨點文字以前是排名因素，現在是垃圾訊號。自然的檔案，錨點大多是品牌和 URL。
- **時間模式**：反向連結突然暴增（例如一天 100 個）會觸發垃圾過濾器。自然的連結取得是漸進的。
