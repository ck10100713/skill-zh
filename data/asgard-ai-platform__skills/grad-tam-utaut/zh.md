# 科技接受模型（TAM）與 UTAUT

## 概述

TAM 主張，知覺有用性（PU）與知覺易用性（PEOU）決定使用技術的行為意圖。UTAUT 把先前八個模型整合成四個核心構念：績效期望、努力期望、社會影響與促成條件，並由年齡、性別、經驗與自願性來調節。

## 何時使用

- 預測使用者對新技術或新系統的採用
- 診斷技術推行為什麼採用率低
- 設計提升接受率的介入措施
- 比較不同使用者族群的採用驅動因素

## 何時不要使用

- 採用後的持續使用（改用期望確認模型）
- 組織層級的擴散（改用 DOI 或 TOE 框架）
- 採用是強制的，沒有行為上的變異

## 假設

```
鐵律：技術採用是由「知覺到的」價值驅動，不是實際的能力。
一個知覺有用性很差的優秀系統會被拒絕，
一個被認為有用的較差系統卻會被採用。
```

關鍵假設：
1. 使用者是理性的行為者，會在行為之前先形成意圖
2. 知覺可以透過自陳式工具來測量
3. 外部變數只透過核心構念來影響採用
4. 行為意圖是實際使用的主要預測因子

## 方法

### 步驟 1：定義技術與使用者群體

指明要評估的系統、目標使用者與使用情境。確認採用是自願還是強制的。

### 步驟 2：測量核心構念

**TAM 構念：**
- 知覺有用性（PU）：「使用 X 能提升我的工作績效」
- 知覺易用性（PEOU）：「使用 X 不費力」

**UTAUT 構念：**
| 構念 | 定義 | TAM 對應 |
|-----------|-----------|----------------|
| 績效期望 | 系統對工作績效有幫助的程度 | PU |
| 努力期望 | 使用系統的容易程度 | PEOU |
| 社會影響 | 重要的人認為我應該使用 | 主觀規範 |
| 促成條件 | 基礎設施支持使用 | （外部） |

### 步驟 3：找出調節因素與障礙

描繪調節變數：年齡、性別、經驗、自願性。針對每個構念找出具體的障礙（例如訓練不足 → 努力期望偏低）。

### 步驟 4：設計介入措施

針對最弱的構念，用具體的介入措施處理：訓練（努力）、展示價值（績效）、推廣大使計畫（社會）、IT 支援（促成）。

## 常見陷阱

- TAM 解釋的是意圖，不是實際的持續使用，要做長期預測，需加入習慣與持續使用的構念
- 隨著使用者累積經驗，PEOU 的影響會遞減，長期來看 PU 會佔主導
- 社會影響在強制情境下，以及對早期採用者最重要
- 自陳式偏誤會膨脹構念之間的相關（共同方法變異）
- UTAUT2 為消費者情境增加了享樂動機、價格價值與習慣
- 文化背景會改變構念的權重，不要假設西方驗證出來的權重普遍適用
