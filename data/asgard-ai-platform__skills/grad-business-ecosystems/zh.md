# 商業生態系（Moore）

## 概述

Moore 的商業生態系框架把產業概念化為由企業、顧客和其他利害關係人組成的共同演化社群，他們共同創造並獲取價值。生態系會經歷四個階段（誕生、擴張、領導、更新），參與者占據不同的角色：關鍵物種（keystone）、支配者（dominator）或利基玩家（niche player），各有不同的策略，也對生態系的健康度有不同的影響。

## 何時使用

- 分析以平台為基礎的市場，或多家企業共同創造價值的網絡
- 評估在產業生態系中的策略定位
- 評估一個生態系為什麼蓬勃、停滯或崩解
- 規劃進入既有生態系的策略，或設計一個新的生態系

## 何時不要用

- 產業最適合用原子式競爭來建模時（沒有共同演化）
- 分析聚焦在單一企業的內部策略時（用 RBV 或動態能力）
- 需要有契約明確性的正式供應鏈分析時

## 假設

```
IRON LAW: Ecosystem health depends on DIVERSITY and PRODUCTIVITY — a
dominant player that extracts too much value destroys the ecosystem
it depends on.
```

關鍵假設：
1. 企業是共同演化的，策略被更廣大的生態系所形塑，也反過來形塑它
2. 價值是集體創造的，並分配給生態系的參與者
3. 生態系的領導需要培育生態系，不只是獲取價值
4. 生態系有生命週期，在誕生階段有效的做法，到了更新階段會失效

## 方法論

### 步驟 1：定義生態系的邊界

找出生態系：核心價值主張、平台或焦點企業，以及主要的參與者類別（供應商、互補者、顧客、競爭者）。

### 步驟 2：評估生態系的階段

| 階段 | 特徵 | 關鍵挑戰 |
|-------|----------------|---------------|
| **誕生（Birth）** | 創業者圍繞一項種子創新來定義價值主張 | 保護構想、建立最初的夥伴關係 |
| **擴張（Expansion）** | 擴大到廣大的市場、吸引互補者 | 達到臨界質量、抵禦其他生態系 |
| **領導（Authority）** | 架構穩定、領導者明確、標準確立 | 維持議價能力、鼓勵持續創新 |
| **更新（Renewal）** | 成熟的生態系面臨顛覆或停滯 | 重新創造自己，否則被新的生態系取代 |

### 步驟 3：描繪生態系的角色

分類主要的參與者：關鍵物種（創造共享價值、維持平台的健康）、支配者（獲取大部分價值、控制生態系）、利基玩家（專精在狹窄的區隔）。

### 步驟 4：評估生態系的健康度

評估三項健康指標：生產力（每位參與者創造的價值）、穩健性（參與者的存活率）和利基創造（角色與機會的多樣性）。

## 輸出格式

```markdown
## Ecosystem Analysis: [Context]

### Ecosystem Definition
- Core value proposition: [what the ecosystem delivers]
- Focal firm/platform: [the central orchestrator]
- Key participants: [complementors, suppliers, customers, competitors]

### Stage Assessment
- Current stage: [birth / expansion / authority / renewal]
- Evidence: [indicators supporting this assessment]
- Trajectory: [evolving toward which next stage]

### Role Map
| Participant | Role | Value Created | Value Captured | Strategy |
|-------------|------|---------------|----------------|----------|
| [name] | [keystone/dominator/niche] | [contribution] | [share] | [approach] |

### Health Assessment
- Productivity: [high/medium/low] — [evidence]
- Robustness: [high/medium/low] — [evidence]
- Niche creation: [high/medium/low] — [evidence]
- Overall health: [thriving / stable / declining / collapsing]

### Implications
1. [Strategic recommendation for target firm]
2. [Risk of ecosystem decline and mitigation]
```

## 常見陷阱

- 生態系「不是」「產業」的隱喻，它特別意味著共同演化和相互依賴
- 關鍵物種策略不是利他，而是維持價值網絡的開明利己
- 支配者策略短期可能成功，但長期往往會破壞生態系的健康
- 平台生態系加入了 Moore 原本的生物學隱喻中沒有的網絡效應動態
- 不要假設單一企業控制了生態系，領導權可能轉移，尤其是在更新階段
- 這四個階段不是決定論的，生態系可能跳過階段或倒退
