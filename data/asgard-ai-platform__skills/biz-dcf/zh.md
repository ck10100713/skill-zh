# 現金流量折現（DCF）估值

## 概述

DCF 透過預測未來的自由現金流，並用 WACC 折現到現值，來估算公司的內在價值。它回答的是「這個事業根據未來創造現金的能力，值多少錢？」

## 何時使用

**觸發條件：**
- 使用者需要替公司或事業單位估值
- 使用者在評估併購標的或投資機會
- 使用者問「合理價格是多少？」或「建一個估值模型」

**何時不要用：**
- 還沒有營收的早期新創 → 用可比公司法或創投法
- 快速的相對估值 → 用倍數（P/E、EV/EBITDA）
- 投資組合層級的決策 → 用 BCG 矩陣

## 框架

```
鐵律：垃圾進，垃圾出

DCF 的輸出，只會和它的假設一樣好。每一個假設（成長率、利潤率、
WACC、終值成長率）都必須明確列出，並附上理由。
沒有假設表的 DCF 一文不值。
```

```
鐵律：終值占主導，處理要小心

終值通常占 DCF 總價值的 60-80%。如果你的終值成長率超過
長期 GDP 成長（約 2-3%），就等於暗示這家公司最終會比整個經濟體還大。
終值成長率要以無風險利率或 GDP 成長為上限。
```

### 步驟 1：預測自由現金流（5-10 年）

```
FCF = EBIT × (1 - 稅率) + 折舊 - 資本支出 - Δ營運資金
```

預測的依據：
- 營收成長假設（由上而下或由下而上）
- 營業利益率的走勢
- 資本支出需求
- 營運資金的變動

### 步驟 2：計算 WACC

```
WACC = (E/V × Re) + (D/V × Rd × (1 - 稅率))
```

其中：
- Re = 股權成本（用 CAPM：Rf + β × 市場風險溢酬）
- Rd = 債務成本（借款的利率）
- E/V = 股權權重，D/V = 債務權重

### 步驟 3：計算終值

**Gordon 成長模型（建議）：**
```
TV = FCF_final × (1 + g) / (WACC - g)
```
其中 g = 終值成長率（上限 2-3%）

**退出倍數法（替代方案）：**
```
TV = EBITDA_final × EV/EBITDA 倍數
```

### 步驟 4：折現到現值

```
企業價值 = Σ FCFt / (1 + WACC)^t + TV / (1 + WACC)^n
股權價值 = 企業價值 - 淨負債
每股價值 = 股權價值 / 流通在外股數
```

### 步驟 5：敏感度分析

測試關鍵假設：WACC（±1%）、終值成長率（±0.5%）、營收成長（±2%）。以敏感度表呈現。

## 範例

### 正確的應用
**情境：** 一家台灣 SaaS 公司的 DCF（ARR NT$500M，成長 25%）
- 預測 5 年的 FCF，成長率遞減（25% → 15%）
- WACC 10.5%（有理由：Rf 1.5%、β 1.2、ERP 6%、債務成本 4%）
- 終值成長率 2.5%（以台灣 GDP 成長為代理）
- TV = 企業價值的 72%，在正常範圍內 ✓
- 敏感度表顯示 WACC ±1% 下的 $X 區間

### 錯誤的應用
- 終值成長率 8% → 暗示這家公司會永遠比經濟體成長得更快。違反鐵律。
- 沒有假設表，只寫「企業價值 = NT$2.5B」→ 沒有辦法驗證。違反鐵律。

## 常見陷阱

- **終值的敏感度**：終值成長率或 WACC 的小幅變動，就會讓估值擺盪 20-30%。一定要呈現一個區間，不要只給點估計。
- **WACC 的循環參照**：WACC 需要股權價值（市值），但 DCF 算的就是股權價值。要用迭代，或使用目標資本結構。
- **FCF vs 淨利**：DCF 用的是自由現金流，不是盈餘。資本支出或營運資金需求高的公司，可能盈餘為正，但 FCF 為負。
- **國家風險溢酬**：對台灣／新興市場的公司，要在 WACC 上加國家風險溢酬（通常 1-3%）。
- **早期年度的 FCF 為負**：成長型公司一開始可能 FCF 為負。這沒關係，價值來自後面幾年和終值。
