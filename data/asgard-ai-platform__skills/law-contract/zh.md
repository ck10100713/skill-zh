# 契約分析

## 概述

契約法規範具有執行力的協議。這個 skill 涵蓋商業契約的成立要件、必備條款與常見的風險區域。內容屬於教育性質的指引，不是法律意見，針對具體情況，一定要諮詢合格的律師。

## 框架

```
鐵律：契約需要要約 + 承諾 + 對價 + 合法性

四個要素必須全部具備，契約才有效。缺任何一個，
就不存在有執行力的契約，不管文件看起來多正式。
沒有對價（價值的交換）的簽署文件，不是契約。
```

### 契約的成立

| 要素 | 定義 | 檢驗 |
|---------|-----------|------|
| **要約** | 明確、確定、有受拘束意思的提議 | 一個理性的人會把它理解成有拘束力的提議嗎？ |
| **承諾** | 對要約條款的無保留同意 | 鏡像規則：承諾必須與要約完全一致 |
| **對價** | 雙方交換的有價值之物 | 每一方都放棄了某些東西（金錢、服務、權利、承諾） |
| **合法性** | 標的必須合法，當事人必須有行為能力 | 沒有違法的目的；當事人必須是有能力的成年人或有授權的實體 |

### 契約的必備條款

| 條款 | 目的 | 警訊 |
|--------|---------|-----------|
| **當事人** | 誰受拘束 | 實體名稱不正確、沒有簽署權限 |
| **範圍/標的** | 交換的是什麼 | 交付物含糊、用語未定義 |
| **付款條件** | 何時、如何付款 | 沒有付款時程、逾期付款沒有後果 |
| **期間與終止** | 期限與退出條件 | 未經通知就自動續約、沒有因違約而終止的條款 |
| **責任與賠償** | 誰承擔風險 | 無限責任、單方面的賠償 |
| **保密（NDA）** | 資訊保護 | 定義過於寬泛、沒有期限 |
| **智慧財產權歸屬** | 誰擁有產出的成果 | 工作成果的歸屬不明確 |
| **競業禁止** | 終止後的限制 | 範圍/地域/期間過於寬泛 |
| **爭議解決** | 如何解決衝突 | 外國管轄、未經同意的強制仲裁 |
| **不可抗力** | 因不可預見的事件而免除履行 | 定義過窄或過寬 |

### 契約審閱步驟

1. **找出當事人**：誰同意？實體名稱正確嗎？
2. **理解交易內容**：每一方給出什麼、得到什麼？
3. **檢查成立要件**：要約、承諾、對價、合法性，都具備嗎？
4. **審閱必備條款**：用上面的表當檢核清單
5. **標出風險區域**：無限責任、單方面條款、範圍含糊、自動續約
6. **檢查準據法**：適用哪個司法管轄區的法律？爭議解決機制可以接受嗎？

## 範例

### 正確的應用
**情境：** 審閱 SaaS 服務協議
- **警訊**：「供應商得以 30 天的通知調整價格」 → 單方面的調價條款。應該是：合約期間內價格鎖定，只在續約時調整。
- **警訊**：「客戶就所有請求向供應商負賠償責任」 → 單方面的賠償。應該是雙方互相賠償。
- **缺漏**：沒有定義 SLA（服務水準協議） → 服務中斷時無從追索。建議加入附帶補償點數的可用時間承諾 ✓

### 不正確的應用
- 「這份契約看起來沒問題，因為雙方都簽了」 → 簽名不會讓每個條款都公平或有執行力。必須審閱個別的條款內容。簽署過的契約裡若有顯失公平的條款，仍可能被挑戰。

## 常見陷阱

- **「標準契約」不代表公平：** 供應商擬定的「標準」契約，是偏向供應商的。一切都可以談。
- **台灣特有的情況：** 台灣的民法規範契約。與普通法的主要差異：沒有對價的要求（以承諾換承諾就足夠）、某些契約類型（勞動、消費）有強制規定。
- **自動續約陷阱：** 許多契約除非在到期前 30-90 天通知，否則會自動續約。把通知的期限記進行事曆。
- **這個 skill 不是法律意見：** 它提供的是契約概念的教育性分析。要做有拘束力的法律決定，一定要諮詢有執照的律師。
