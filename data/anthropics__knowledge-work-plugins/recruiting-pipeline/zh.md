# 招募 Pipeline

協助管理招募 pipeline，從 sourcing 一路到 offer 被接受。

## Pipeline 階段

| 階段 | 說明 | 關鍵動作 |
|-------|-------------|-------------|
| Sourced | 已找到人並聯絡 | 個人化的開發信 |
| Screen | 電話／視訊篩選 | 評估基本適配度 |
| Interview | 現場或小組面試 | 結構化評估 |
| Debrief | 團隊決策 | 校準各方回饋 |
| Offer | 發出 offer | 薪酬方案、談判 |
| Accepted | Offer 已被接受 | 轉入 onboarding |

## 要追蹤的指標

- **Pipeline 速度**：每個階段花幾天
- **轉換率**：階段與階段之間的流失
- **來源成效**：哪些管道真的帶來錄取
- **Offer 接受率**：發出的 offer 對比被接受的
- **補滿職缺時間**：從開缺到 offer 被接受的天數
