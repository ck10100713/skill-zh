# Journal Entry Preparation

**重要**：這個 skill 協助處理分錄工作流程，但不提供財務建議。所有分錄在過帳前都應該由合格的財務專業人員審閱。

會計分錄準備的最佳實務、標準分錄類型、文件要求和審閱流程。

## 標準應計類型與其分錄

### 應付帳款應計

對期末已收到貨品或服務、但尚未開發票的部分做應計。

**典型分錄：**
- 借方：費用科目（符合資產條件的就資本化）
- 貸方：應計負債

**計算來源：**
- 已確認收貨的未結採購單
- 服務已提供但尚未開立帳單的合約
- 經常性的供應商安排（水電、訂閱、專業服務）
- 已提交但尚未處理的員工費用報告

**重要考量：**
- 在下一期迴轉（建議自動迴轉）
- 各期使用一致的估計方法
- 記錄估計的依據（採購單金額、合約條款、歷史平均值）
- 追蹤實際金額與應計金額的差異，以修正未來的估計

### 固定資產折舊

入帳有形和無形資產的定期折舊費用。

**典型分錄：**
- 借方：折舊或攤銷費用（依部門或成本中心）
- 貸方：累計折舊或累計攤銷

**折舊方法：**
- **直線法：** (成本 - 殘值) / 耐用年限，財務報告最常用
- **餘額遞減法：** 加速折舊法，對淨帳面價值套用固定比率
- **生產數量法：** 依實際使用量或產出量，相對於預期總量

**重要考量：**
- 依固定資產登記簿或明細表跑折舊
- 確認新增資產設定了正確的耐用年限和方法
- 檢查是否有需要沖銷的處分或減損
- 確保帳上與稅務折舊的追蹤一致

### 預付費用攤銷

把預付費用在其效益期間內攤銷。

**典型分錄：**
- 借方：費用科目（保險、軟體、租金等）
- 貸方：預付費用

**常見的預付類別：**
- 保險費（通常是 12 個月的保單）
- 軟體授權和訂閱
- 預付租金（如果租約條款適用）
- 預付維護合約
- 研討會和活動的訂金

**重要考量：**
- 維護一份攤銷明細表，載明起訖日期和每月金額
- 檢視有沒有應該一次全數費用化的預付項目（金額不重大的）
- 檢查有沒有已取消或終止、需要加速攤銷的合約
- 確認新的預付項目有及時加進明細表

### 薪資應計

對本期的薪酬和相關成本做應計。

**典型分錄：**

*薪水應計（針對發薪期間與月底不一致的情況）：*
- 借方：薪資費用（依部門）
- 貸方：應計薪資

*獎金應計：*
- 借方：獎金費用（依部門）
- 貸方：應計獎金

*福利應計：*
- 借方：福利費用
- 貸方：應計福利

*薪資稅應計：*
- 借方：薪資稅費用
- 貸方：應計薪資稅

**重要考量：**
- 薪水應計依本期工作日數相對於發薪期間來計算
- 獎金應計要反映計畫條款（目標金額、績效指標、發放時間）
- 包含雇主負擔的稅金和福利（FICA、FUTA、健康保險、401k 配合提撥）
- 如果政策或司法管轄區要求，要追蹤特休或休假的應計負債

### 收入認列

依履約義務和交付情況認列收入。

**典型分錄：**

*認列先前遞延的收入：*
- 借方：遞延收入
- 貸方：收入

*認列收入並產生新的應收帳款：*
- 借方：應收帳款
- 貸方：收入

*遞延預先收到的收入：*
- 借方：現金 / 應收帳款
- 貸方：遞延收入

**重要考量：**
- 客戶合約依 ASC 606 的五步驟架構
- 找出每份合約中各自獨立的履約義務
- 決定交易價格（包含變動對價）
- 把交易價格分攤到各履約義務
- 在履約義務被滿足時（或隨著滿足）認列收入
- 保留合約層級的明細，作為稽核佐證

## 佐證文件的要求

每筆會計分錄都應該有：

1. **分錄說明/備註：** 清楚、具體地說明這筆分錄記錄什麼、為什麼
2. **計算佐證：** 金額是怎麼算出來的（公式、明細表、來源資料參照）
3. **來源文件：** 指向底層交易或事件的參照（採購單號、發票號碼、合約參照、薪資登記表）
4. **期間：** 這筆分錄適用的會計期間
5. **編製者識別：** 誰在什麼時候編製這筆分錄
6. **核准：** 依授權矩陣，有審閱和核准的證據
7. **迴轉指標：** 這筆分錄是否自動迴轉，以及迴轉日期

## 審閱與核准流程

### 典型的核准矩陣

| 分錄類型 | 金額門檻 | 核准人 |
|-----------|-----------------|----------|
| 標準經常性 | 任何金額 | 會計經理 |
| 非經常性 / 手動 | < $50K | 會計經理 |
| 非經常性 / 手動 | $50K - $250K | Controller |
| 非經常性 / 手動 | > $250K | CFO / 財務副總 |
| 頂層 / 合併 | 任何金額 | Controller 或更高層級 |
| 跨期調整 | 任何金額 | Controller 或更高層級 |

*注意：門檻應依貴組織的重大性和風險承受度來設定。*

### 審閱檢查清單

核准會計分錄之前，審閱者應確認：

- [ ] 借方等於貸方（分錄是平衡的）
- [ ] 會計期間正確（沒有過帳到已關閉的期間）
- [ ] 科目代碼存在，且適合這筆交易
- [ ] 金額在數學上正確，並有計算佐證
- [ ] 說明清楚、具體，足以供稽核之用
- [ ] 部門/成本中心/專案編碼正確
- [ ] 處理方式與前期和會計政策一致
- [ ] 自動迴轉設定得當（應計項目應該迴轉）
- [ ] 佐證文件完整並有引用
- [ ] 分錄金額在編製者的權限範圍內
- [ ] 沒有跟既有分錄重複
- [ ] 不尋常或大額的金額有說明並有正當理由

## 要檢查的常見錯誤

1. **分錄不平衡：** 借方不等於貸方（系統應該會防止，但手動分錄要檢查）
2. **期間錯誤：** 分錄過帳到錯誤或已關閉的期間
3. **正負號錯誤：** 借方記成貸方，或反過來
4. **重複分錄：** 同一筆交易記錄了兩次（過帳前先檢查是否重複）
5. **科目錯誤：** 分錄過帳到錯誤的總帳科目（尤其是代碼相近的科目）
6. **漏掉迴轉：** 應計分錄沒有設成自動迴轉，造成重複計算
7. **過時的應計：** 經常性的應計沒有隨情況變動而更新
8. **整數估計：** 可疑的整數金額，可能不是實際計算的結果
9. **匯率錯誤：** 外幣分錄用了錯誤的匯率或日期
10. **漏掉內部往來沖銷：** 實體之間的分錄沒有對應的沖銷
11. **資本化錯誤：** 應該資本化的費用，或是應該費用化的資本化項目
12. **截止錯誤：** 依交付或服務日期，交易記錄在錯誤的期間
