# Journal Entry Preparation

> 如果看到不認識的佔位符，或需要確認目前連了哪些工具，請看 [CONNECTORS.md](../../CONNECTORS.md)。

**重要**：這個指令協助處理分錄工作流程，但不提供財務建議。所有分錄在過帳前都應該由合格的財務專業人員審閱。

準備借貸正確、附佐證明細和審閱文件的會計分錄。

## 用法

```
/je <type> <period>
```

### 參數

- `type`：分錄類型。以下擇一：
  - `ap-accrual`：已收到貨品或服務但尚未開發票的應付帳款應計
  - `fixed-assets`：固定資產和無形資產的折舊與攤銷分錄
  - `prepaid`：預付費用（保險、軟體、租金等）的攤銷
  - `payroll`：薪資應計，包括薪水、福利、稅金和獎金應計
  - `revenue`：收入認列分錄，包括遞延收入調整
- `period`：會計期間（例如 `2024-12`、`2024-Q4`、`2024`）

## 工作流程

### 1. 收集來源資料

如果有連上 ~~erp 或 ~~data warehouse：
- 拉出指定期間的試算表
- 拉出相關科目的明細帳
- 拉出前期同類型的分錄當參考
- 找出受影響科目目前的總帳餘額

如果沒有連上資料來源：
> 連上 ~~erp 或 ~~data warehouse，就能自動拉總帳資料。你也可以貼上試算表資料或上傳試算表。

請使用者提供：
- 受影響科目的試算表或總帳餘額
- 明細帳或佐證明細表
- 前期分錄當參考（選填）

### 2. 計算分錄

依 JE 類型：

**AP Accrual（應付帳款應計）：**
- 找出期末已收到但尚未開發票的貨品或服務
- 依採購單收貨、合約或估計值算出應計金額
- 借方：費用科目（可資本化的項目則用資產科目）
- 貸方：應計負債

**Fixed Assets（固定資產）：**
- 拉出固定資產登記簿或折舊明細表
- 依資產類別和方法（直線法、餘額遞減法、生產數量法）算出本期折舊
- 借方：折舊費用（依部門或成本中心）
- 貸方：累計折舊

**Prepaid（預付費用）：**
- 拉出預付費用攤銷明細表
- 算出每個預付項目的本期攤銷
- 借方：費用科目（依類型，例如保險、軟體、租金等）
- 貸方：預付費用科目

**Payroll（薪資）：**
- 計算已工作但尚未發放的天數的應計薪資
- 計算應計福利（健康保險、退休金提撥、特休）
- 計算雇主的薪資稅應計
- 計算獎金應計（如適用，依計畫條款）
- 借方：薪資費用、福利費用、薪資稅費用
- 貸方：應計薪資、應計福利、應計薪資稅

**Revenue（收入）：**
- 審閱合約和履約義務
- 依交付或履約情況算出應認列的收入
- 調整遞延收入餘額
- 借方：遞延收入（或應收帳款）
- 貸方：收入科目（依收入來源或類別）

### 3. 產生會計分錄

用標準格式呈現分錄：

```
Journal Entry: [類型] — [期間]
Prepared by: [使用者]
Date: [期間結束日]

| Line | Account Code | Account Name | Debit | Credit | Department | Memo |
|------|-------------|--------------|-------|--------|------------|------|
| 1    | XXXX        | [名稱]       | X,XXX |        | [部門]     | [明細] |
| 2    | XXXX        | [名稱]       |       | X,XXX  | [部門]     | [明細] |
|      |             | **Total**    | X,XXX | X,XXX  |            |      |

Supporting Detail:
- [計算依據和假設]
- [佐證明細表或文件的參照]

Reversal: [Yes/No — 若是，註明迴轉日期]
```

### 4. 審閱檢查清單

定稿前，確認：

- [ ] 借方等於貸方
- [ ] 會計期間正確
- [ ] 科目代碼有效，且對應到正確的總帳科目
- [ ] 金額計算正確，並附有佐證明細
- [ ] 備註或說明夠清楚、夠具體，足以供稽核使用
- [ ] 部門或成本中心的編碼正確
- [ ] 分錄與前期的處理方式一致
- [ ] 迴轉旗標設定得當（應計項目應該自動迴轉）
- [ ] 佐證文件已引用或附上
- [ ] 分錄在使用者的核准權限範圍內
- [ ] 沒有需要調查的不尋常或不符合慣例的金額

### 5. 輸出

提供：
1. 格式化好的會計分錄
2. 佐證計算
3. 與前期同類型分錄的比較（如有）
4. 任何標記要審閱或後續追蹤的項目
5. 過帳說明（手動輸入，或是適用於使用者 ERP 的上傳格式）
