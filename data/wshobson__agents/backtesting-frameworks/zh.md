# 回測框架

建構穩健、可上線等級的回測系統，避開常見的陷阱，產出可靠的策略績效估計。

## 何時使用這個 Skill

- 開發交易策略的回測
- 建構回測基礎設施
- 驗證策略績效
- 避開常見的回測偏誤
- 實作 walk-forward 分析
- 比較不同的策略方案

## 核心概念

### 1. 回測偏誤

| 偏誤             | 說明               | 緩解方式              |
| ---------------- | ------------------------- | ----------------------- |
| **Look-ahead**   | 使用未來的資訊  | Point-in-time 資料      |
| **Survivorship** | 只在存活下來的標的上測試 | 納入已下市的證券 |
| **Overfitting**  | 對歷史資料做曲線擬合  | 樣本外測試   |
| **Selection**    | 只挑好看的策略 | 預先註冊        |
| **Transaction**  | 忽略交易成本    | 真實的成本模型   |

### 2. 正確的回測結構

```
Historical Data
      │
      ▼
┌─────────────────────────────────────────┐
│              Training Set               │
│  (Strategy Development & Optimization)  │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│             Validation Set              │
│  (Parameter Selection, No Peeking)      │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│               Test Set                  │
│  (Final Performance Evaluation)         │
└─────────────────────────────────────────┘
```

### 3. Walk-Forward 分析

```
Window 1: [Train──────][Test]
Window 2:     [Train──────][Test]
Window 3:         [Train──────][Test]
Window 4:             [Train──────][Test]
                                     ─────▶ Time
```

## 最佳實務

### 該做的

- **用 point-in-time 資料** - 避免前視偏誤
- **納入交易成本** - 要有貼近真實的估計
- **做樣本外測試** - 一定要保留資料
- **用 walk-forward** - 不要只做 train/test
- **蒙地卡羅分析** - 了解不確定性

### 不該做的

- **不要過度擬合** - 限制參數數量
- **不要忽略存活者偏誤** - 要納入已下市的標的
- **不要隨便使用調整過的資料** - 要了解做了哪些調整
- **不要用完整歷史資料做最佳化** - 要保留測試集
- **不要忽略容量** - 市場衝擊很重要
