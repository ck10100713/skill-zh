# 混合搜尋實作

結合向量相似度與關鍵字搜尋的模式。

## 什麼時候用這個 Skill

- 建構召回率更高的 RAG 系統
- 結合語意理解與精確比對
- 處理帶有特定詞彙（名稱、代碼）的查詢
- 改善針對特定領域詞彙的搜尋
- 純向量搜尋漏掉關鍵字命中的時候

## 核心概念

### 1. 混合搜尋架構

```
Query → ┬─► Vector Search ──► Candidates ─┐
        │                                  │
        └─► Keyword Search ─► Candidates ─┴─► Fusion ─► Results
```

### 2. 融合方法

| 方法              | 說明                     | 最適合          |
| ----------------- | ------------------------ | --------------- |
| **RRF**           | Reciprocal Rank Fusion   | 通用            |
| **Linear**        | 分數的加權總和           | 可調整的平衡    |
| **Cross-encoder** | 用神經網路模型重新排序   | 品質最高        |
| **Cascade**       | 先過濾再重新排序         | 效率            |

## 最佳實務

### 該做的

- **憑經驗調整權重**：用你自己的資料測試
- **為了簡單用 RRF**：不用調整也運作得很好
- **加上 reranking**：品質大幅提升
- **兩種分數都記 log**：方便除錯
- **做 A/B 測試**：衡量對真實使用者的影響

### 不該做的

- **不要以為一種設定通吃**：不同的查詢需要不同的權重
- **不要跳過關鍵字搜尋**：它處理精確比對比較好
- **不要抓太多**：在召回率與延遲之間取得平衡
- **不要忽略邊界案例**：空結果、單字查詢
