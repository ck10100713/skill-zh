# PPTX Visual Assets

視覺素材是用來支撐投影片的訊息，絕不能用來壓平或取代可編輯的內容。

## Workflow

1. 只有在能幫助理解時，才選擇素材類型：圖示、圖片、SVG、圖表或資訊圖表。
2. 放置之前，先確認本機素材的路徑、來源、使用權利與簡潔的替代文字。
3. 用最終以英吋計的 bbox、刻意安排的 z-index，以及 `content` 或 `layout_design` 的分類來加入素材。
4. 保持長寬比，並檢查素材沒有蓋住可閱讀的文字，也沒有把重要資訊鎖在圖片裡。

## Rules

- 使用簡單、清楚易讀的圖示，並搭配文字標籤。
- 圖說放在圖片旁邊，不要蓋在圖片上。
- 只有在是乾淨的向量時，才使用真正的 SVG 來源；絕對不要把點陣圖包在 SVG 裡，然後說它是可編輯的。
- 重要的標籤、圖例、數值與流程步驟，要用原生 PowerPoint 物件重新建立。
- 如果沒有授權、出處，或沒有合適的素材，就省略素材並回報這個缺口。絕對不要把 placeholder 當成完成的視覺放進去。
- 把供應商或來源的細節記錄在來源清單裡。絕對不要在聊天中索取機密。

授權、放置與 SVG 限制見 `references/asset-guidance.md`。
