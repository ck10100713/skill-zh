# 無障礙合規

掌握無障礙的實作，建立人人都能用的包容性體驗，包括身心障礙的使用者。

## 何時使用這個 Skill

- 實作 WCAG 2.2 Level AA 或 AAA 合規
- 建構螢幕閱讀器可用的介面
- 為互動元件加上鍵盤導覽
- 實作焦點管理和焦點鎖定（focus trapping）
- 建立有正確標籤的無障礙表單
- 支援減少動態效果和高對比的偏好設定
- 建構行動裝置的無障礙功能（iOS VoiceOver、Android TalkBack）
- 進行無障礙稽核並修正違規項目

## 最佳實務

1. **使用語意化 HTML**：可以的話優先用原生元素，不要用 ARIA
2. **跟真實使用者一起測試**：使用者測試要納入身心障礙者
3. **鍵盤優先**：設計出不用滑鼠也能操作的互動
4. **不要停用焦點樣式**：幫它設計樣式，不要把它移除
5. **提供文字替代**：所有非文字內容都需要描述
6. **支援縮放**：內容在 200% 縮放下要能正常使用
7. **宣告變化**：動態內容要用 live region
8. **尊重偏好設定**：遵守 prefers-reduced-motion 和 prefers-contrast

## 常見問題

- **缺少 alt 文字**：圖片沒有描述
- **色彩對比不佳**：文字在背景上很難讀
- **鍵盤陷阱**：焦點卡在元件裡
- **缺少標籤**：表單輸入沒有對應的標籤
- **自動播放媒體**：不是使用者主動觸發就開始播放的內容
- **無法存取的自訂控制項**：把原生功能做得很差
- **缺少 skip link**：沒辦法跳過重複的內容
- **焦點順序問題**：Tab 順序跟視覺順序不一致

## 測試工具

- **自動化**：axe DevTools、WAVE、Lighthouse
- **手動**：VoiceOver（macOS/iOS）、NVDA/JAWS（Windows）、TalkBack（Android）
- **模擬器**：NoCoffee（視覺）、Silktide（各種障礙）
