# 雇用合約範本

建立合法有效的雇用文件的範本與模式，包含合約、offer letter 與 HR 政策。

## 什麼時候用這個 Skill

- 草擬雇用合約
- 建立 offer letter
- 撰寫員工手冊
- 制定 HR 政策
- 讓雇用文件標準化
- Onboarding 文件

## 核心概念

### 1. 雇用文件類型

| 文件                    | 用途                    | 使用時機      |
| ----------------------- | ----------------------- | ------------- |
| **Offer Letter**        | 初步的工作邀約          | 錄用前        |
| **雇用合約**            | 正式協議                | 錄用時        |
| **員工手冊**            | 政策與流程              | Onboarding    |
| **NDA**                 | 保密                    | 開放存取前    |
| **競業禁止**            | 限制競爭                | 錄用/離職時   |

### 2. 重要的法律考量

```
雇用關係：
├── At-Will 或契約制
├── 員工或承包商
├── 全職或兼職
├── 免加班費或需給加班費
└── 各司法管轄區的特定要求
```

**免責聲明：這些範本僅供參考，不構成法律建議。使用任何雇用文件之前，請諮詢合格的法律顧問。**

## 最佳實務

### 該做的

- **諮詢法律顧問**：雇用法規因司法管轄區而異
- **保留簽署過的副本**：所有協議都要有紀錄
- **定期更新**：法律和政策會變
- **清楚且具體**：避免含糊
- **訓練主管**：關於政策與流程

### 不該做的

- **不要用通用範本**：要依你的司法管轄區客製化
- **不要亂做承諾**：可能會形成默示契約
- **不要歧視**：無論是在用語或實際運用上
- **不要忘記 at-will 的措辭**：適用的話
- **不要跳過審閱**：所有文件都要請法律顧問審閱
