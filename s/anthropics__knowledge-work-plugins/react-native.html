# Zoom Meeting SDK（React Native）

在建置需要嵌入式 Zoom 會議加入／開始流程的 React Native app 時使用這個 skill。

## 快速連結

1. **[生命週期工作流程](concepts/lifecycle-workflow.md)** - init -> auth -> join/start -> in-meeting -> cleanup
2. **[架構](concepts/architecture.md)** - JS wrapper、native bridge、iOS/Android SDK 各層
3. **[高層情境](concepts/high-level-scenarios.md)** - 實用的產品模式
4. **[設定指南](examples/setup-guide.md)** - 安裝套件加平台需求
5. **[加入會議模式](examples/join-meeting-pattern.md)** - JWT + meetingNumber + password
6. **[開始會議模式](examples/start-meeting-pattern.md)** - 以 ZAK 為基礎的主持人開始流程
7. **[SKILL.md](SKILL.md)** - 完整導覽

## 核心 API（Wrapper）

來自 `@zoom/meetingsdk-react-native` wrapper 的介面：

- `initSDK(config)`
- `isInitialized()`
- `updateMeetingSetting(config)`
- `joinMeeting(config)`
- `startMeeting(config)`
- `cleanup()`

參見：**[Wrapper API](references/wrapper-api.md)**

## 重要備註

- 你仍然需要設定好 native iOS/Android Meeting SDK 的相依套件。
- `joinMeeting` 和 `startMeeting` 會回傳來自 native 層的數字狀態／錯誤碼。
- 主持人開始流程要傳入 `zoomAccessToken`（ZAK）。
- JWT 的產生要留在後端，絕對不要把 SDK secret 嵌進 app。
- 目前的文件指出 React Native 支援到 `0.75.4`；不支援 Expo。

# Zoom Meeting SDK (React Native)

Use this skill when building React Native apps that need embedded Zoom meeting join/start flows.

## Quick Links

1. **[Lifecycle Workflow](concepts/lifecycle-workflow.md)** - init -> auth -> join/start -> in-meeting -> cleanup

7. **[SKILL.md](SKILL.md)** - full navigation

## Core APIs (Wrapper)

From `@zoom/meetingsdk-react-native` wrapper surface:

- `initSDK(config)`
- `isInitialized()`
- `updateMeetingSetting(config)`
- `joinMeeting(config)`
- `startMeeting(config)`
- `cleanup()`

See: **[Wrapper API](references/wrapper-api.md)**

## Critical Notes

- You still need native iOS/Android Meeting SDK dependencies configured.
- `joinMeeting` and `startMeeting` return numeric status/error codes from native layer.
- For host start flow, pass `zoomAccessToken` (ZAK).
- Keep JWT generation on backend, never embed SDK secret in app.
- Current docs note React Native support up to `0.75.4`; Expo is not supported.
