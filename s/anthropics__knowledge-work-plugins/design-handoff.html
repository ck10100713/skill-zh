# /design-handoff

> 如果看到不熟悉的佔位符，或需要確認目前連接了哪些工具，請看 [CONNECTORS.md](../../CONNECTORS.md)。

從設計稿產生完整的開發者 handoff 文件。

## 用法

```
/design-handoff $ARGUMENTS
```

為這個產生 handoff 規格：@$1

如果有給 Figma URL，就從 Figma 把設計拉下來。否則就根據提供的描述或截圖來做。

## 要包含什麼

### 視覺規格
- 精確的尺寸（padding、margin、寬度）
- Design token 參照（顏色、字體排印、間距）
- Responsive 斷點和行為
- 元件的 variant 和狀態

### 互動規格
- 點擊／輕觸的行為
- Hover 狀態
- 轉場和動畫（時長、easing）
- 手勢支援（滑動、縮放、長按）

### 內容規格
- 字數上限
- 截斷行為
- 空狀態
- 載入狀態
- 錯誤狀態

### 邊界情況
- 內容的最小／最大量
- 國際化文字（字串比較長）
- 網路很慢
- 資料缺漏

### 無障礙
- Focus 順序
- ARIA label 和 role
- 鍵盤互動
- 螢幕閱讀器的朗讀內容

## 原則

1. **不要假設**：沒寫清楚的東西，開發者就會用猜的。每件事都要講清楚。
2. **用 token，不要用數值**：參照 `spacing-md`，不要寫 `16px`。
3. **每個狀態都要列**：default、hover、active、disabled、loading、error、empty。
4. **說明為什麼**：「這在 mobile 會收合，因為使用者主要單手操作」這種說明，能幫開發者做出好的判斷。

# /design-handoff

> If you see unfamiliar placeholders or need to check which tools are connected, see [CONNECTORS.md](../../CONNECTORS.md).

Generate comprehensive developer handoff documentation from a design.

## Usage

```
/design-handoff $ARGUMENTS
```

Generate handoff specs for: @$1

If a Figma URL is provided, pull the design from Figma. Otherwise, work from the provided description or screenshot.

## What to Include

### Visual Specifications
- Exact measurements (padding, margins, widths)
- Design token references (colors, typography, spacing)
- Responsive breakpoints and behavior
- Component variants and states

### Interaction Specifications
- Click/tap behavior
- Hover states
- Transitions and animations (duration, easing)
- Gesture support (swipe, pinch, long-press)

### Content Specifications
- Character limits
- Truncation behavior
- Empty states
- Loading states
- Error states

### Edge Cases
- Minimum/maximum content
- International text (longer strings)
- Slow connections
- Missing data

### Accessibility
- Focus order
- ARIA labels and roles
- Keyboard interactions
- Screen reader announcements

## Principles

1. **Don't assume** — If it's not specified, the developer will guess. Specify everything.
2. **Use tokens, not values** — Reference `spacing-md` not `16px`.
3. **Show all states** — Default, hover, active, disabled, loading, error, empty.
4. **Describe the why** — "This collapses on mobile because users primarily use one-handed" helps developers make good judgment calls.
