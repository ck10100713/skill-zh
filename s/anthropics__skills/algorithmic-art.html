演算法哲學是一種運算的美學運動，之後會透過程式碼表達出來。輸出 .md 檔（哲學）、.html 檔（互動式檢視器）和 .js 檔（生成演算法）。

分兩個步驟進行：
1. 建立演算法哲學（.md 檔）
2. 創作 p5.js 生成藝術來表達它（.html + .js 檔）

先做這個任務：

## 建立演算法哲學

一開始，先創造一套「演算法哲學」（不是靜態圖片或範本），透過以下方式來詮釋：
- 運算過程、湧現行為、數學之美
- 種子隨機數、雜訊場、有機系統
- 粒子、流動、場、力
- 參數變化與受控的混沌

### 關鍵的理解
- 收到的是：使用者給的一些細微的輸入或指示，要納入考量，但只當作基礎，不能限制創作的自由。
- 創造的是：一套演算法哲學／生成式美學運動。
- 接下來發生的是：同一個版本的你收到這套哲學，然後「用程式碼表達它」，創造出 90% 是演算法生成、10% 是必要參數的 p5.js sketch。

可以這樣想：
- 為一個生成藝術運動寫一份宣言
- 下一階段是寫出讓它活起來的演算法

這套哲學必須強調：演算法表達。湧現行為。運算之美。種子變化。

### 如何產生演算法哲學

**幫這個運動取名**（1 到 2 個詞）：「Organic Turbulence」 / 「Quantum Harmonics」 / 「Emergent Stillness」

**闡述這套哲學**（4 到 6 段，簡潔但完整）：

為了抓住「演算法」的本質，要說明這套哲學如何透過以下面向展現：
- 運算過程和數學關係？
- 雜訊函式和隨機模式？
- 粒子行為和場的動態？
- 時間演化和系統狀態？
- 參數變化和湧現的複雜性？

**關鍵準則：**
- **避免重複**：每個演算法面向只提一次。除非能加進新的深度，否則不要重複講雜訊理論、粒子動力學或數學原理的概念。
- **反覆強調工藝**：這套哲學一定要多次強調，最終的演算法看起來要像花了無數個小時開發、細心精修過，而且出自該領域頂尖的人之手。這個框架很重要，要重複使用像「精心打造的演算法」、「深厚運算專業的成果」、「一絲不苟的最佳化」、「大師級的實作」這類說法。
- **留下創作空間**：演算法的方向要具體，但要簡潔到讓下一個 Claude 有空間，以極高的工藝水準做出自己對實作的詮釋選擇。

這套哲學必須引導下一個版本用「演算法」來表達想法，而不是靠靜態圖片。美存在於過程裡，不是最後一幀。

### 哲學範例

**「Organic Turbulence」**
哲學：受自然法則約束的混沌，從無序中浮現的秩序。
演算法表達：由多層 Perlin noise 驅動的流場。數千個粒子沿著向量力移動，軌跡累積成有機的密度圖。多個 noise octave 創造出紊流區和平靜區。色彩從速度和密度中浮現，快的粒子燃燒般明亮，慢的粒子淡成陰影。演算法一直跑到平衡為止，這是一個精心調校的平衡，每個參數都由運算美學的大師經過無數次迭代精修而成。

**「Quantum Harmonics」**
哲學：離散的個體展現出像波一樣的干涉圖樣。
演算法表達：粒子在網格上初始化，每個都帶著一個透過正弦波演化的相位值。粒子靠近時，它們的相位會互相干涉，建設性干涉產生明亮的節點，破壞性干涉產生空洞。簡單的諧運動產生複雜、湧現的曼陀羅。這是一絲不苟的頻率校準的成果，每個比例都經過仔細挑選，以產生共鳴之美。

**「Recursive Whispers」**
哲學：跨尺度的自相似，有限空間裡的無限深度。
演算法表達：遞迴細分的分枝結構。每個分枝都有一點隨機，但受黃金比例約束。L-system 或遞迴細分產生的樹狀形態，既有數學感又有有機感。細微的 noise 擾動打破完美的對稱。線條粗細隨每一層遞迴遞減。每一個分枝角度都是深入數學探索的成果。

**「Field Dynamics」**
哲學：看不見的力，透過它們對物質的作用而被看見。
演算法表達：由數學函式或 noise 建構的向量場。粒子從邊緣誕生，沿著場線流動，到達平衡或邊界時死亡。多個場可以吸引、排斥或旋轉粒子。視覺化只顯示軌跡，那是看不見的力留下的幽靈般的證據。一支透過力的平衡精心編排的運算之舞。

**「Stochastic Crystallization」**
哲學：隨機過程結晶成有序的結構。
演算法表達：隨機的圓填充（circle packing）或 Voronoi 鑲嵌。從隨機的點開始，讓它們透過鬆弛演算法演化。細胞互相推開直到平衡。色彩依據細胞大小、鄰居數量或離中心的距離。浮現出來的有機鋪排，感覺既隨機又必然。每個種子都產生獨一無二的結晶之美，這是大師級生成演算法的印記。

*這些是濃縮過的範例。實際的演算法哲學應該是 4 到 6 段內容充實的段落。*

### 核心原則
- **演算法哲學**：創造一個要透過程式碼表達的運算世界觀
- **過程重於成品**：一律強調美是從演算法的執行中浮現的，每次執行都獨一無二
- **參數化表達**：想法透過數學關係、力、行為來傳達，不是靜態構圖
- **藝術自由**：下一個 Claude 會用演算法詮釋這套哲學，要留給它實作上的創作空間
- **純粹的生成藝術**：這是在做「活的演算法」，不是加了隨機性的靜態圖片
- **專家級的工藝**：反覆強調最終的演算法必須讓人感覺精心打造，經過無數次迭代精修，是運算美學領域絕對頂尖的人的深厚專業成果

**演算法哲學應該有 4 到 6 段。** 用富有詩意的運算哲學把預期的願景串在一起。避免重複相同的論點。把這套演算法哲學輸出成 .md 檔。

## 推演出概念種子

**關鍵步驟**：在實作演算法之前，先從原始請求裡找出那條細微的概念線索。

**核心原則**：
概念是一個**嵌在演算法本身裡面、細微而小眾的參照**，不一定是字面的，永遠要精緻。熟悉那個主題的人應該能直覺地感受到，其他人則單純體驗到一件高明的生成式作品。演算法哲學提供運算語言。推演出來的概念提供靈魂，那是悄悄織進參數、行為和湧現模式裡、看不見的概念 DNA。

這件事**非常重要**：這個參照必須精煉到加深作品的層次，卻不張揚。想像爵士樂手透過演算法的和聲引用另一首歌，只有懂的人聽得出來，但每個人都欣賞那份生成之美。

## P5.JS 實作

哲學「和」概念框架都確立之後，就用程式碼表達它。繼續之前先停下來整理思緒。只使用你創造的演算法哲學和下面的指示。

### ⚠️ 步驟 0：先讀範本 ⚠️

**關鍵：在寫任何 HTML「之前」：**

1. 用 Read 工具**讀取** `templates/viewer.html`
2. **研究**它的確切結構、樣式和 Anthropic 品牌
3. **把那個檔案當作「字面上的起點」**，不只是靈感
4. **所有固定（FIXED）的區塊都要完全照原樣保留**（標題、側邊欄結構、Anthropic 的顏色／字型、種子控制、動作按鈕）
5. **只替換**檔案註解裡標示的**可變（VARIABLE）區塊**（演算法、參數、參數的 UI 控制項）

**要避免：**
- ❌ 從頭自己做 HTML
- ❌ 發明自訂的樣式或配色
- ❌ 使用系統字型或深色主題
- ❌ 改變側邊欄結構

**要遵循這些做法：**
- ✅ 複製範本確切的 HTML 結構
- ✅ 保留 Anthropic 品牌（Poppins/Lora 字型、淺色、漸層背景）
- ✅ 維持側邊欄的版面配置（Seed → Parameters → Colors? → Actions）
- ✅ 只替換 p5.js 演算法和參數控制項

範本是基礎。在它上面建構，不要重建它。

要創作出有展覽水準、會呼吸的運算藝術，就以演算法哲學為基礎。

### 技術要求

**種子隨機數（Art Blocks 模式）**：
```javascript
// 一律使用 seed，確保可重現
let seed = 12345; // 或由使用者輸入的雜湊值
randomSeed(seed);
noiseSeed(seed);
```

**參數結構：跟隨哲學**：

要建立從演算法哲學自然浮現的參數，可以想：「這個系統有哪些特質可以調整？」

```javascript
let params = {
  seed: 12345,  // 一律放 seed，確保可重現
  // colors
  // 加上控制「你的」演算法的參數：
  // - 數量（多少個？）
  // - 尺度（多大？多快？）
  // - 機率（多有可能？）
  // - 比例（什麼比例？）
  // - 角度（什麼方向？）
  // - 閾值（行為什麼時候改變？）
};
```

**要設計有效的參數，要聚焦在系統需要可調整的屬性，而不是用「圖案類型」來思考。**

**核心演算法：表達哲學**：

**關鍵**：該建構什麼，要由演算法哲學來決定。

要透過程式碼表達哲學，避免去想「我該用哪個圖案？」，而是去想「怎麼用程式碼表達這套哲學？」

如果哲學是關於**有機的湧現**，可以考慮用：
- 隨時間累積或生長的元素
- 受自然規則約束的隨機過程
- 回饋迴圈和交互作用

如果哲學是關於**數學之美**，可以考慮用：
- 幾何關係和比例
- 三角函數和諧波
- 精確的計算創造出意想不到的圖案

如果哲學是關於**受控的混沌**，可以考慮用：
- 嚴格邊界內的隨機變化
- 分岔和相變
- 從無序中浮現的秩序

**演算法源自哲學，不是源自一份選項清單。**

要引導實作，就讓概念的本質來啟發有創意、原創的選擇。打造出能表達這個特定請求的願景的東西。

**畫布設定**：標準的 p5.js 結構：
```javascript
function setup() {
  createCanvas(1200, 1200);
  // 初始化你的系統
}

function draw() {
  // 你的生成演算法
  // 可以是靜態的（noLoop）或動態的
}
```

### 工藝要求

**關鍵**：要達到精通，就創作出讓人感覺像是經過資深生成藝術家無數次迭代而浮現的演算法。仔細調校每個參數。確保每個圖案的出現都有目的。這「不是」隨機雜訊，這是經過深厚專業精煉的「受控混沌」。

- **平衡**：複雜但不雜亂，有秩序但不僵硬
- **色彩和諧**：用心挑選的色盤，不是隨機的 RGB 值
- **構圖**：即使在隨機中，也要維持視覺層次和流動
- **效能**：執行流暢，如果是動態的就針對即時運作最佳化
- **可重現性**：相同的 seed「一定」產生一模一樣的輸出

### 輸出格式

輸出：
1. **演算法哲學**：以 markdown 或文字說明這套生成式美學
2. **單一 HTML artifact**：以 `templates/viewer.html` 為基礎建立、自成一體的互動式生成藝術（見步驟 0 和下一節）

這個 HTML artifact 包含所有東西：p5.js（從 CDN 載入）、演算法、參數控制項和 UI，全部在一個檔案裡，在 claude.ai artifact 或任何瀏覽器裡都能立刻運作。從範本檔開始，不要從頭做。

## 建立互動式 ARTIFACT

**提醒：`templates/viewer.html` 應該已經讀過了（見步驟 0）。以那個檔案為起點。**

為了讓人探索這件生成藝術，建立單一、自成一體的 HTML artifact。確保這個 artifact 在 claude.ai 或任何瀏覽器裡都能立刻運作，不需要任何設定。所有東西都內嵌。

### 關鍵：什麼是固定的、什麼是可變的

`templates/viewer.html` 檔案是基礎。它包含所需的確切結構和樣式。

**固定（FIXED）（一律完全照原樣放進去）：**
- 版面結構（標題、側邊欄、主畫布區）
- Anthropic 品牌（UI 的顏色、字型、漸層）
- 側邊欄的 Seed 區塊：
  - Seed 顯示
  - Previous/Next 按鈕
  - Random 按鈕
  - 跳到指定 seed 的輸入框 + Go 按鈕
- 側邊欄的 Actions 區塊：
  - Regenerate 按鈕
  - Reset 按鈕

**可變（VARIABLE）（針對每件作品客製）：**
- 整個 p5.js 演算法（setup/draw/class）
- 參數物件（定義這件藝術需要什麼）
- 側邊欄的 Parameters 區塊：
  - 參數控制項的數量
  - 參數名稱
  - 滑桿的最小／最大／step 值
  - 控制項類型（滑桿、輸入框等）
- Colors 區塊（選用）：
  - 有些藝術需要色彩選擇器
  - 有些藝術可能用固定的顏色
  - 有些藝術可能是單色（不需要色彩控制項）
  - 依藝術的需求來決定

**每件作品都應該有獨特的參數和演算法！** 固定的部分提供一致的使用體驗，其他一切都用來表達獨特的願景。

### 必要功能

**1. 參數控制項**
- 數值參數用滑桿（粒子數量、noise 尺度、速度等）
- 色盤的顏色用色彩選擇器
- 參數改變時即時更新
- 用 Reset 按鈕還原預設值

**2. Seed 導覽**
- 顯示目前的 seed 數字
- 「Previous」和「Next」按鈕，用來循環切換 seed
- 「Random」按鈕，取隨機 seed
- 輸入欄位，用來跳到特定的 seed
- 被要求時產生 100 個變體（seed 1-100）

**3. 單一 Artifact 結構**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- 從 CDN 載入 p5.js，隨時都能用 -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* 所有樣式都內嵌，乾淨、極簡 */
    /* 畫布在上面，控制項在下面 */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- 所有參數控制項 -->
  </div>
  <script>
    // 所有 p5.js 程式碼都內嵌在這裡
    // 參數物件、class、函式
    // setup() 和 draw()
    // UI 事件處理
    // 一切都自成一體
  </script>
</body>
</html>
```
