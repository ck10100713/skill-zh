# Pydantic Models

依照多模型模式建立 Pydantic 模型，讓 API 契約乾淨清楚。

## 快速開始

從 [assets/template.py](assets/template.py) 複製範本，並替換 placeholder：
- `{{ResourceName}}` → PascalCase 名稱（例如 `Project`）
- `{{resource_name}}` → snake_case 名稱（例如 `project`）

## 多模型模式

| 模型 | 用途 |
|-------|---------|
| `Base` | 各模型共用的欄位 |
| `Create` | 建立用的 request body（必填欄位） |
| `Update` | 更新用的 request body（全部選填） |
| `Response` | 包含所有欄位的 API response |
| `InDB` | 帶有 `doc_type` 的資料庫文件 |

## camelCase 別名

```python
from datetime import datetime

from pydantic import BaseModel, ConfigDict, Field

class MyModel(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    workspace_id: str = Field(..., alias="workspaceId")
    created_at: datetime = Field(..., alias="createdAt")
```

## 選填的更新欄位

```python
class MyUpdate(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    name: Optional[str] = Field(None, min_length=1)
    description: Optional[str] = None
```

## 資料庫文件

```python
class MyInDB(MyResponse):
    doc_type: str = "my_resource"
```

## 整合步驟

1. 在 `src/backend/app/models/` 建立模型
2. 從 `src/backend/app/models/__init__.py` export
3. 加上對應的 TypeScript 型別

# Pydantic Models

Create Pydantic models following the multi-model pattern for clean API contracts.

## Quick Start

Copy the template from [assets/template.py](assets/template.py) and replace placeholders:
- `{{ResourceName}}` → PascalCase name (e.g., `Project`)
- `{{resource_name}}` → snake_case name (e.g., `project`)

## Multi-Model Pattern

| Model | Purpose |
|-------|---------|
| `Base` | Common fields shared across models |
| `Create` | Request body for creation (required fields) |
| `Update` | Request body for updates (all optional) |
| `Response` | API response with all fields |
| `InDB` | Database document with `doc_type` |

## camelCase Aliases

```python
from datetime import datetime

from pydantic import BaseModel, ConfigDict, Field

class MyModel(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    workspace_id: str = Field(..., alias="workspaceId")
    created_at: datetime = Field(..., alias="createdAt")
```

## Optional Update Fields

```python
class MyUpdate(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    name: Optional[str] = Field(None, min_length=1)
    description: Optional[str] = None
```

## Database Document

```python
class MyInDB(MyResponse):
    doc_type: str = "my_resource"
```

## Integration Steps

1. Create models in `src/backend/app/models/`
2. Export from `src/backend/app/models/__init__.py`
3. Add corresponding TypeScript types
