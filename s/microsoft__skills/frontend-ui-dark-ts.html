# Frontend UI Dark Theme (TypeScript)

使用 **Tailwind CSS** 和 **Framer Motion** 的現代深色主題 React UI 系統。專為 dashboard、後台和資料密集的應用設計，帶有 glassmorphism 效果和有品味的動畫。

## Stack

| Package | Version | Purpose |
|---------|---------|---------|
| `react` | ^18.x | UI 框架 |
| `react-dom` | ^18.x | DOM 渲染 |
| `react-router-dom` | ^6.x | 路由 |
| `framer-motion` | ^11.x | 動畫 |
| `clsx` | ^2.x | 合併 class |
| `tailwindcss` | ^3.x | 樣式 |
| `vite` | ^5.x | 建置工具 |
| `typescript` | ^5.x | 型別安全 |

## Quick Start

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install framer-motion clsx react-router-dom
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

### Page Transition Wrapper

```tsx
import { motion } from 'framer-motion';
import { ReactNode } from 'react';

interface PageTransitionProps {
  children: ReactNode;
}

export function PageTransition({ children }: PageTransitionProps) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 20 }}
      animate={{ opacity: 1, y: 0 }}
      exit={{ opacity: 0, y: -20 }}
      transition={{ duration: 0.3, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}
```

### Page Transition Wrapper

```tsx
import { motion } from 'framer-motion';
import { ReactNode } from 'react';

interface PageTransitionProps {
  children: ReactNode;
}

export function PageTransition({ children }: PageTransitionProps) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 20 }}
      animate={{ opacity: 1, y: 0 }}
      exit={{ opacity: 0, y: -20 }}
      transition={{ duration: 0.3, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}
```
