# Turborepo Caching

Turborepo 建置最佳化的 production 模式。

## When to Use This Skill

- 設定新的 Turborepo 專案
- 設定建置流水線
- 實作遠端快取
- 最佳化 CI/CD 效能
- 從其他 monorepo 工具遷移
- 除錯 cache miss

## Core Concepts

### 1. Turborepo Architecture

```
Workspace Root/
├── apps/
│   ├── web/
│   │   └── package.json
│   └── docs/
│       └── package.json
├── packages/
│   ├── ui/
│   │   └── package.json
│   └── config/
│       └── package.json
├── turbo.json
└── package.json
```

### 2. Pipeline Concepts

| Concept        | Description                      |
| -------------- | -------------------------------- |
| **dependsOn**  | 必須先完成的任務   |
| **cache**      | 是否快取輸出         |
| **outputs**    | 要快取的檔案               |
| **inputs**     | 會影響 cache key 的檔案      |
| **persistent** | 長時間執行的任務（dev server） |

## Templates

### Template 1: turbo.json Configuration

```json
{
  "$schema": "https://turbo.build/schema.json",
  "globalDependencies": [".env", ".env.local"],
  "globalEnv": ["NODE_ENV", "VERCEL_URL"],

      "dependsOn": ["^build"],

      "dependsOn": ["build"],

      "cache": false
    }
  }
}
```

```yaml
  push:
    branches: [main]

  TURBO_TOKEN: ${{ secrets.TURBO_TOKEN }}
  TURBO_TEAM: ${{ vars.TURBO_TEAM }}

    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npx turbo build --filter='...[origin/main]'

      - name: Test
        run: npx turbo test --filter='...[origin/main]'
```

### Template 4: Self-Hosted Remote Cache

```typescript
// 自訂遠端快取伺服器（Express）
import express from "express";
import { createReadStream, createWriteStream } from "fs";
import { mkdir } from "fs/promises";
import { join } from "path";

const app = express();
const CACHE_DIR = "./cache";

// 取得 artifact
app.get("/v8/artifacts/:hash", async (req, res) => {
  const { hash } = req.params;
  const team = req.query.teamId || "default";
  const filePath = join(CACHE_DIR, team, hash);

  try {
    const stream = createReadStream(filePath);
    stream.pipe(res);
  } catch {
    res.status(404).send("Not found");
  }
});

// 存入 artifact
app.put("/v8/artifacts/:hash", async (req, res) => {
  const { hash } = req.params;
  const team = req.query.teamId || "default";
  const dir = join(CACHE_DIR, team);
  const filePath = join(dir, hash);

  await mkdir(dir, { recursive: true });

  const stream = createWriteStream(filePath);
  req.pipe(stream);

  stream.on("finish", () => {
    res.json({
      urls: [`${req.protocol}://${req.get("host")}/v8/artifacts/${hash}`],
    });
  });
});

// 檢查 artifact 是否存在
app.head("/v8/artifacts/:hash", async (req, res) => {
  const { hash } = req.params;
  const team = req.query.teamId || "default";
  const filePath = join(CACHE_DIR, team, hash);

  try {
    await fs.access(filePath);
    res.status(200).end();
  } catch {
    res.status(404).end();
  }
});

app.listen(3000, "127.0.0.1");
```

### Template 5: Filtering and Scoping

```bash
# 建置特定 package
turbo build --filter=@myorg/web

# 建置該 package 和它的相依套件
turbo build --filter=@myorg/web...

# 建置該 package 和依賴它的套件
turbo build --filter=...@myorg/ui

# 建置自 main 以來有變動的 package
turbo build --filter='...[origin/main]'

# 建置某目錄下的 package
turbo build --filter='./apps/*'

# 組合多個 filter
turbo build --filter=@myorg/web --filter=@myorg/docs

# 排除某個 package
turbo build --filter='!@myorg/docs'

# 包含有變動套件的相依套件
turbo build --filter='...[HEAD^1]...'
```

## Debugging Cache

```bash
# 乾跑，看哪些任務會執行
turbo build --dry-run

# 顯示 hash 的詳細輸出
turbo build --verbosity=2

# 顯示 task graph
turbo build --graph

# 強制不使用快取
turbo build --force

# 顯示快取狀態
turbo build --summarize

# 除錯特定任務
TURBO_LOG_VERBOSITY=debug turbo build --filter=@myorg/web
```

## Best Practices

### Do's

- **Define explicit inputs** - 避免快取失效
- **Use workspace protocol** - `"@myorg/ui": "workspace:*"`
- **Enable remote caching** - 在 CI 和本機之間共用
- **Filter in CI** - 只建置受影響的 package
- **Cache build outputs** - 快取建置輸出，不要快取原始碼

### Don'ts

- **Don't cache dev servers** - 用 `persistent: true`
- **Don't include secrets in env** - 用執行期環境變數
- **Don't ignore dependsOn** - 會造成 race condition
- **Don't over-filter** - 可能會漏掉相依套件

## Best Practices

### Do's

- **Define explicit inputs** - Avoid cache invalidation
- **Use workspace protocol** - `"@myorg/ui": "workspace:*"`
- **Enable remote caching** - Share across CI and local
- **Filter in CI** - Build only affected packages
- **Cache build outputs** - Not source files

### Don'ts

- **Don't cache dev servers** - Use `persistent: true`
- **Don't include secrets in env** - Use runtime env vars
- **Don't ignore dependsOn** - Causes race conditions
- **Don't over-filter** - May miss dependencies
