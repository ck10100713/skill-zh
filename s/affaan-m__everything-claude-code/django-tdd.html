# 用 TDD 做 Django 測試

用 pytest、factory_boy 和 Django REST Framework 為 Django 應用程式做測試驅動開發。

## 何時啟用

- 撰寫新的 Django 應用程式
- 實作 Django REST Framework API
- 測試 Django 的 model、view 和 serializer
- 為 Django 專案建立測試基礎設施

## Django 的 TDD 流程

### Red-Green-Refactor 循環

```python
# Step 1: RED - Write failing test
def test_user_creation():
    user = User.objects.create_user(email='test@example.com', password='testpass123')
    assert user.email == 'test@example.com'
    assert user.check_password('testpass123')
    assert not user.is_staff

# Step 2: GREEN - Make test pass
# Create User model or factory

# Step 3: REFACTOR - Improve while keeping tests green
```

## Factory Boy

### 設定 Factory

```python
# tests/factories.py
import factory
from factory import fuzzy
from datetime import datetime, timedelta
from django.contrib.auth import get_user_model
from apps.products.models import Product, Category

User = get_user_model()

class UserFactory(factory.django.DjangoModelFactory):
    """Factory for User model."""

    class Meta:
        model = User

    email = factory.Sequence(lambda n: f"user{n}@example.com")
    username = factory.Sequence(lambda n: f"user{n}")
    password = factory.PostGenerationMethodCall('set_password', 'testpass123')
    first_name = factory.Faker('first_name')
    last_name = factory.Faker('last_name')
    is_active = True

class CategoryFactory(factory.django.DjangoModelFactory):
    """Factory for Category model."""

    class Meta:
        model = Category

    name = factory.Faker('word')
    slug = factory.LazyAttribute(lambda obj: obj.name.lower())
    description = factory.Faker('text')

class ProductFactory(factory.django.DjangoModelFactory):
    """Factory for Product model."""

    class Meta:
        model = Product

    name = factory.Faker('sentence', nb_words=3)
    slug = factory.LazyAttribute(lambda obj: obj.name.lower().replace(' ', '-'))
    description = factory.Faker('text')
    price = fuzzy.FuzzyDecimal(10.00, 1000.00, 2)
    stock = fuzzy.FuzzyInteger(0, 100)
    is_active = True
    category = factory.SubFactory(CategoryFactory)
    created_by = factory.SubFactory(UserFactory)

    @factory.post_generation
    def tags(self, create, extracted, **kwargs):
        """Add tags to product."""
        if not create:
            return
        if extracted:
            for tag in extracted:
                self.tags.add(tag)
```

import pytest

class TestPaymentView:
    """Test payment view with mocked payment gateway."""

    @patch('apps.payments.services.stripe')
    def test_successful_payment(self, mock_stripe, client, user, product):

        mock_stripe.Charge.create.return_value = {

            'status': 'succeeded',
            'amount': 9999,
        }

        client.force_login(user)

            'product_id': product.id,
            'token': 'tok_visa',

        assert response.status_code == 302
        mock_stripe.Charge.create.assert_called_once()

## 測試最佳實務

### 該做的

- **用 factory**：不要手動建立物件
- **每個測試一個 assertion**：讓測試保持聚焦
- **測試名稱要有描述性**：`test_user_cannot_delete_others_post`
- **測試邊界情況**：空輸入、None 值、邊界條件
- **Mock 外部服務**：不要依賴外部 API
- **用 fixture**：消除重複
- **測試權限**：確保授權有效
- **讓測試跑得快**：用 `--reuse-db` 和 `--nomigrations`

### 不該做的

- **不要測 Django 內部**：相信 Django 會正常運作
- **不要測第三方程式碼**：相信套件會正常運作
- **不要忽略失敗的測試**：所有測試都必須通過
- **不要讓測試互相依賴**：測試要能以任何順序執行
- **不要 mock 過頭**：只 mock 外部依賴
- **不要測 private method**：測 public 介面
- **不要用 production 資料庫**：一律用測試資料庫

## 快速參考

| 模式 | 用途 |
|---------|-------|
| `@pytest.mark.django_db` | 啟用資料庫存取 |
| `client` | Django test client |
| `api_client` | DRF API client |
| `factory.create_batch(n)` | 建立多個物件 |
| `patch('module.function')` | Mock 外部依賴 |
| `override_settings` | 暫時改設定 |
| `force_authenticate()` | 測試中略過認證 |
| `assertRedirects` | 檢查 redirect |
| `assertTemplateUsed` | 驗證有用到哪個 template |
| `mail.outbox` | 檢查寄出的信 |

記住：測試就是文件。好的測試會說明你的程式該怎麼運作。要保持簡單、好讀、好維護。

# tests/factories.py
import factory
from factory import fuzzy
from datetime import datetime, timedelta
from django.contrib.auth import get_user_model
from apps.products.models import Product, Category

User = get_user_model()

class UserFactory(factory.django.DjangoModelFactory):
    """Factory for User model."""

    class Meta:
        model = User

    email = factory.Sequence(lambda n: f"user{n}@example.com")
    username = factory.Sequence(lambda n: f"user{n}")
    password = factory.PostGenerationMethodCall('set_password', 'testpass123')
    first_name = factory.Faker('first_name')
    last_name = factory.Faker('last_name')
    is_active = True

class CategoryFactory(factory.django.DjangoModelFactory):
    """Factory for Category model."""

    class Meta:
        model = Category

    name = factory.Faker('word')
    slug = factory.LazyAttribute(lambda obj: obj.name.lower())
    description = factory.Faker('text')

class ProductFactory(factory.django.DjangoModelFactory):
    """Factory for Product model."""

    class Meta:
        model = Product

    name = factory.Faker('sentence', nb_words=3)
    slug = factory.LazyAttribute(lambda obj: obj.name.lower().replace(' ', '-'))
    description = factory.Faker('text')
    price = fuzzy.FuzzyDecimal(10.00, 1000.00, 2)
    stock = fuzzy.FuzzyInteger(0, 100)
    is_active = True
    category = factory.SubFactory(CategoryFactory)
    created_by = factory.SubFactory(UserFactory)

    @factory.post_generation
    def tags(self, create, extracted, **kwargs):
        """Add tags to product."""
        if not create:
            return
        if extracted:
            for tag in extracted:
                self.tags.add(tag)

## Testing Best Practices

### DO

- **Use factories**: Instead of manual object creation
- **One assertion per test**: Keep tests focused
- **Descriptive test names**: `test_user_cannot_delete_others_post`
- **Test edge cases**: Empty inputs, None values, boundary conditions
- **Mock external services**: Don't depend on external APIs
- **Use fixtures**: Eliminate duplication
- **Test permissions**: Ensure authorization works
- **Keep tests fast**: Use `--reuse-db` and `--nomigrations`

### DON'T

- **Don't test Django internals**: Trust Django to work
- **Don't test third-party code**: Trust libraries to work
- **Don't ignore failing tests**: All tests must pass
- **Don't make tests dependent**: Tests should run in any order
- **Don't over-mock**: Mock only external dependencies
- **Don't test private methods**: Test public interface
- **Don't use production database**: Always use test database

## Quick Reference

| Pattern | Usage |
|---------|-------|
| `@pytest.mark.django_db` | Enable database access |
| `client` | Django test client |
| `api_client` | DRF API client |
| `factory.create_batch(n)` | Create multiple objects |
| `patch('module.function')` | Mock external dependencies |
| `override_settings` | Temporarily change settings |
| `force_authenticate()` | Bypass authentication in tests |
| `assertRedirects` | Check for redirects |
| `assertTemplateUsed` | Verify template usage |
| `mail.outbox` | Check sent emails |

Remember: Tests are documentation. Good tests explain how your code should work. Keep them simple, readable, and maintainable.
