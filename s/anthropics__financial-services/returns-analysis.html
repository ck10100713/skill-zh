# 報酬分析

## 工作流程

### 步驟 1：蒐集交易輸入

向使用者詢問（或從先前的分析中取得）：

**進場：**
- 進場 EBITDA（LTM 或 NTM）
- 進場倍數（EV / EBITDA）
- 企業價值
- 交割時的淨負債
- 股權投入金額
- 交易費用與支出

**融資：**
- 優先債（x EBITDA、利率、攤還）
- 次順位債／夾層債（如有）
- 進場時的總槓桿（x EBITDA）
- 股權出資

**營運假設：**
- 營收成長率（年）
- EBITDA 利潤率走勢
- 資本支出佔營收的 %
- 營運資金變動
- 債務償還時程

**出場：**
- 持有期間（年）
- 出場倍數（EV / EBITDA）
- 出場 EBITDA（由成長假設算出）

### 步驟 2：基準情境報酬

計算：

| 指標 | 數值 |
|--------|-------|
| 進場 EV | |
| 投入股權 | |
| 出場 EBITDA | |
| 出場 EV | |
| 出場時淨負債 | |
| 出場股權價值 | |
| **MOIC** | |
| **IRR** | |
| 現金回報倍數（Cash-on-cash） | |

呈現報酬的拆解（waterfall）：
- EBITDA 成長的貢獻
- 倍數擴張／收縮的貢獻
- 債務償還的貢獻
- 費用／支出的拖累

### 步驟 3：敏感度表

建立雙向敏感度矩陣：

**進場倍數 vs. 出場倍數**
| | 出場 6x | 出場 7x | 出場 8x | 出場 9x | 出場 10x |
|---|---------|---------|---------|---------|----------|
| 進場 7x | | | | | |
| 進場 8x | | | | | |
| 進場 9x | | | | | |
| 進場 10x | | | | | |

**EBITDA 成長 vs. 出場倍數**（固定進場條件）

**槓桿 vs. 出場倍數**（固定進場條件和成長率）

**持有期間 vs. 出場倍數**

每個儲存格同時顯示 IRR 和 MOIC（IRR / MOIC 格式）。

### 步驟 4：情境分析

建立 3 個情境：

| | 樂觀 | 基準 | 悲觀 |
|---|------|------|------|
| 營收 CAGR | | | |
| 出場 EBITDA 利潤率 | | | |
| 出場倍數 | | | |
| 出場 EBITDA | | | |
| MOIC | | | |
| IRR | | | |

### 步驟 5：輸出

- Excel 活頁簿，包含：
  - 假設工作表
  - 報酬計算
  - 敏感度表（用條件式色彩格式化）
  - 情境摘要
- 適合放進 IC 簡報的一頁式報酬摘要

## 關鍵公式

- **MOIC** = 出場股權價值 / 投入股權
- **IRR** = 解 r：投入股權 × (1 + r)^n = 出場股權價值（有期間現金流時要調整）
- **報酬歸因**：
  - 成長：(出場 EBITDA - 進場 EBITDA) × 出場倍數 / 股權
  - 倍數：(出場倍數 - 進場倍數) × 進場 EBITDA / 股權
  - 槓桿：持有期間的債務償還 / 股權

## 重要注意事項

- 適用的話，報酬一律同時呈現扣費前（gross）和扣除費用／carry 後（net）
- 管理層再投資（rollover）和共同投資會改變股權投入金額，相關的話要問
- 股利再融資（dividend recap）或期間分配會大幅影響 IRR，有計畫的話要納入
- 別忘了交易成本（通常是 EV 的 2-4%），它們會降低第一天的股權價值
- 稅務考量（資產交易 vs. 股權交易、338(h)(10) 選擇）可能實質影響稅後報酬

# Returns Analysis

## Workflow

### Step 1: Gather Deal Inputs

Ask for (or extract from prior analysis):

**Entry:**
- Entry EBITDA (LTM or NTM)
- Entry multiple (EV / EBITDA)
- Enterprise value
- Net debt at close
- Equity check size
- Transaction fees & expenses

**Financing:**
- Senior debt (x EBITDA, rate, amortization)
- Subordinated debt / mezzanine (if any)
- Total leverage at entry (x EBITDA)
- Equity contribution

**Operating Assumptions:**
- Revenue growth rate (annual)
- EBITDA margin trajectory
- Capex as % of revenue
- Working capital changes
- Debt paydown schedule

**Exit:**
- Hold period (years)
- Exit multiple (EV / EBITDA)
- Exit EBITDA (calculated from growth assumptions)

### Step 2: Base Case Returns

Calculate:

| Metric | Value |
|--------|-------|
| Entry EV | |
| Equity invested | |
| Exit EBITDA | |
| Exit EV | |
| Net debt at exit | |
| Exit equity value | |
| **MOIC** | |
| **IRR** | |
| Cash-on-cash | |

Show the returns waterfall:
- EBITDA growth contribution
- Multiple expansion/contraction contribution
- Debt paydown contribution
- Fee/expense drag

### Step 3: Sensitivity Tables

**Entry Multiple vs. Exit Multiple**

|---|---------|---------|---------|---------|----------|
| Entry 7x | | | | | |
| Entry 8x | | | | | |
| Entry 9x | | | | | |
| Entry 10x | | | | | |

**EBITDA Growth vs. Exit Multiple** (at fixed entry)

**Leverage vs. Exit Multiple** (at fixed entry and growth)

**Hold Period vs. Exit Multiple**

| | Bull | Base | Bear |
|---|------|------|------|
| Revenue CAGR | | | |

### Step 5: Output

- Excel workbook with:
  - Assumptions tab
  - Returns calculation
  - Sensitivity tables (formatted with conditional coloring)
  - Scenario summary
- One-page returns summary suitable for IC deck

## Key Formulas

- **MOIC** = Exit Equity Value / Equity Invested
- **IRR** = solve for r: Equity Invested × (1 + r)^n = Exit Equity Value (adjust for interim cash flows)
- **Returns attribution**:
  - Growth: (Exit EBITDA - Entry EBITDA) × Exit Multiple / Equity
  - Multiple: (Exit Multiple - Entry Multiple) × Entry EBITDA / Equity
  - Leverage: Debt paydown over hold period / Equity

## Important Notes

- Always show returns both gross and net of fees/carry where applicable
- Management rollover and co-invest change the equity check — ask if relevant
- Dividend recaps or interim distributions affect IRR significantly — include if planned
- Don't forget transaction costs (typically 2-4% of EV) — they reduce Day 1 equity value
- Tax considerations (asset vs. stock deal, 338(h)(10) election) can materially affect after-tax returns
